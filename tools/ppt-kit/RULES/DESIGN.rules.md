# DESIGN 规则 · 设计宪法

> 所有数值默认生效，可被 `STORY.md` 或用户显式指令覆盖；覆盖只作用于被点名的值，其余条款继续生效。
> 冲突处理：用户显式指令 > 本节通例。同向冲突取更严者。

---

## 1. 画布与网格

- 画布 **1280 × 720 pt**（16:9），所有坐标以此为基准。
- **A/B/C 三区**：A 标题区 `y 64–150`；B 内容区 `y 150–596`；C 页脚区 `y 596–720`（横线在 612，页码基线 660）。
- 左右安全边距 **76**，内容宽 **1128**。
- 同类页面之间，标题位置、页码位置**必须完全一致**。封面 / 扉页 / 结束页允许自定义版式。
- 页脚三件套固定：左侧「项目名 · 场合 + 日期」，右侧「页码 / 总页数」，中间留空。

## 2. 字号阶梯

| 角色 | 字号 | 用途 |
|---|---|---|
| display | 72–80 | 封面主标题 |
| h1 | 40 | 内页标题 |
| h2 | 28 | 栏目标题、大数字 |
| h3 | 22 | 卡片标题、副标题 |
| body | 17 | 正文 |
| small | 14 | 表格、注释 |
| caption | 12 | 页脚、图注 |
| eyebrow | 13 | 标题上方的栏目小字（加字距 3） |

规则：
- 阶梯比例保持 **1.3–1.5**，形成跳跃。**禁止所有元素趋近中间大小**——这是"看起来平庸"的第一原因。
- 单页字号种类 ≤ 4 种。超过 4 种说明层级没理清。
- 标题字重 bold，正文常规。**不要用 3 种以上字重**。

## 3. 色彩

- **面积分配 60-30-10**：中性底 60%，结构色（主色）30%，强调色 ≤ 10%。
- 强调色**只用于**：论点数字、关键判断、当前状态。用满一页就失效了。
- 主色不超过 **1 个**，色板总数 ≤ 5 个（主色 / 辅助 / 正文 / 次要文本 / 浅底）。
- 深浅色对必须满足对比度：正文对底色 ≥ 4.5:1，大标题 ≥ 3:1。
- 禁止：渐变、投影、发光、霓虹。平板纯色永远比渐变稳。
- 学术 / 评审场合默认 **蓝白灰**；商务咨询默认 **深蓝 + 橙点**；政务默认 **红金**。选择即锁定全篇，不许中途换。

## 4. 密度

- 常规页正文字数 **180–340 字**；低于 120 字视为"内容稀薄"，高于 420 字必须拆页。
- 留白：常规页 15%–35%；封面 / 扉页 30%–45%。
- **空不等于极简。** 极简的前提是剩下的元素信息密度足够大。内容稀薄 + 大留白 = 空洞。
- 每页只回答**一个问题**。发现自己在页内塞第二个论点，就拆页。

## 5. 视觉锚点

- **每页必须有且只有一个视觉锚点**：超大字号 / 大色块 / 大图 / 大数字 / 数据图表。
- 其余元素围绕锚点组织，尺寸明显小于锚点（至少 1.5 倍差距）。
- Hero 页的锚点占有效面积 ≥ 35%；支撑页 ≥ 20%。
- 禁止"装饰小贴片"：200×70 的小图标塞在标题旁，既不承担叙事也破坏留白。

## 6. 版式预算（全篇级）

| 项 | 约束 |
|---|---|
| 非对称版式占比 | ≥ 40% |
| 单一 layout 占比 | ≤ 40% |
| 相邻两页 layout | 不得相同 |
| 对称版式（N 卡横排、居中大标题） | ≤ 2 页 |
| Hero 占比 | 20%–30% |
| 连续低密度页 | ≤ 2 页 |

## 7. 排版细节（中文向）

- 中文正文行高 **1.6**；标题 1.1–1.2；英文段落 1.4。
- 中英文混排：中文字体设 `微软雅黑`，西文另设 `Times New Roman`（学术）或 `Arial`（商务）。**python-pptx 必须显式设置 eastasia 字体**，否则中文会掉回宋体。
- 标题不加句号；正文句子用中文全角标点；数字与英文用半角，两侧不加空格。
- 中文段落**不做分散对齐**（会出现难看的字间距），用左对齐。
- 项目符号最多两级，第二级缩进 24。符号用 `·` 或实心小方块，不用花哨图标。
- 页码格式固定 `03 / 16`，右对齐。

## 8. 反模式总表

出现任一条，视为设计不通过。

| 类别 | 禁止项 |
|---|---|
| 布局 | 等宽三/四卡横排（除非确为并列关系且仅 1 页）；50:50 对半分栏；所有内容居中 |
| 文字 | 艺术字标题；标题加下划线；全篇同字号（无层级）；一页超过 4 种字号 |
| 色彩 | 渐变底；彩虹配色；强调色铺满；红蓝撞色；低对比灰字 |
| 图形 | 阴影 + 圆角 + 渐变三件套；3D 饼图；装饰性卡通插画；无意义图标堆叠 |
| 内容 | 标题是栏目名；表格只列优点；只讲功能不讲效果；用"持续优化"代替具体计划 |
| 数据 | 柱状图纵轴不从 0 开始；饼图超过 5 块；折线图无单位；只给百分比不给基数 |

## 9. 自检触发返工

以下情况必须重做该页，不允许"调一调再看看"：

- 视觉锚点缺位，或一页有两个互相竞争的锚点
- 正文超出框体（由 `check.py` 的溢出估算报出）
- 标题无法独立成句
- 该页出现 `anti_pattern` 里禁止的形式
- 密度超出 §4 区间 ±30%
