# STORY.md 模板 · 叙事层

> 这份文档在看任何排版软件之前写完。写不满的页面，说明你自己还没想清楚，不要靠加框加色去补。
> 三步必须按顺序做，第①步没写完，禁止进入第②步。

---

## ① 用户意图对齐

用一段话回答下面 5 个问题。不要写成清单，写成判断。

| 问题 | 它决定什么 | 常见错误 |
|---|---|---|
| **目标受众**是谁，什么场合 | 措辞深浅、证据类型 | 写"领导和同事"——等于没写 |
| **核心目标**：讲完希望对方相信什么 / 记住什么 / 做什么 | 全篇的唯一论点 | 写"介绍我们的项目"——那是话题不是目标 |
| **总页数** | Hero 页配额（见下） | 先定 20 页再想内容 |
| **视觉调性** 3–5 个词 | 色板、字体、装饰预算 | 写"高端大气"——无法执行 |
| **内容边界**：必讲 / 不讲 / 禁碰 | 防止页数和废话失控 | 只写"必讲"，不写"不讲" |

**页数与 Hero 配额**：10 页 → 2–3 个 Hero；15 页 → 3–4 个；20 页 → 4–5 个。Hero 占比必须落在 **20%–30%**。

**「禁碰」这一栏最值钱。** 写清楚哪些话绝对不能出现，例如：

- 不能把 AI 评分说成教师评审结论
- 不能说有学习效果提升（没有对照组）
- 不能把"222 项测试通过"说成质量验证通过

写下来之后，后面每一页的措辞都会被这栏约束住。大部分 PPT 让人不舒服，不是因为丑，是因为它在夸大。

## ② 页面骨架

用一张表把全篇排完，一页一行。字段：

| 页 | type | role | rhythm | layout | 这一页要说什么 |
|---|---|---|---|---|---|

### 硬契约（自动校验，违反即报错）

1. **目录 ↔ 章节扉页**：目录里声明 N 个章节，全篇就必须有且仅有 N 个 `type: section` 页，编号 01..N 连续，标题与目录条目**逐字一致**。
2. **Hero 配额**：`role: hero` 的页数占全篇 20%–30%，且任意两个 Hero 之间至少隔 1 个非 Hero 页。
3. **节奏曲线**：每页标 `peak / valley / transition`。禁止连续 ≥3 页 `valley`；章节切换处必须是 `transition`；全篇至少 2 个 `peak`。
4. **版式预算**：非对称版式 ≥ 40%；同一种 layout 使用次数 ≤ 全篇 40%；**相邻两页 layout 不得相同**。
5. **密度**：禁止连续 3 页以上为低密度页。

骨架写完后跑 `pptkit.contract.validate()`，上面 5 条会逐条检查。

## ③ 逐页契约

每页写成 `slides/NN.json`（或集中在 `deck.json` 里），字段：

```json
{
  "type": "content",
  "role": "supporting",
  "rhythm": "valley",
  "layout": "split_title_body",
  "eyebrow": "项目概况 / OVERVIEW",
  "title": "缺的不是教学法，是中间层",
  "subtitle": "个体差异只有在被翻译成写作指令之后才可执行",
  "body": ["……", "……", "……"],
  "insight": "不做通用教学平台，只把讲义这一条线做透。",
  "anti_pattern": ["禁止等宽三卡横排", "禁止把个体差异画成卡通插画"]
}
```

### 标题必须是论断句

这是拉开差距最大的一条。对照：

| 平庸（栏目名） | 有力量（论断） |
|---|---|
| 系统架构 | 给教师用的备课副驾，不是教案生成器 |
| 研究背景 | 教学规模化下的个体差异缺口 |
| 实验结果 | 12 次对照：3 项达标，2 项不达标 |
| 下一步计划 | 先做真实教师评审，再做班级对照 |

**写不出论断，就删掉这一页。** 一个只放栏目名的页面，听众读完标题得不到任何信息。

### 每页必须写 anti_pattern

写着"要什么"很容易撞车，写着"禁止什么"才逼出设计。至少 1 条，例如：

- 禁止等宽三卡横排
- 禁止 50:50 对半分栏
- 禁止表格只列优点
- 禁止用艺术字做标题
- 禁止满版深色底

- [ ] 目录章节数与扉页数逐字对齐？
