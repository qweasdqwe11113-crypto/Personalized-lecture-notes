# 版式速查

10 个版式覆盖 90% 的页面。每个版式对应 `pptkit/layouts.py` 里的一个函数，函数名即 `layout` 字段值。

**选版式的顺序**：先问"这页的视觉锚点是什么"（数字 / 图 / 表 / 流程 / 论断），再选版式。不要先选版式再往里塞内容。

---

## 通用骨架

| 区域 | 坐标 |
|---|---|
| 左右安全边距 | 76 / 1204（内容宽 1128） |
| eyebrow（栏目小字） | y 64，13pt，字距 3，accent 色 |
| 主标题 h1 | y 92 起，40pt bold |
| 副标题 | y 150 起，22pt，muted |
| 内容区 | y 176 – 560 |
| 洞察条 | y 566 – 600（上方 1px 横线 + 左侧 3pt 竖条） |
| 页脚 | 横线 y 612，文字 y 648，12pt hint 色 |

## 1. `cover_split` 封面

**字段**：`title` `subtitle` `en_title` `bullets[3]` `org` `date`
**几何**：左侧 13pt 深色竖条骑线；右侧 560×620 浅底块；左栏内容 x76 w620；bullets 从 y408 起。
**用**：开篇。**反模式**：满版深色底、艺术字标题、人物大头照、印章烟花装饰、把副标写成一句话的堆砌。

## 2. `catalog` 目录

**字段**：`items[{no, title, desc}]`，2–4 条
**几何**：左侧 380 宽整幅主色块（标题反白）；右侧条目 x460 起，每条高 130，编号 40pt accent。
**用**：全篇第 2 页。**反模式**：圆球编号、书法繁体数字、英文比中文抢眼、条目超过 4 条。

## 3. `section` 章节扉页

**字段**：`no`（01..N） `title` `points[3]`
**几何**：大数字 120pt 浅色（非主色）在左上；标题 h1；3 个要点纵向排列；右侧留白 35%。
**用**：每章开头，数量必须与目录章节数一致。
**反模式**：满版蓝底、`PART 02` 式英文水印、放四张卡片预告本章内容、与封面雷同。

## 4. `split_title_body` 左标题右内容

**字段**：`title` `body[2..3]` `insight`
**几何**：左栏 x76 w340（标题 + 3pt 竖线）；右栏 x460 w744，每段「小标题 + 正文」。
**用**：以文字论断为主的支撑页，全篇主力版式。
**反模式**：左右 50:50；右栏做成三个等宽卡片；标题超过 2 行。

## 5. `asym_two_col` 非对称双栏 60:40

**字段**：`title` `left{heading, body[]}` `right{heading, items[{no,title,desc}]}` `insight`
**几何**：左 x76 w620（论述）；右 x748 w456（纵向编号条目，浅底块）。
**用**：左边讲"为什么"，右边讲"有哪些"。
**反模式**：等分 50:50；右侧做成横向卡片；右栏条目超过 4 条。

## 6. `table_insight` 表格 + 洞察

**字段**：`title` `table{header[], rows[][], col_widths[]?}` `insight`
**几何**：表 x76 w1128，y 起 186；行高 = min(48, 300/行数)；表头主色底反白。
**用**：多方案对比、能力矩阵。
**反模式**：只列优点不列局限；用表格代替判断（表格下方必须有 insight 结论）；超过 6 行（该拆分或精选）。

## 7. `flow_axis` 横向流程轴

**字段**：`title` `nodes[{label, desc}]`（3–5 个）`insight`
**几何**：节点横排于 y 280，节点间距 24，节点宽 =（1128 − 24×(n−1)）/n，高 96；节点之间箭头。
**用**：流程、闭环、演进阶段。
**反模式**：超过 5 个节点；环形排布；节点内含三行以上文字。

## 8. `cards_row` 卡片横排

**字段**：`title` `cards[{title, desc}]`（2–3 个）`insight`
**几何**：卡 y 200 h 300，宽 =（1128 − 32×(n−1)）/n；浅底 + 顶部 3pt 色条。
**用**：并列的三个概念（全篇 ≤ 2 页）。
**反模式**：4 卡以上等宽横排——改用 `asym_two_col` 或 `table_insight`。

## 9. `big_number_insight` 大数字 + 洞察

**字段**：`title` `numbers[{value, unit, label}]`（2–4 个）`insight`
**几何**：数字 72pt accent 横排于 y 240，label 14pt 在下方；可带单位小字。
**用**：关键结论页、成果页。
**反模式**：4 个以上数字；数字含义需要读正文才懂；给数字不给对比基准。

## 10. `chart_insight` 图表 + 洞察

**字段**：`title` `chart{kind: bar|line, categories[], series[{name, values[]}]}` `insight`
**几何**：图 x76 w700 h340；右侧洞察 x812 w392。
**用**：趋势、对比。
**反模式**：柱状图纵轴不从 0 开始；超过 3 条系列；无单位；饼图（改用 bar）。

## 版式 ↔ 内容类型映射

| 这页要表达 | 选 |
|---|---|
| 一个判断 / 一段论述 | `split_title_body` |
| 原因 + 清单 | `asym_two_col` |
| 多方案横向对比 | `table_insight` |
| 步骤 / 闭环 | `flow_axis` |
| 三个并列概念 | `cards_row` |
| 关键结果 | `big_number_insight` |
| 数据趋势 | `chart_insight` |
| 章节切换 | `section` |
