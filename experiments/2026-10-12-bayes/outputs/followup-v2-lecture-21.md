# 大学概率：贝叶斯推导与先验敏感性

## 学习目标
1. 从条件概率定义出发，推导全概率公式与贝叶斯公式，明确所有分母为正的条件。
2. 完成双产线基准计算，区分 P(A|B) 与 P(B|A)，避免方向混淆。
3. 通过先验变化对照，理解后验对先验的敏感性，并验证后验归一性。

## 本次学习安排
针对小唐“交换条件方向”和“忽略先验加权”的易错点，本次采用“正确 vs 错误”对比讲解。重点拆解交集分解过程，强调全概率中“来源先验”的必要性，并通过数值计算强化后验归一检查。

## 核心讲解
**1. 条件概率与方向区分**
设事件 A、B，当 P(B)>0 时，P(A|B) = P(A∩B) / P(B) [M11]。
注意：P(A|B) 与 P(B|A) 一般不同。
*   **错误理解**：认为 P(A|B) = P(B|A)，或仅在 P(A)=P(B) 时相等。
*   **正确理解**：若 P(A∩B)=0 且 P(A)>0, P(B)>0，则两者均为 0；否则数值通常不同。分母代表“已知条件”的样本空间缩小范围。

**2. 全概率公式推导**
设 A1, A2 为样本空间的有限互斥完备划分（两两互斥，合并覆盖全空间），且 P(Ai)>0 [M12]。
事件 B 可分解为互不相交的并集：B = (B∩A1) ∪ (B∩A2)。
因此：
P(B) = P(B∩A1) + P(B∩A2)
利用乘法公式 P(B∩Ai) = P(Ai) × P(B|Ai)，得：
P(B) = P(A1) × P(B|A1) + P(A2) × P(B|A2)
*   **易错点**：不能直接将次品率相加，必须乘以来源先验 P(Ai)。

**3. 贝叶斯公式**
在 P(B)>0 条件下，后验概率为：
P(Ak|B) = [P(Ak) × P(B|Ak)] / P(B)
其中分母 P(B) = Σi [P(Ai) × P(B|Ai)] [M13]。
先验是 P(Ak)，似然是 P(B|Ak)，后验是 P(Ak|B)。

## 例题与检验
**例1：双产线基准（先验 0.6, 0.4；似然 0.02, 0.05）**
*   **计算 P(D)**：
    P(D) = 0.6 × 0.02 + 0.4 × 0.05 = 0.012 + 0.020 = 0.032
*   **计算后验**：
    P(A1|D) = (0.6 × 0.02) / 0.032 = 0.012 / 0.032 = 0.375
    P(A2|D) = (0.4 × 0.05) / 0.032 = 0.020 / 0.032 = 0.625
*   **归一检查**：0.375 + 0.625 = 1。
*   **频数复核**：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。来自 A1 的次品占比 120/320 = 0.375，一致。

**例2：先验变化（先验 0.2, 0.8；似然不变）**
*   **计算 P(D)**：
    P(D) = 0.2 × 0.02 + 0.8 × 0.05 = 0.004 + 0.040 = 0.044
*   **计算后验**：
    P(A1|D) = (0.2 × 0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091
    P(A2|D) = (0.8 × 0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909
*   **归一检查**：0.091 + 0.909 = 1。
*   **对比**：A1 先验从 0.6 降至 0.2，其后验从 0.375 降至 0.091。说明后验随先验变化，但推理逻辑（全概率+贝叶斯）不变。

## 易错点与小结
1.  **方向混淆**：P(A|B) 是“已知 B 发生，A 发生的概率”，分母是 P(B)。切勿将 P(B|A) 当作 P(A|B)。
2.  **忽略先验**：全概率公式中，每一项必须是“来源概率 × 该来源下的条件概率”。直接相加条件概率是错误的。
3.  **互斥不等于独立**：划分事件 A1, A2 互斥，不代表它们与 B 独立。
4.  **小结**：贝叶斯公式本质是条件概率的代数变形，核心在于正确识别先验、似然与分母（全概率）。
