# 大学概率：贝叶斯推导与先验敏感性

## 学习目标
掌握条件概率定义及正分母条件，理解互斥完备划分下的全概率公式推导，熟练运用贝叶斯公式计算后验概率，并通过双产线案例验证后验归一性，区分条件概率的方向性。

## 本次学习安排
首先回顾条件概率与乘法公式，明确 P(A|B) 与 P(B|A) 的区别。接着推导全概率公式，强调划分需两两互斥且完备。随后推导贝叶斯公式，完成固定双产线基准计算，最后通过改变先验比例进行敏感性对照分析。

## 核心讲解
设事件 A、B，当 P(B)>0 时，定义条件概率 P(A|B) = P(A∩B) / P(B) [M11]。由此可得乘法公式 P(A∩B) = P(B) × P(A|B)。注意 P(A|B) 与 P(B|A) 一般不相等，前者以 B 为条件，分母为 P(B)；后者以 A 为条件，分母为 P(A)，且需 P(A)>0 [M11]。

若有限事件 A1, …, An 构成样本空间的划分，即两两互斥且合并覆盖整个空间，且每个 P(Ai)>0，则事件 B 可分解为互不相交的 B∩Ai 之并。根据可加性与乘法公式，全概率公式为 P(B) = Σi P(Ai) × P(B|Ai) [M12]。此处划分互斥不等于事件独立，不可混淆。

在 P(B)>0 条件下，由条件概率定义及乘法公式，贝叶斯公式推导如下：
P(Ak|B) = P(Ak∩B) / P(B) = P(Ak) × P(B|Ak) / [Σi P(Ai) × P(B|Ai)] [M13]
其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1 [M13]。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**双产线基准**：设 A1、A2 为互斥完备产线，D 为次品。先验 P(A1)=0.6, P(A2)=0.4；似然 P(D|A1)=0.02, P(D|A2)=0.05。
全概率 P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
后验 P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375。
后验 P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
检查归一：0.375 + 0.625 = 1。
假设频数核对：10000 件中，A1 产 6000 件，次品 120 件；A2 产 4000 件，次品 200 件。总次品 320 件。A1 次品占比 120/320 = 0.375，A2 次品占比 200/320 = 0.625，与计算一致。

**先验变化对照**：保持似然不变，改变先验为 P(A1)=0.2, P(A2)=0.8。
新 P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
新后验 P(A1|D) = (0.2×0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091。
新后验 P(A2|D) = (0.8×0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909。
比较发现，A1 后验从 0.375 降至 0.091。说明先验变化显著影响后验，但推理逻辑及适用条件（正分母、互斥完备）保持不变 [M13]。


新后验完整核对：P(A1|D)=1/11≈0.091，P(A2|D)=10/11≈0.909，精确和为 1；用先验变化后的假设频数，次品为 40 与 400 件，总计 440 件，40/440 与 400/440 分别对应这两个后验 [M13]。

## 易错点与小结
常见错误是将 P(A|B) 误认为 P(B|A)，或忽略条件事件概率大于零的前提。全概率公式中若划分不互斥或不完备，会导致重复计算或遗漏来源。贝叶斯公式中分母 P(B) 必须大于零。本讲义基于自编假设数据，旨在展示数学推导与计算流程，不涉及实际医学诊断或模型训练建议。掌握从条件概率到贝叶斯公式的完整推导链条，是理解概率更新机制的关键。
