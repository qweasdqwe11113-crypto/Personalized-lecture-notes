# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

## 学习目标
基于小顾已掌握条件概率方向、全概率划分及贝叶斯推导的证据，本次压缩基础定义复述，聚焦推导中的正分母条件、后验归一检验及先验变化对结果的影响。重点区分 P(A|B) 与 P(B|A) 的方向性，完成双产线基准计算及先验敏感性对照，确保推理逻辑严密。

## 本次学习安排
1. 简述推导链条：从条件概率定义出发，经乘法公式至全概率，最后推导贝叶斯公式，强调每一步的分母非零条件。
2. 执行固定双产线基准例题：计算全概率、两个后验，并用假设频数复核归一性。
3. 执行先验变化对照：保持似然不变，改变先验比例，比较后验变化，分析推理条件的稳定性。

## 核心讲解
推导起点是条件概率。当 P(B)>0 时，P(A|B) = P(A∩B) / P(B)，由此得 P(A∩B) = P(B) × P(A|B) [M11]。注意 P(A|B) 与 P(B|A) 分母不同，一般不相等。

设 A1, A2 为样本空间的有限划分，需满足两两互斥、合并完备，且各 P(Ai)>0 [M12]。事件 B 可分解为互不相交的 B∩A1 与 B∩A2 之并。根据加法公式与乘法公式，P(B) = P(A1)P(B|A1) + P(A2)P(B|A2)。此即全概率公式，要求划分完备以避免遗漏或重复 [M12]。

在 P(B)>0 的前提下，贝叶斯公式为 P(Ak|B) = P(Ak)P(B|Ak) / P(B) [M13]。其中 P(Ak) 为先验，P(B|Ak) 为似然，分母 P(B) 由全概率公式给出。后验各项非负且和为 1，这是概率公理的自然结果，也是数值计算的校验标准 [M13]。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**基准案例**：设产线 A1、A2 互斥完备，先验 P(A1)=0.6, P(A2)=0.4；次品率 P(D|A1)=0.02, P(D|A2)=0.05。
1. 全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
2. 后验：P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375；P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
3. 归一检查：0.375 + 0.625 = 1。
4. 频数复核：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。A1 来源次品占比 120/320 = 0.375，A2 来源占比 200/320 = 0.625，与公式一致。

**先验变化对照**：保持似然不变，改先验为 P(A1)=0.2, P(A2)=0.8。
1. 新全概率：P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
2. 新后验：P(A1|D) = 0.004 / 0.044 ≈ 0.091；P(A2|D) = 0.040 / 0.044 ≈ 0.909。
3. 比较：A1 的后验从 0.375 降至 0.091。说明在似然不变时，先验比例直接主导后验分布，但推理仍依赖相同的互斥完备划分及正分母条件 [M13]。


新后验完整核对：P(A1|D)=1/11≈0.091，P(A2|D)=10/11≈0.909，精确和为 1；用先验变化后的假设频数，次品为 40 与 400 件，总计 440 件，40/440 与 400/440 分别对应这两个后验 [M13]。

## 易错点与小结
常见错误是将 P(A|B) 误认为 P(B|A)，或忽略 P(B)>0 的条件。互斥划分仅保证概率可加，不蕴含事件独立。先验变化仅反映信息更新，不构成因果推断。本讲义基于自编假设数据，旨在验证推导逻辑与归一性质，不扩展至连续密度或医学诊断场景。
