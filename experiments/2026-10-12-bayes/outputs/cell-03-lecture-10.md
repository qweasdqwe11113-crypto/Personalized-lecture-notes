## 本次学习安排
针对小唐“交换条件方向”及“忽略先验加权”的诊断证据，本次讲义采用“正确与错误推理对比”策略。首先纠正 P(A|B) 与 P(B|A) 的混淆，随后通过分步推导全概率公式，强调互斥完备划分的加权必要性，最后通过双产线例题与先验变化对照，巩固贝叶斯后验的计算逻辑。

## 核心讲解
**1. 条件概率的方向与正分母**
设事件 A、B，当 P(B)>0 时，定义 P(A|B) = P(A∩B) / P(B) [M11]。
**错误推理**：认为 P(A|B) = P(B|A)。
**正确解释**：P(A|B) 的分母是 P(B)，表示在 B 发生的条件下 A 发生的概率；P(B|A) 的分母是 P(A)，二者一般不相等。例如，抽到次品来自产线1的概率，不等于产线1生产次品的概率。

**2. 全概率公式的推导**
设 A1, A2 为样本空间的互斥完备划分（两两互斥且并集为全集），且 P(Ai)>0 [M12]。
事件 D（次品）可分解为互不相交的并集：D = (D∩A1) ∪ (D∩A2)。
因此 P(D) = P(D∩A1) + P(D∩A2)。
利用乘法公式 P(D∩Ai) = P(Ai)P(D|Ai)，得：
P(D) = P(A1)P(D|A1) + P(A2)P(D|A2) [M12]。
**错误推理**：直接相加次品率 P(D|A1) + P(D|A2)。
**正确解释**：必须乘以来源先验 P(Ai) 进行加权，否则忽略了各产线产量占比。

**3. 贝叶斯公式与后验归一**
在 P(D)>0 条件下，P(Ak|D) = P(Ak)P(D|Ak) / P(D) [M13]。
代入全概率公式作为分母：
P(Ak|D) = P(Ak)P(D|Ak) / [P(A1)P(D|A1) + P(A2)P(D|A2)]
后验 P(A1|D) + P(A2|D) 恒等于 1，体现了概率归一性 [M13]。

## 例题与检验
**基准案例（自编假设数据）**
设产线1先验 P(A1)=0.6，产线2先验 P(A2)=0.4；次品率 P(D|A1)=0.02，P(D|A2)=0.05。
1. 计算总次品率：
P(D) = 0.6 × 0.02 + 0.4 × 0.05 = 0.012 + 0.020 = 0.032
2. 计算后验：
P(A1|D) = (0.6 × 0.02) / 0.032 = 0.012 / 0.032 = 0.375
P(A2|D) = (0.4 × 0.05) / 0.032 = 0.020 / 0.032 = 0.625
3. 归一检查：0.375 + 0.625 = 1。
4. 频数复核：假设10000件，产线1有6000件，次品120件；产线2有4000件，次品200件。总次品320件。来自产线1的次品占比 120/320 = 0.375，与计算一致。

**先验变化对照**
保持似然不变，改变先验为 P(A1)=0.2，P(A2)=0.8。
1. 新总次品率：
P(D) = 0.2 × 0.02 + 0.8 × 0.05 = 0.004 + 0.040 = 0.044
2. 新后验：
P(A1|D) = (0.2 × 0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091
P(A2|D) = (0.8 × 0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909
3. 对比：A1 后验从 0.375 降至 0.091。说明先验变化显著影响后验，但推理逻辑与适用条件（互斥完备、正分母）保持不变 [M13]。

## 易错点与小结
1. **方向混淆**：切勿将 P(A|B) 与 P(B|A) 等同。P(A|B) 关注“已知B，A发生”，P(B|A) 关注“已知A，B发生”。
2. **忽略加权**：全概率公式中，必须对每个来源的似然乘以先验，不能简单相加。
3. **先验敏感性**：后验不仅取决于似然，还强烈依赖于先验。改变先验比例会改变后验分布，但不改变公式的推导结构。
4. **独立与互斥**：互斥完备划分是推导全概率的基础，但互斥事件不一定独立，不可混淆概念。
