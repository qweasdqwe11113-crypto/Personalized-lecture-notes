# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

2. 明确所有推导步骤中分母大于零的必要条件。
3. 完成固定双产线基准计算，并通过假设频数核对后验归一性。
4. 执行先验变化对照实验，分析先验对后验的影响，并区分 P(A|B) 与 P(B|A)。

## 本次学习安排
本次为进阶任务，重点在于逻辑链条的完整性与数值计算的严谨性。我们将首先梳理理论推导，随后进行两组数值计算：基准案例与先验变化案例。所有数据均为自编假设模型，旨在验证公式逻辑而非反映真实工业数据 [M11]。

## 核心讲解
**1. 条件概率与乘法公式**
设事件 A、B，当 P(B) > 0 时，定义 P(A|B) = P(A∩B) / P(B)。由此可得乘法公式 P(A∩B) = P(B) × P(A|B) [M11]。注意，P(A|B) 与 P(B|A) 一般不相等，前者以 B 为条件限定范围，分母为 P(B)；后者以 A 为条件，分母为 P(A) [M11]。

**2. 全概率公式推导**
设 A1, A2, …, An 构成样本空间的一个有限划分，即两两互斥且并集为全集。若每个 P(Ai) > 0，则事件 B 可分解为互不相交的并集：B = ∪(B∩Ai)。根据概率可加性与乘法公式：
P(B) = Σ P(B∩Ai) = Σ P(Ai) × P(B|Ai) [M12]
此推导要求划分完备且互斥，但互斥不等于独立 [M12]。

**3. 贝叶斯公式推导**
在上述划分条件下，若 P(B) > 0，则：
P(Ak|B) = P(Ak∩B) / P(B) = [P(Ak) × P(B|Ak)] / [Σ P(Ai) × P(B|Ai)] [M13]
其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1 [M13]。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**案例一：双产线基准**
设 A1、A2 为互斥完备的产线来源，D 为次品。
先验：P(A1)=0.6, P(A2)=0.4。
似然：P(D|A1)=0.02, P(D|A2)=0.05。

计算全概率 P(D)：
P(D) = 0.6 × 0.02 + 0.4 × 0.05 = 0.012 + 0.020 = 0.032

计算后验：
P(A1|D) = (0.6 × 0.02) / 0.032 = 0.012 / 0.032 = 0.375
P(A2|D) = (0.4 × 0.05) / 0.032 = 0.020 / 0.032 = 0.625
检查归一：0.375 + 0.625 = 1。

假设频数核对（10000件）：
A1 次品数：10000 × 0.6 × 0.02 = 120
A2 次品数：10000 × 0.4 × 0.05 = 200
总次品：320
P(A1|D) ≈ 120/320 = 0.375，P(A2|D) ≈ 200/320 = 0.625，结果一致。

**案例二：先验变化**
保持似然不变，改变先验为 P(A1)=0.2, P(A2)=0.8。
新 P(D) = 0.2 × 0.02 + 0.8 × 0.05 = 0.004 + 0.040 = 0.044
新 P(A1|D) = (0.2 × 0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091
新 P(A2|D) = (0.8 × 0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909
检查归一：0.091 + 0.909 = 1。
对比发现，A1 的后验从 0.375 降至 0.091，说明先验变化显著影响后验，但推理逻辑与适用条件不变 [M13]。

## 易错点与小结
1. **分母条件**：定义条件概率必须 P(B)>0；使用全概率需各 P(Ai)>0；贝叶斯后验需 P(B)>0 [M11][M12][M13]。
2. **方向混淆**：切勿将 P(A|B) 等同于 P(B|A)，二者分母不同，含义迥异 [M11]。
3. **互斥与独立**：划分互斥仅保证不重叠，不能推导出事件独立 [M12]。
4. **归一检查**：计算后务必验证后验之和为 1，这是检验计算错误的有效手段 [M13]。
