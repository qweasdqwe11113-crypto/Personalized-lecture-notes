# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

## 学习目标
本次学习旨在从条件概率和互斥完备划分出发，严谨推导全概率与贝叶斯公式，明确所有正分母条件。通过固定双产线例题及先验变化对照，核对后验归一性，并严格区分 P(A|B) 与 P(B|A) 的方向差异。

## 本次学习安排
针对小许同学“把 P(A|B) 分母误写为 P(A)”的诊断，本讲义将分步拆解条件样本空间，明确分母含义。针对“漏写 P(B)>0”的问题，将在推导中反复强调正分母前提。全概率部分暂无诊断证据，采用适中解释，不预设薄弱。

## 核心讲解
首先明确条件概率方向。设事件 A、B，当 P(B)>0 时，P(A|B) = P(A∩B) / P(B)。此处分母 P(B) 代表已知 B 发生后的条件样本空间大小，而非 P(A)。反向 P(B|A) 需 P(A)>0，二者一般不等 [M11]。

接着推导全概率。设有限事件 A1, …, An 构成样本空间划分，即两两互斥且合并覆盖整个空间，且每个 P(Ai)>0。事件 B 可分解为互不相交的 B∩Ai 的并集。根据加法公式与乘法公式，P(B) = Σi P(Ai∩Bi) = Σi P(Ai)P(B|Ai)。注意，划分互斥不等于事件独立 [M12]。

最后推导贝叶斯公式。在上述划分条件及 P(B)>0 下，由条件概率定义 P(Ak|B) = P(Ak∩B) / P(B)。分子利用乘法公式得 P(Ak)P(B|Ak)，分母利用全概率公式得 Σi P(Ai)P(B|Ai)。因此 P(Ak|B) = P(Ak)P(B|Ak) / Σi P(Ai)P(B|Ai)。其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1 [M13]。

## 例题与检验
**双产线基准**：设 A1、A2 为互斥完备产线，D 为次品。先验 P(A1)=0.6, P(A2)=0.4；似然 P(D|A1)=0.02, P(D|A2)=0.05。
1. 全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
2. 后验 P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375。
3. 后验 P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
4. 归一检查：0.375 + 0.625 = 1。
5. 频数复核：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。A1 次品占比 120/320 = 0.375，A2 次品占比 200/320 = 0.625，与计算一致。

**先验变化**：保持似率不变，改先验为 P(A1)=0.2, P(A2)=0.8。
1. 新 P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
2. 新 P(A1|D) = (0.2×0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091。
3. 新 P(A2|D) = (0.8×0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909。
4. 比较：A1 后验从 0.375 降至 0.091。说明先验变化会改变后验，但推理仍需满足 P(B)>0 等适用条件 [M13]。

## 易错点与小结
易错点一：混淆 P(A|B) 与 P(B|A)。P(A|B) 分母是 P(B)，表示在 B 条件下 A 的比例；P(B|A) 分母是 P(A)，二者数值通常不同。
易错点二：忽略正分母条件。使用条件概率、全概率及贝叶斯公式时，必须确保分母事件概率大于零，否则公式无定义。
易错点三：误将互斥当独立。全概率推导依赖划分互斥，但这不意味着各来源事件独立。
小结：贝叶斯公式是条件概率与全概率的自然结合。通过固定双产线例题，我们验证了后验归一性，并通过先验变化展示了参数敏感性。所有推导均基于有限划分与正概率假设，未扩展至连续密度或重复观测独立性。
