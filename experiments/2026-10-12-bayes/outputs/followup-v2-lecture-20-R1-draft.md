# 大学概率：条件概率与贝叶斯公式（基础任务）

## 学习目标
明确条件概率的方向性与正分母要求，理解全概率公式中互斥完备划分的逻辑，掌握贝叶斯后验的计算与归一化检验，完成双产线基准例题。

## 本次学习安排
针对小许在条件概率分母方向上的诊断证据，本次将分步推导条件概率定义，强调分母为条件事件概率；针对全概率划分暂无诊断证据，提供适中解释；针对贝叶斯公式漏写 P(B)>0 条件的部分掌握状态，重点补充推导中的前提条件。

## 核心讲解
设事件 A、B，当 P(B)>0 时，条件概率定义为 P(A|B) = P(A∩B) / P(B) [M11]。这里分母 P(B) 代表已知事件 B 发生后的样本空间缩减比例，不能误写为 P(A)。反向条件 P(B|A) 需满足 P(A)>0，且 P(A|B) 与 P(B|A) 一般不相等 [M11]。

若 A1, …, An 构成样本空间的有限划分，即两两互斥且并集为全集，且各 P(Ai)>0，则事件 B 可分解为互不相交的 B∩Ai 之并。由加法公式与乘法公式可得全概率公式：P(B) = Σi [P(Ai) × P(B|Ai)] [M12]。注意划分互斥不等于事件独立。

在 P(B)>0 条件下，贝叶斯公式为 P(Ak|B) = [P(Ak) × P(B|Ak)] / P(B) [M13]。其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1。

### 条件范围与检查说明
P(B) 是事件 B 的概率，并不是事件包含的结果数。只有在所用频数或等可能计数模型中，才能用条件范围中的件数直观解释比值；一般情形仍使用概率测度 [M11]。全概率推导必须对同一个观测事件分解，不能改变次品事件或省掉一条来源 [M12]。两项后验和为一来自相同的正分母及互斥完备划分；和为一只是必要检查，互换两个后验仍可能通过，所以还要核对分子对应哪条产线、似然与先验是否正确。频数是为本题编写的假设数据，不是实际测量结果 [M13]。

## 例题与检验
**双产线基准**：设 A1、A2 为互斥完备的产线来源，D 为次品。先验 P(A1)=0.6, P(A2)=0.4；似然 P(D|A1)=0.02, P(D|A2)=0.05。
1. 全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
2. 后验：P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375；P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
3. 归一检查：0.375 + 0.625 = 1。
4. 频数复核：假设 10000 件产品，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320 件。来自 A1 的后验比例 120/320=0.375，来自 A2 的 200/320=0.625，与计算一致。

## 易错点与小结
易错点：混淆 P(A|B) 与 P(B|A) 的分母；忽略 P(B)>0 的前提；误认为划分互斥即独立。小结：条件概率方向由“已知”决定，全概率依赖互斥完备划分，贝叶斯后验必须通过归一化检验。进阶任务可尝试改变先验观察后验变化，但需保持似然不变。
