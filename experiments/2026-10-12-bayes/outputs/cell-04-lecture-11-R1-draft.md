# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

## 学习目标
1. 从条件概率定义与乘法公式出发，推导全概率公式与贝叶斯公式。
2. 明确所有推导步骤中正分母条件的必要性。
3. 完成固定双产线基准计算，并通过假设频数核对后验归一性。
4. 执行先验变化对照，分析先验对后验的影响，并严格区分 P(A|B) 与 P(B|A)。

## 本次学习安排
本次为进阶任务，重点在于逻辑推导的严密性与数值计算的验证。讲义将首先梳理从条件概率到贝叶斯公式的完整推导链条，随后通过两个具体的产线案例进行数值演练。案例数据均为自编假设模型，旨在验证公式逻辑而非反映真实工业数据。

## 核心讲解
设事件 A、B，当 P(B)>0 时，条件概率定义为 P(A|B) = P(A∩B) / P(B) [M11]。由此可得乘法公式 P(A∩B) = P(B) × P(A|B)。注意，P(A|B) 与 P(B|A) 一般不相等，前者以 B 为条件限定范围，分母为 P(B)；后者以 A 为条件，分母为 P(A) [M11]。

若有限事件 A1, …, An 构成样本空间的划分，即两两互斥且合并覆盖整个空间，且每个 P(Ai)>0，则事件 B 可分解为互不相交的 B∩Ai 的并。根据概率可加性与乘法公式，全概率公式为 P(B) = Σi P(Ai) × P(B|Ai) [M12]。推导中需强调，划分互斥不等于事件独立，不可混淆。

在 P(B)>0 的条件下，对特定来源 Ak，由条件概率定义 P(Ak|B) = P(Ak∩B) / P(B)，代入乘法公式与全概率公式，得贝叶斯公式：
P(Ak|B) = [P(Ak) × P(B|Ak)] / [Σi [P(Ai) × P(B|Ai)]] [M13]
其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**基准案例**：产线 A1、A2 互斥完备，先验 P(A1)=0.6, P(A2)=0.4；次品率 P(D|A1)=0.02, P(D|A2)=0.05。
1. 全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
2. 后验：P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375；P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
3. 归一检查：0.375 + 0.625 = 1。
4. 频数核对：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。A1 来源次品占比 120/320 = 0.375，与计算一致。

**先验变化案例**：保持似然不变，改变先验为 P(A1)=0.2, P(A2)=0.8。
1. 新全概率：P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
2. 新后验：P(A1|D) = (0.2×0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091；P(A2|D) = (0.8×0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909。
3. 对比：A1 后验从 0.375 降至 0.091。说明在似然不变时，先验比例的变化会显著改变后验分布，但推理仍需满足划分互斥完备及正分母条件 [M13]。


新后验完整核对：P(A1|D)=1/11≈0.091，P(A2|D)=10/11≈0.909，精确和为 1；用先验变化后的假设频数，次品为 40 与 400 件，总计 440 件，40/440 与 400/440 分别对应这两个后验 [M13]。

## 易错点与小结
1. **方向混淆**：切勿将 P(D|A1)（A1 产次品概率）误作 P(A1|D)（次品来自 A1 概率）。前者是似然，后者是后验。
2. **分母条件**：所有条件概率及贝叶斯公式应用必须确保分母事件概率大于零。
3. **互斥与独立**：全概率公式依赖划分的互斥完备性，而非独立性。
4. **先验敏感性**：后验受先验影响，但改变先验不改变似然结构，也不构成因果推断。
5. **归一性**：计算后务必检查所有后验概率之和是否为 1，这是验证计算正确性的关键步骤。
