# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

## 学习目标
1. 从条件概率定义出发，严格推导全概率公式与贝叶斯公式，明确所有分母大于零的前提。
2. 完成双产线基准计算，通过假设频数核对后验归一性。
3. 执行先验变化对照，分析先验调整对后验的影响，区分 P(A|B) 与 P(B|A) 的方向差异。

## 本次学习安排
针对小唐“易交换条件方向”及“忽略先验加权”的诊断，本次采用“错误对比+分步推导”策略。重点纠正将次品率直接当作来源概率的误区，强调全概率中先验的权重作用。

## 核心讲解
**1. 条件概率与方向辨析**
定义 P(A|B) = P(A∩B) / P(B)，要求 P(B) > 0 [M11]。
*   **错误推理**：认为 P(A|B) = P(B|A)。
*   **正确步骤**：P(A|B) 的分母是 P(B)，P(B|A) 的分母是 P(A)。二者一般不同。交集概率为零时也可同时为零；交集概率为正且两事件概率为正时，相等等价于 P(A)=P(B)。条件概率以已知事件限定样本空间范围。

**2. 全概率公式推导**
设 A1, A2 为样本空间的互斥完备划分，且 P(Ai) > 0 [M12]。
事件 D 可分解为互不相交的并集：D = (D∩A1) ∪ (D∩A2)。
由加法公式与乘法公式：
P(D) = P(D∩A1) + P(D∩A2)
P(D) = P(A1)P(D|A1) + P(A2)P(D|A2)
*   **易错点**：不能直接将 P(D|A1) 与 P(D|A2) 相加，必须乘以对应的先验概率 P(Ai) 进行加权。

**3. 贝叶斯公式推导**
在 P(D) > 0 条件下，由条件概率定义：
P(Ak|D) = P(Ak∩D) / P(D)
代入乘法公式 P(Ak∩D) = P(Ak)P(D|Ak) 及全概率公式作为分母：
P(Ak|D) = P(Ak)P(D|Ak) / [P(A1)P(D|A1) + P(A2)P(D|A2)] [M13]
其中 P(Ak) 为先验，P(D|Ak) 为似然，P(Ak|D) 为后验。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**1. 双产线基准（假设数据）**
设 A1（产线1）、A2（产线2）互斥完备。
先验：P(A1)=0.6, P(A2)=0.4。
似然（次品率）：P(D|A1)=0.02, P(D|A2)=0.05。

*   **全概率 P(D)**：
    P(D) = 0.6 × 0.02 + 0.4 × 0.05 = 0.012 + 0.020 = 0.032
*   **后验 P(A1|D)**：
    P(A1|D) = (0.6 × 0.02) / 0.032 = 0.012 / 0.032 = 0.375
*   **后验 P(A2|D)**：
    P(A2|D) = (0.4 × 0.05) / 0.032 = 0.020 / 0.032 = 0.625
*   **归一检查**：0.375 + 0.625 = 1。
*   **频数复核**：假设 10000 件产品。
    A1 来源 6000 件，次品 120 件；A2 来源 4000 件，次品 200 件。
    总次品 320 件。
    来自 A1 的次品占比：120 / 320 = 0.375。与公式结果一致。

**2. 先验变化对照**
保持似然不变，仅改变先验：P(A1)=0.2, P(A2)=0.8。
*   **新 P(D)**：
    P(D) = 0.2 × 0.02 + 0.8 × 0.05 = 0.004 + 0.040 = 0.044
*   **新后验 P(A1|D)**：
    P(A1|D) = (0.2 × 0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091
*   **对比分析**：
    原后验 P(A1|D) 为 0.375，新后验降至 0.091。
    说明当先验大幅降低 A1 的比例时，即使 A1 次品率较低，观测到次品后归属于 A1 的概率也显著下降。推理逻辑不变，但数值对先验敏感。


新后验完整核对：P(A1|D)=1/11≈0.091，P(A2|D)=10/11≈0.909，精确和为 1；用先验变化后的假设频数，次品为 40 与 400 件，总计 440 件，40/440 与 400/440 分别对应这两个后验 [M13]。

## 易错点与小结
1.  **方向混淆**：P(D|A1) 是“已知来自 A1，是次品的概率”（似然）；P(A1|D) 是“已知是次品，来自 A1 的概率”（后验）。二者分母不同，不可互换。
2.  **忽略先验**：计算全概率时，必须用 P(Ai) 加权。直接相加次品率是错误的，因为忽略了各产线产量占比。
3.  **正分母条件**：使用条件概率及贝叶斯公式时，必须确保条件事件概率大于零，否则公式无定义。
4.  **小结**：贝叶斯公式本质是条件概率的代数变形。后验概率由先验和似然共同决定，先验的变化会直接改变后验分布，但需始终满足互斥完备划分及正概率前提。
