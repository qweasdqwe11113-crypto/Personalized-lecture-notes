## 核心讲解
**1. 条件概率的方向与正分母**
设事件 A、B。当 P(B)>0 时，定义 P(A|B) = P(A∩B) / P(B)。这里 B 是已知发生的条件，样本空间被限定在 B 内，因此分母是 P(B) 而非 P(A)。反之，P(B|A) = P(B∩A) / P(A)，要求 P(A)>0。二者一般不相等，混淆方向是常见错误 [M11]。

**2. 全概率公式的推导**
设 A1, A2 构成样本空间的有限划分，即两两互斥且合并覆盖整个空间，且每个 P(Ai)>0。事件 B 可分解为互不相交的并集：B = (B∩A1) ∪ (B∩A2)。根据概率可加性及乘法公式 P(Ai∩B) = P(Ai)P(B|Ai)，可得：
P(B) = P(A1)P(B|A1) + P(A2)P(B|A2)
注意：划分互斥不等于事件独立，不能省略任何来源 [M12]。

**3. 贝叶斯公式与归一性**
在 P(B)>0 的前提下，由条件概率定义：
P(Ak|B) = P(Ak∩B) / P(B) = P(Ak)P(B|Ak) / Σi P(Ai)P(B|Ai)
其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1 [M13]。

## 例题与检验
**基准案例：双产线模型**
假设 A1（产线1）先验 0.6，次品率 0.02；A2（产线2）先验 0.4，次品率 0.05。
1. 全概率 P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
2. 后验 P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375。
3. 后验 P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
4. 归一检查：0.375 + 0.625 = 1。
5. 频数复核：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。P(A1|D) = 120/320 = 0.375，一致。

**先验变化对照**
保持次品率不变，仅将先验改为 A1: 0.2, A2: 0.8。
1. 新 P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
2. 新 P(A1|D) = 0.004 / 0.044 ≈ 0.091。
3. 新 P(A2|D) = 0.040 / 0.044 ≈ 0.909。
4. 比较：A1 的后验从 0.375 降至 0.091。说明先验变化会显著影响后验，但推理逻辑与适用条件（互斥完备、正分母）保持不变 [M13]。

## 易错点与小结
1. **方向错误**：切勿将 P(A|B) 的分母写成 P(A)。务必问自己：“已知哪个事件发生了？”
2. **条件缺失**：使用贝叶斯公式前，必须确认 P(B)>0。若 P(B)=0，后验无定义。
3. **互斥与独立**：全概率公式依赖划分的互斥性，而非独立性。不要因 A1、A2 互斥就假设它们与 D 独立。
4. **归一性**：计算后务必检查所有后验之和是否为 1，这是检验计算错误的有效手段。
