## 核心讲解
推导起点是条件概率定义。当 P(B)>0 时，P(A|B) = P(A∩B) / P(B)，由此得 P(A∩B) = P(B) × P(A|B) [M11]。注意方向性：P(A|B) 与 P(B|A) 一般不等，后者需 P(A)>0。

对于有限事件 A1, …, An，若它们两两互斥且合并覆盖样本空间，且每个 P(Ai)>0，则事件 B 可分解为互不相交的 B∩Ai 之并。根据可加性，P(B) = Σi P(Ai)P(B|Ai) [M12]。此即全概率公式，要求划分完备且互斥，但互斥不意味着独立。

在 P(B)>0 条件下，贝叶斯公式为 P(Ak|B) = P(Ak)P(B|Ak) / Σi P(Ai)P(B|Ai) [M13]。分子是“先验×似然”，分母是全概率 P(B)。后验各项非负且和为 1，这是归一性的必然结果。

## 例题与检验
**基准案例**：设 A1、A2 为互斥完备产线，D 为次品。先验 P(A1)=0.6, P(A2)=0.4；似然 P(D|A1)=0.02, P(D|A2)=0.05。
计算全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
后验 P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375。
后验 P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
检验：0.375 + 0.625 = 1。
频数复核：假设 10000 件，A1 产 6000 件（次品 120），A2 产 4000 件（次品 200）。总次品 320。A1 来源次品占比 120/320 = 0.375，与公式一致。

**先验变化**：保持似然不变，改先验为 P(A1)=0.2, P(A2)=0.8。
新 P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
新 P(A1|D) = (0.2×0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091。
新 P(A2|D) = (0.8×0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909。
检验：0.091 + 0.909 = 1。
对比：A1 后验从 0.375 降至 0.091。说明先验变化显著影响后验，但推理逻辑及适用条件（互斥完备、正分母）保持不变。

## 易错点与小结
1. **方向混淆**：切勿将 P(D|A1) 当作 P(A1|D)。前者是似然（已知来源求次品率），后者是后验（已知次品求来源概率）。
2. **分母条件**：所有条件概率及贝叶斯公式均要求分母事件概率大于零。若 P(B)=0，公式无定义。
3. **归一检查**：计算后必须验证后验之和为 1，这是发现算术错误的有效手段。
4. **先验敏感性**：后验随先验变化而变，这反映了信息更新的过程，但不构成因果推断。材料未涵盖连续密度或重复观测独立性，此处不扩展。
