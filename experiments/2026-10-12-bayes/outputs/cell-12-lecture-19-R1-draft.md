# 大学概率：贝叶斯推导与先验敏感性（进阶任务）

## 学习目标
1. 从条件概率定义出发，严格推导全概率公式与贝叶斯公式，明确所有分母为正的前提。
2. 完成固定双产线基准计算，通过假设频数复核后验归一性。
3. 执行先验变化对照，分析先验调整对后验的影响，并区分 P(A|B) 与 P(B|A)。

## 本次学习安排
本次为进阶任务，基于通用适中讲解。首先回顾条件概率与乘法公式，接着推导全概率公式，最后推导贝叶斯公式。随后进行双产线基准计算与先验变化对照，重点检查计算逻辑与归一性。

## 核心讲解
设事件 A、B，当 P(B)>0 时，定义条件概率 P(A|B) = P(A∩B) / P(B)。由此可得乘法公式 P(A∩B) = P(B) × P(A|B) [M11]。注意 P(B|A) 需 P(A)>0，且 P(A|B) 与 P(B|A) 一般不相等，前者以 B 为条件限定范围，分母为 P(B)。

设 A1, ..., An 为样本空间的一个有限划分，即两两互斥且并集为全集。若每个 P(Ai)>0，则事件 B 可表示为互不相交的 B∩Ai 的并。根据概率可加性与乘法公式，全概率公式为 P(B) = Σi P(Ai) × P(B|Ai) [M12]。此处划分互斥不等于事件独立。

在 P(B)>0 条件下，由条件概率定义 P(Ak|B) = P(Ak∩B) / P(B)。分子利用乘法公式展开为 P(Ak) × P(B|Ak)，分母利用全概率公式展开为 Σi P(Ai) × P(B|Ai)。因此贝叶斯公式为 P(Ak|B) = [P(Ak) × P(B|Ak)] / [Σi P(Ai) × P(B|Ai)] [M13]。其中 P(Ak) 为先验，P(B|Ak) 为似然，P(Ak|B) 为后验。后验各项非负且和为 1。改变先验通常改变后验，但这不意味着因果结论。


### 条件与核查逻辑补充
反向概率 P(B|A) 只有在 P(A)>0 时才按交集比值定义。分母对应已知的条件事件，不能把 P(A|B) 的条件改成 A；若两事件概率都为正而交集为零，两个方向的条件概率也可同时为零。因此“一般不同”不等于“只能在两事件概率相等时相等”。这些判断直接由同一交集除以各自分母得到 [M11]。
划分表示每件产品恰好来自一条所列产线，不能遗漏来源或重复归类。观测到次品后，仍须保留同一个观测事件 D，分别考虑 D∩A1 与 D∩A2；互斥只用于把两项交集概率相加，不允许把产线与次品事件当作独立 [M12]。
后验归一的理由是：各项后验共享正分母 P(D)，各项分子之和由全概率公式恰好等于 P(D)，所以相加得到 1。但和为 1 只是一项必要核查，错误地互换两个后验也可能通过这一检查；仍须核对事件方向、先验、似然和交集分子 [M13]。
假设频数用于解释这个给定模型：分母是所有来源的次品数，分子是其中某一来源的次品数。它们不是实测生产数据，不能把课堂假设当成真实参数。调整先验时应同时调整各来源的假设件数，保持次品率不变，再重新计算总次品数；不能直接沿用旧分母。

## 例题与检验
**双产线基准**
设 A1、A2 为互斥完备的产线来源，D 为次品。先验 P(A1)=0.6, P(A2)=0.4；似然 P(D|A1)=0.02, P(D|A2)=0.05。
全概率：P(D) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。
后验：P(A1|D) = (0.6×0.02) / 0.032 = 0.012 / 0.032 = 0.375。
P(A2|D) = (0.4×0.05) / 0.032 = 0.020 / 0.032 = 0.625。
检查：0.375 + 0.625 = 1。
频数复核（假设 10000 件）：A1 产 6000 件，次品 120；A2 产 4000 件，次品 200。总次品 320。P(A1|D) = 120/320 = 0.375，P(A2|D) = 200/320 = 0.625。

**先验变化**
保持似然不变，改变先验为 P(A1)=0.2, P(A2)=0.8。
新全概率：P(D) = 0.2×0.02 + 0.8×0.05 = 0.004 + 0.040 = 0.044。
新后验：P(A1|D) = (0.2×0.02) / 0.044 = 0.004 / 0.044 ≈ 0.091。
P(A2|D) = (0.8×0.05) / 0.044 = 0.040 / 0.044 ≈ 0.909。
比较：A1 后验从 0.375 降至 0.091。推理仍需满足划分互斥完备、各先验为正及 P(D)>0 的条件。


新后验完整核对：P(A1|D)=1/11≈0.091，P(A2|D)=10/11≈0.909，精确和为 1；用先验变化后的假设频数，次品为 40 与 400 件，总计 440 件，40/440 与 400/440 分别对应这两个后验 [M13]。

## 易错点与小结
1. 混淆 P(A|B) 与 P(B|A)：前者分母是 P(B)，后者分母是 P(A)，二者数值通常不同。
2. 忽略正分母条件：使用条件概率及贝叶斯公式时，必须确保条件事件概率大于零。
3. 误将互斥当独立：划分事件两两互斥并不意味着它们相互独立，推导全概率时仅依赖互斥性与完备性。
4. 后验归一检查：计算后验后务必验证各项之和为 1，这是检验计算正确性的有效手段。
5. 先验敏感性：后验依赖于先验，改变先验会改变后验分布，但似然结构保持不变。
