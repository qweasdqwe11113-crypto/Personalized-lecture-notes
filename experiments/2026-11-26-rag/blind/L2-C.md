# 方程的解、移项与合并同类项

## 本课要点

**重点**　用等式性质说明移项要变号的依据，并用移项与合并同类项解一元一次方程。

**难点**　移项时忘记变号；合并同类项时漏掉字母或系数算错。

**本课不展开**　系数化为 1 时两边同除以负数的情形留到下一课时。

**学习目标**

1. 能把给定的值代入方程两边分别计算，判断它是否为方程的解（由前测1、例1、作业1检验）
2. 能说出移项的依据是等式性质 1，并在移项时正确改变符号（由例2、练1、作业2检验）
3. 能正确合并同类项，做到系数相加减而字母和指数不变（由练2、例3检验）
4. 能用移项和合并同类项解形如 $ax + b = cx + d$ 的一元一次方程，并代入检验（由例3、练3、练4、作业3、作业4检验）

**符号**　$x$ 表示未知数；$=$ 表示等号，表示左右两边的值相等

**学情与对策**　全班 20 人中约半数能判断一个数是否为方程的解，但条件变化后容易出错；移项时常忘记变号且说不出依据；7 人合并同类项基础薄弱，常把 $3x + 2x$ 写成 $5x^2$ 或丢掉字母。因此前测1先确认代入检验的操作，新授环节从等式性质出发讲清移项依据，例3和练4为已掌握的学生准备含负系数的变式。

- 方程与方程的解：用前测1让全班动手代入检验，快速暴露错误并纠正。（第 1 环节）
- 移项及其依据：从等式性质 1 推导移项过程，让学生自己说出变号原因。（第 3 环节）
- 合并同类项：用小例子逐步演示合并同类项，强调只加减系数、字母不变。（第 3 环节）

## 一、前测与回顾：判断方程的解（4 分钟）

- **屏幕**：前测1的题目和两个选项。
- **板书**：使方程左右两边相等的未知数的值叫做方程的解。
- **学生**：把给定的值代入方程，分别计算左右两边再比较。

### 前测1（基础） 判断方程的解

**题目**　判断下列各值是否为对应方程的解：(1) $x = 3$ 是否为方程 $2x - 1 = 5$ 的解；(2) $x = -1$ 是否为方程 $3x + 4 = 1$ 的解。

**解答**

1. 将给定值代入方程左边，计算结果。　——方程的解的定义：使方程左右两边相等的未知数的值。
2. 将给定值代入方程右边，计算结果。　——需要分别求出两边的值才能比较。
3. 比较左边与右边的值是否相等。　——相等则是解，不相等则不是解。

**答案**　(1) 是；(2) 是。

**检验**　(1) 左边 $= 2 \times 3 - 1 = 5$，右边 $= 5$，相等；(2) 左边 $= 3 \times (-1) + 4 = 1$，右边 $= 1$，相等。

**易错**　只代入左边算出结果就下结论，没有和右边比较。

- 让学生独立做前测1，限时 2 分钟。
- 巡视看学生是否把值代入方程两边分别计算。
- 请一名学生口述判断过程，教师板书关键步骤。

**提问 1**（基础）怎么判断 $x = 3$ 是不是方程 $2x - 1 = 5$ 的解？
- 预期回答：把 $x = 3$ 代入左边得 $2 \times 3 - 1 = 5$，右边也是 $5$，左边等于右边，所以是解。
- 常见错答：只看一边或者心算不写过程。
- 追问：如果代入后左边不等于右边说明什么？

**时间不够时**　只做第 (1) 问，第 (2) 问口头带过。

## 二、例题：验证方程的解（5 分钟）

- **屏幕**：例1的完整题目。
- **板书**：例：判断 $x=2$ 是否为 $3x+1=7$ 的解；左边 $= 3\times2+1 = 7$；右边 $= 7$；左边 $=$ 右边，是解。
- **学生**：模仿板书格式完成例1第 (2) 问的代入计算。

### 例1 验证方程的解

**题目**　判断下列各值是否为对应方程的解：(1) $x = 2$ 是否为方程 $3x + 1 = 7$ 的解；(2) $x = 4$ 是否为方程 $2x - 3 = 5$ 的解。

**解答**

1. 当 $x = 2$ 时，左边 $= 3 \times 2 + 1 = 7$，右边 $= 7$。　——代入求值，按运算顺序先乘后加。
2. 因为左边 $=$ 右边，所以 $x = 2$ 是方程的解。　——符合方程的解的定义。
3. 当 $x = 4$ 时，左边 $= 2 \times 4 - 3 = 5$，右边 $= 5$。　——代入求值，注意先乘后减。
4. 因为左边 $=$ 右边，所以 $x = 4$ 是方程的解。　——符合方程的解的定义。

**答案**　(1) $x = 2$ 是方程 $3x + 1 = 7$ 的解；(2) $x = 4$ 是方程 $2x - 3 = 5$ 的解。

**检验**　两次代入后左边都等于右边。

**易错**　计算 $3 \times 2 + 1$ 时先算 $2 + 1 = 3$ 再乘 $3$ 得 $9$，得出不是解的错误结论。

板演例1第(1)问时，把“左边 $=$”“右边 $=$”分行写，等号上下对齐。让学生看清代入后先算乘法再算加减的顺序。

学生独立完成例1第(2)问，限时 1.5 分钟。巡视重点看：是否写了“当 $x=4$ 时”，是否分别算出左右两边再比较。基础薄弱的学生若只写了一个数，提醒其分两行写出左边和右边的计算过程。

请一名学生口述第(2)问结果。将两问的结论并列指给学生看：两次代入后左边都等于右边，所以都是解。

讲：“判断一个数是不是方程的解，必须代入原方程，分别算出左边和右边的值再比较，不能只算一边。”

**时间不够时**　第 (2) 问改为口答。

## 三、新授：移项的依据与合并同类项（9 分钟）· 重点

- **屏幕**：从 $x + 3 = 7$ 到 $x = 7 - 3$ 的变形过程及等式性质 1 的文字。
- **板书**：等式性质 1：等式两边加（或减）同一个数，结果仍相等。；移项：把某一项从等号一边移到另一边，要变号。；合并同类项：系数相加减，字母和指数不变。
- **学生**：跟着教师的推导说出每一步的依据，回答提问。

在黑板上写出 $x + 3 = 7$。让学生独立想 10 秒，怎样把左边的 $+3$ 去掉，使等式仍然成立。

提问 1。学生如果只答“移项”，追问依据是什么；如果答不出，提示“等式两边同时做同一个运算”。

讲：“我们不是凭空把 $3$ 搬走，而是在等式两边同时减去 $3$。”

板书推导过程：
$$x + 3 - 3 = 7 - 3$$
左边 $+3$ 与 $-3$ 抵消，化简得：
$$x = 7 - 3$$
指着这一步指出：从结果看，左边的 $+3$ 到了右边变成了 $-3$。这就是移项。因为它的本质是两边同减一个数，所以符号必须改变。依据就是等式性质 1。

在黑板上写 $3x + 2x$，让全班口答等于多少。

提问 2。巡视时注意有没有人写 $5x^2$ 或丢掉字母写成 $5$。看到错解，先不纠正，请写对的学生说理由。

讲：“合并同类项只动系数，字母和指数照抄。$3x + 2x$ 就是把 $3$ 个 $x$ 和 $2$ 个 $x$ 合在一起，一共 $5$ 个 $x$，写成 $5x$。”

板书法则：合并同类项——系数相加减，字母和指数不变。

基础薄弱的学生若仍犹豫，让他们用数字验证：取 $x=2$，算出 $3 \times 2 + 2 \times 2 = 6 + 4 = 10$，而 $5 \times 2 = 10$，两边相等，说明 $3x + 2x = 5x$ 成立。学有余力的学生追问一句：$3x + 2y$ 能不能合并？为什么？（不能，字母不同，不是同类项。）

**学案笔记**（学生边听边填）

- 等式性质 1：等式两边加（或减）【同一个数（或同一个整式）】，结果仍相等。
- 移项时，被移动的项要【改变符号】。
- 合并同类项时，把【系数】相加减，字母和指数不变。

**提问 1**（基础）从 $x + 3 = 7$ 得到 $x = 7 - 3$，依据是什么？
- 预期回答：等式性质 1，等式两边同时减去 $3$。
- 常见错答：直接说移项但说不出依据。
- 追问：如果不减 $3$ 而加 $3$，等式还成立吗？

**提问 2**（基础）$3x + 2x$ 等于多少？为什么不是 $5x^2$？
- 预期回答：等于 $5x$，因为合并同类项只把系数相加，字母和指数都不变。
- 常见错答：写成 $5x^2$ 或 $6x$。

**时间不够时**　合并同类项的讲解缩短，直接用例2里的步骤带过。

## 四、例题：用移项解简单方程（5 分钟）

- **屏幕**：例2的题目和解题步骤框架。
- **板书**：$x + 5 = 12$；移项，得 $x = 12 - 5$；合并同类项，得 $x = 7$
- **学生**：口述每一步操作和依据，在学案上补全步骤。

### 例2 用移项解简单方程

**题目**　解方程：$x + 5 = 12$。

**解答**

1. 移项，得 $x = 12 - 5$。　——依据等式性质 1，等式两边同时减去 $5$，即把 $+5$ 从左边移到右边变为 $-5$。
2. 合并同类项，得 $x = 7$。　——计算 $12 - 5 = 7$。

**答案**　$x = 7$。

**检验**　把 $x = 7$ 代入原方程，左边 $= 7 + 5 = 12$，右边 $= 12$，左边等于右边。

**易错**　移项不变号，写成 $x = 12 + 5 = 17$。

读完例2，先让学生判断：要把常数项 $5$ 从左边移到右边。

教师板书写出“移项，得”，让学生口述右边应写成什么。学生说出 $12 - 5$ 后，追问一句：“为什么是减 $5$ 而不是加 $5$？”要求答出依据是等式性质 1。

最容易走错的地方是不变号，直接写成 $x = 12 + 5 = 17$。巡视时若看到这种写法，指着板书上的等式性质 1 问：“两边同时减去 $5$，右边的 $+5$ 应该变成什么？”让学生自己划掉错误符号改正。

合并同类项一步较简单，让学生齐答结果。

做完后让学生把 $x = 7$ 代回原方程检验，确认左边等于右边。

追问：“如果方程是 $x - 5 = 12$，移项后右边怎么写？”确定答案：$x = 12 + 5$，因为 $-5$ 移到右边要变为 $+5$。

**提问 1**（基础）移项这一步的依据是什么？
- 预期回答：等式性质 1。
- 常见错答：说成乘法或除法。

**时间不够时**　检验步骤改为课后完成。

## 五、例题：移项与合并同类项综合（6 分钟）· 重点

- **屏幕**：例3的题目。
- **板书**：$3x + 2 = x + 8$；移项，得 $3x - x = 8 - 2$；合并同类项，得 $2x = 6$；系数化为 1，得 $x = 3$
- **学生**：在学案上写出移项后的式子，完成合并和求解。

### 例3 移项与合并同类项综合

**题目**　解方程：$3x + 2 = x + 8$，并检验。

**解答**

1. 移项，得 $3x - x = 8 - 2$。　——依据等式性质 1，把右边的 $x$ 移到左边变为 $-x$，把左边的 $+2$ 移到右边变为 $-2$。
2. 合并同类项，得 $2x = 6$。　——左边 $3x - x = (3 - 1)x = 2x$，右边 $8 - 2 = 6$。
3. 系数化为 1，得 $x = 3$。　——依据等式性质 2，等式两边同时除以 $2$（除数不为零）。
4. 检验：把 $x = 3$ 代入原方程，左边 $= 3 \times 3 + 2 = 11$，右边 $= 3 + 8 = 11$，左边等于右边。　——用代入法验证所求的值是否为方程的解。

**答案**　$x = 3$。

**检验**　把 $x = 3$ 代入原方程，左边 $= 3 \times 3 + 2 = 11$，右边 $= 3 + 8 = 11$，左边等于右边。

**易错**　移项时 $x$ 没变号，写成 $3x + x = 8 - 2$，合并得 $4x = 6$，解出 $x = \frac{3}{2}$。

读完例3，先让学生判断：哪些项含 $x$，哪些是常数。明确目标——把含 $x$ 的项集中到等号左边，常数项集中到右边。

提问：“要把右边的 $x$ 移到左边，符号怎么变？”让学生口答，教师在黑板上写出移项后的式子 $3x - x = 8 - 2$。追问依据，确认学生说出“等式性质 1”。若有人写成 $3x + x = 8 - 2$，立刻停住，带全班回看等式性质 1：两边同时减去 $x$，右边消去 $x$，左边多出一个 $-x$，所以必须变号。

合并同类项这一步教师示范书写格式，让学生算出结果。重点盯左边的 $3x - x$：提醒 $x$ 的系数是 1，即 $(3 - 1)x = 2x$。巡视时若看到学生写成 $3x - x = 3$（丢掉字母）或 $3x^2$（指数相加），指着板书上的法则“系数相加减，字母和指数不变”让其当场订正。

讲：“记住两句话：过等号，要变号；合在一起，只动系数不动字母。”

系数化为 1 得 $x = 3$ 后，让全班一起代入原方程检验。左边 $= 3 \times 3 + 2 = 11$，右边 $= 3 + 8 = 11$，相等。

做完追问：“如果刚才移项时忘了把 $+2$ 变成 $-2$，会解出什么数？代回去能成立吗？”让学生实际算一遍：错解为 $3x - x = 8 + 2$，即 $2x = 10$，$x = 5$；代回原方程左边 $= 3 \times 5 + 2 = 17$，右边 $= 5 + 8 = 13$，不相等，说明忘变号一定出错。

对合并同类项薄弱的学生，在学案旁补写一行提示：$3x - x = (3 - 1)x$。对已掌握的学生，口头追加一问：“如果把含 $x$ 的项都移到右边、常数移到左边，最后结果一样吗？”让其课后用练4验证。

**时间不够时**　不能省。

## 六、解方程练习（13 分钟）· 重点

- **屏幕**：练1至练4的题目，做完一题显示一题答案。
- **学生**：独立解方程，完成后代入原方程检验。

### 练1（基础） 基础移项练习

**题目**　解方程：$x - 4 = 9$。

**解答**

1. 移项，得 $x = 9 + 4$。　——依据等式性质 1，把 $-4$ 移到右边变为 $+4$。
2. 合并同类项，得 $x = 13$。　——计算 $9 + 4 = 13$。

**答案**　$x = 13$。

**检验**　把 $x = 13$ 代入原方程，左边 $= 13 - 4 = 9$，右边 $= 9$，相等。

**易错**　移项不变号，写成 $x = 9 - 4 = 5$。

### 练2（基础） 基础合并同类项练习

**题目**　解方程：$7x - 3x = 16$。

**解答**

1. 合并同类项，得 $4x = 16$。　——$7x - 3x = (7 - 3)x = 4x$，系数相减，字母不变。
2. 系数化为 1，得 $x = 4$。　——依据等式性质 2，两边同时除以 $4$。

**答案**　$x = 4$。

**检验**　把 $x = 4$ 代入原方程，左边 $= 7 \times 4 - 3 \times 4 = 28 - 12 = 16$，右边 $= 16$，相等。

**易错**　合并时丢掉字母写成 $4 = 16$，或把指数相加写成 $4x^2 = 16$。

### 练3（基础） 含负数移项练习

**题目**　解方程：$5x + 1 = 3x + 7$，并检验。

**解答**

1. 移项，得 $5x - 3x = 7 - 1$。　——依据等式性质 1，含 $x$ 的项移到左边，常数项移到右边，都要变号。
2. 合并同类项，得 $2x = 6$。　——左边 $(5 - 3)x = 2x$，右边 $7 - 1 = 6$。
3. 系数化为 1，得 $x = 3$。　——两边同时除以 $2$。
4. 检验：把 $x = 3$ 代入原方程，左边 $= 5 \times 3 + 1 = 16$，右边 $= 3 \times 3 + 7 = 16$，左边等于右边。　——用代入法验证所求的值是否为方程的解。

**答案**　$x = 3$。

**检验**　把 $x = 3$ 代入原方程，左边 $= 5 \times 3 + 1 = 16$，右边 $= 3 \times 3 + 7 = 16$，相等。

**易错**　移项时 $3x$ 没变号，写成 $5x + 3x = 7 - 1$，合并得 $8x = 6$，解出 $x = \frac{3}{4}$。

### 练4（提高） 负系数移项练习

**题目**　解方程：$4x - 5 = 6x + 1$，并检验。

**解答**

1. 移项，得 $4x - 6x = 1 + 5$。　——依据等式性质 1，把 $6x$ 移到左边变为 $-6x$，把 $-5$ 移到右边变为 $+5$。
2. 合并同类项，得 $-2x = 6$。　——左边 $(4 - 6)x = -2x$，右边 $1 + 5 = 6$。
3. 系数化为 1，得 $x = -3$。　——两边同时除以 $-2$（除数不为零），注意正负号。
4. 检验：把 $x = -3$ 代入原方程，左边 $= 4 \times (-3) - 5 = -17$，右边 $= 6 \times (-3) + 1 = -17$，左边等于右边。　——用代入法验证所求的值是否为方程的解。

**答案**　$x = -3$。

**检验**　把 $x = -3$ 代入原方程，左边 $= 4 \times (-3) - 5 = -17$，右边 $= 6 \times (-3) + 1 = -17$，相等。

**易错**　合并 $4x - 6x$ 时算成 $2x$，导致 $2x = 6$，解出 $x = 3$。

让学生独立完成练1和练2，限时 5 分钟。

巡视时重点看三处：
- 练1移项后是否写成 $x = 9 + 4$。若看到 $x = 9 - 4$，指着等号问：“$-4$ 从左边移到右边，符号变了没有？”
- 练2合并同类项后是否写成 $4x = 16$。若看到 $4 = 16$，问：“$7x - 3x$ 里的 $x$ 去哪了？”；若看到 $4x^2 = 16$，问：“合并同类项时指数要不要变？”
- 做完的学生是否在代入检验。提醒没写的学生把求出的值代回原方程算一遍。

对合并同类项薄弱的学生，巡视到练2时若卡住，先让他口算 $7 - 3$ 等于几，再追问“字母 $x$ 照抄还是丢掉”，确认写出 $4x$ 后再放手让他继续。

讲评挑两类典型错法展示：
- 练1的错解：移项不变号，写成 $x = 9 - 4 = 5$。让写对的学生说出依据（等式性质 1），并当场验算：把 $x = 5$ 代入原方程，左边 $= 5 - 4 = 1 \neq 9$，说明 $x = 5$ 不是解，从而看出不变号的后果。
- 练2的错解：合并时丢掉字母写成 $4 = 16$，或把指数相加写成 $4x^2 = 16$。请出错的学生重新读一遍法则“系数相加减，字母和指数不变”，再自己改对。

已完成练1、练2且检验正确的学生，接着做练3和练4。其余学生先在学案上订正练1、练2，订正完再做练3。

讲评练3和练4时核对两题各自的步骤：
- 练3第 1 步移项得 $5x - 3x = 7 - 1$，第 2 步合并得 $2x = 6$，解出 $x = 3$。
- 练4第 1 步移项得 $4x - 6x = 1 + 5$，第 2 步合并得 $-2x = 6$，解出 $x = -3$。

核对无误后比较两题：两题都是先把含 $x$ 的项移到左边、常数项移到右边，但练4移项后左边是 $4x - 6x$，合并得 $-2x$，系数为负数。提问：“练4合并后得到 $-2x = 6$，下一步怎么做？”引导学生说出两边同除以 $-2$，强调除数不为零。若学生把 $4x - 6x$ 算成 $2x$，让他用具体数字验证：取 $x = 1$，$4 \times 1 - 6 \times 1 = -2$，而不是 $2$。

学有余力的学生做完练4后追问：“如果不把 $6x$ 移到左边，而是把 $4x$ 移到右边，结果一样吗？”让学生试算：移项得 $-5 = 6x - 4x + 1$，即 $-5 = 2x + 1$，再移项得 $-6 = 2x$，解出 $x = -3$，与练4答案一致，体会移项方向不同但结果相同。

**时间不够时**　练4留作课后作业。

## 七、课堂小结（2 分钟）

- **学生**：回顾本节课学到的三个关键操作。

- 让学生齐读小结要点。
- 提醒易错点：移项必变号，合并不丢字母。

**小结要点**

- 判断一个数是不是方程的解，就把它代入方程，看左边是否等于右边。
- 移项就是把某一项从等号一边移到另一边，依据是等式性质 1，移过去的项一定要变号。
- 合并同类项时只把系数相加减，字母和指数保持不变。
- 解完方程要把结果代回原方程检验。

## 课后作业

### 作业1（基础） 判断方程的解

**题目**　判断 $x = 5$ 是否为方程 $4x - 3 = 17$ 的解，写出完整的代入检验过程。

**解答**

1. 当 $x = 5$ 时，左边 $= 4 \times 5 - 3 = 17$，右边 $= 17$。　——代入求值。
2. 因为左边 $=$ 右边，所以 $x = 5$ 是方程的解。　——符合方程的解的定义。

**答案**　$x = 5$ 是方程 $4x - 3 = 17$ 的解。

**检验**　左边 $= 17$，右边 $= 17$，相等。

**易错**　计算 $4 \times 5 - 3$ 时先算 $5 - 3 = 2$ 再乘 $4$ 得 $8$，判断为不是解。

### 作业2（基础） 解方程基础

**题目**　解方程：$x + 8 = 15$。

**解答**

1. 移项，得 $x = 15 - 8$。　——依据等式性质 1，把 $+8$ 移到右边变为 $-8$。
2. 合并同类项，得 $x = 7$。　——计算 $15 - 8 = 7$。

**答案**　$x = 7$。

**检验**　把 $x = 7$ 代入原方程，左边 $= 7 + 8 = 15$，右边 $= 15$，相等。

**易错**　移项不变号，写成 $x = 15 + 8 = 23$。

### 作业3（提高） 解方程提高

**题目**　解方程：$6x - 4 = 3x + 11$。

**解答**

1. 移项，得 $6x - 3x = 11 + 4$。　——依据等式性质 1，含 $x$ 的项移到左边，常数项移到右边，都要变号。
2. 合并同类项，得 $3x = 15$。　——左边 $(6 - 3)x = 3x$，右边 $11 + 4 = 15$。
3. 系数化为 1，得 $x = 5$。　——两边同时除以 $3$。

**答案**　$x = 5$。

**检验**　把 $x = 5$ 代入原方程，左边 $= 6 \times 5 - 4 = 26$，右边 $= 3 \times 5 + 11 = 26$，相等。

**易错**　移项时 $-4$ 没变号，写成 $6x - 3x = 11 - 4$，合并得 $3x = 7$，解出 $x = \frac{7}{3}$。

### 作业4（提高） 解方程拓展

**题目**　解方程：$7x + 1 = 2x - 9$。

**解答**

1. 移项，得 $7x - 2x = -9 - 1$。　——依据等式性质 1，把 $2x$ 移到左边变为 $-2x$，把 $+1$ 移到右边变为 $-1$。
2. 合并同类项，得 $5x = -10$。　——左边 $(7 - 2)x = 5x$，右边 $-9 - 1 = -10$。
3. 系数化为 1，得 $x = -2$。　——两边同时除以 $5$。

**答案**　$x = -2$。

**检验**　把 $x = -2$ 代入原方程，左边 $= 7 \times (-2) + 1 = -13$，右边 $= 2 \times (-2) - 9 = -13$，相等。

**易错**　移项时 $+1$ 没变号，写成 $7x - 2x = -9 + 1$，合并得 $5x = -8$，解出 $x = -\frac{8}{5}$。
