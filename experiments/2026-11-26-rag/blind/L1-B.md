# 等式的两条性质

## 本课要点

**重点**　用等式两边同加同减、同乘同除的性质解只需一步变形的方程，并说出每一步的依据；解完方程后代回原方程检验

**难点**　除法时遗漏除数不为零的条件；只在等式一边做运算导致天平失衡

**本课不展开**　移项的简写留到后续课时；去分母和系数化为1的综合运用留到后续课时

**学习目标**

1. 能说出等式两边同加同减的依据，并用它解形如 x + a = b 或 x - a = b 的方程（由例1、练1、作业1检验）
2. 能说出等式两边同乘同除的依据及除数不为零的条件，并用它解形如 ax = b 或 x / a = b 的方程（由例2、练2、练3、作业2、作业3检验）
3. 解完方程后能把结果代回原方程进行检验（由例1、例2、练1、练2、练3、作业1、作业2、作业3检验）

**符号**　$a = b$ 表示等式左右两边的量相等；$c$ 表示等式两边同时加、减、乘或除的同一个数或整式；$x$ 表示方程中的未知数

**学情与对策**　学生基础题正确但条件变化后易出错，能算出答案却说不清依据。这节课先用具体数字让学生口述理由，再过渡到字母表示；例1重点对比只在一边运算的错误写法，练2专门确认除法时是否记得除数不为零。

- 等式的性质：两边同加同减：用例1的错解对比，让学生指出只在一边减 5 为什么破坏平衡（第 3 环节）
- 等式的性质：两边同乘同除：用例2强调除以 c 时必须说明 c 不等于 0（第 4 环节）

## 一、前测与回顾：天平与等式（3 分钟）

- **屏幕**：天平左边放 x 和 3 个砝码，右边放 7 个砝码，天平水平
- **板书**：x + 3 = 7；两边同减 3；x = 4
- **学生**：观察天平图，在学案上写出等式和变形步骤

### 前测1（基础） 天平读等式

**题目**　一架天平处于平衡状态，左边托盘放着标有 $x$ 的物体和 3 个质量为 1 克的砝码，右边托盘放着 7 个质量为 1 克的砝码。写出天平对应的等式，并求出 $x$ 的值。

**解答**

1. 列出等式 $x + 3 = 7$　——天平平衡表示左右质量相等
2. 两边同时减去 3，得 $x = 7 - 3 = 4$　——等式的性质一：两边同减同一个数，等式仍成立

**答案**　$x = 4$

**检验**　将 $x = 4$ 代入，左边 $= 4 + 3 = 7$，右边 $= 7$，左右相等。

**易错**　只在左边去掉 3 个砝码，写成 $x = 7$，天平不再平衡。

- 让学生看屏幕上的天平图，写出对应的等式
- 问学生怎样让天平左边只剩 x，要求说出对两边做了什么
- 根据回答决定第 3 环节讲多细：若学生只说把 3 挪过去而不提两边同减，则第 3 环节从具体数字重新演示

**提问 1**（基础）要让天平左边只剩 x，两边应该怎么做？
- 预期回答：两边同时减去 3
- 常见错答：把左边的 3 直接拿走，右边不动
- 追问：如果只在左边拿走 3 个砝码，天平会怎样？

**时间不够时**　学生答对且能说出两边同减，直接进入第 2 环节

## 二、新授：等式的性质一：两边同加同减（6 分钟）· 重点

- **屏幕**：如果 a = b，那么 a + c = b + c，a - c = b - c
- **板书**：性质一：两边同加或同减同一个数或整式；结果仍是等式；a = b => a + c = b + c；a = b => a - c = b - c
- **学生**：听讲解，在学案上填写性质一的关键词

- 指着第 1 环节的天平图，让学生看屏幕：天平平衡时左右质量相等，对应等式 $x + 3 = 7$。讲：“等式就像这架平衡的天平，两边同时做一样的事，它才不会歪。”
- 写出字母表示：如果 $a = b$，那么 $a + c = b + c$，$a - c = b - c$。让学生对照天平理解：$c$ 就是两边同时加或减的同一个砝码数。
- 强调“两边”和“同一个”。在板书“性质一”下面画一条线，把“两”和“同一个”圈出来。指出学生之前在变式题里出错的原因：条件一变就忘了两边都要做，或者两边做的不一样。
- 提问 1。若学生答“为了算得快”，立刻回到天平：只在左边加 2 个砝码，右边不加，天平往哪边倒？让学生自己说出“不平衡了，等式就不成立了”。
- 让学生用自己的话复述这条性质。要求必须说出三个词：“两边”“同时”“同一个数或整式”。说不全就指着板书的圈注再补一次。

**学案笔记**（学生边听边填）

- 等式的第一条性质：如果 $a = b$，那么 $a + c$ = 【$b + c$】，$a - c$ = 【$b - c$】。
- 使用性质一时，必须保证等式【两】边都做同样的运算。

**提问 1**（基础）为什么必须两边同时加或同时减？
- 预期回答：保持天平平衡，也就是保持等式成立
- 常见错答：为了算得快
- 追问：如果只在左边加 2，右边不加，等式还成立吗？

**时间不够时**　复述环节省略，直接进入第 3 环节

## 三、例题：用性质一解方程（6 分钟）· 重点

- **屏幕**：例1的完整题干和解题步骤
- **板书**：x + 5 = 12；两边同减 5；x = 12 - 5；x = 7；检验：7 + 5 = 12
- **学生**：在学案上写出例1的步骤，口述每步的理由

### 例1 解加法型方程

**题目**　说出等式两边同加同减的依据，并解方程 $x + 5 = 12$，解完代回检验。

**解答**

1. 依据：等式的性质一，即如果 $a = b$，那么 $a - c = b - c$　——这是等式两边同减同一个数结果仍是等式的依据
2. 方程两边同时减去 5，得 $x + 5 - 5 = 12 - 5$　——利用性质一使左边只剩下 $x$
3. 化简，得 $x = 7$　——左边 $+5$ 与 $-5$ 抵消，只剩 $x$；右边 $12 - 5 = 7$

**答案**　依据是等式的性质一；$x = 7$

**检验**　将 $x = 7$ 代入原方程左边，$7 + 5 = 12$，等于右边，所以 $x = 7$ 是原方程的解。

**易错**　只在左边减 5，右边不变，写成 $x = 12$。代入检验：$12 + 5 = 17 \neq 12$，说明等式被破坏。


让学生在学案上独立写例1的步骤，限时 2 分钟。教师看学生第 1 步有没有写出“两边同时减去 5”，而不只是直接写 $x = 7$。

若学生只写了结果没写依据，先问：“左边原来有 $+5$，怎么让它消失？右边跟着做了什么？”引导学生补全例1 第 2 步的完整写法：$x + 5 - 5 = 12 - 5$。

讲评时把错解写在旁边：只在左边减 5，写成 $x = 12$。让学生自己代回检验：$12 + 5 = 17 \neq 12$，天平倾斜了，等式被破坏。对比正确步骤，确认必须两边同减。

学生在例1 第 3 步化简时容易漏写中间过程，要求保留 $12 - 5$ 再算出 7。

做完检验后追问：“如果方程是 $x + 5 = 5$，两边同减 5 之后 $x$ 等于几？”确定学生能处理结果为 0 的情况。

**提问 1**（基础）为什么要两边同时减去 5？
- 预期回答：为了让左边只剩下 x，同时保持等式成立
- 常见错答：因为 12 减 5 等于 7
- 追问：如果写成 x = 12，左边是 7 还是 12？

**时间不够时**　不能省

## 四、新授：等式的性质二：两边同乘同除（5 分钟）· 重点

- **屏幕**：如果 a = b，那么 ac = bc；如果 a = b 且 c ≠ 0，那么 a ÷ c = b ÷ c
- **板书**：性质二：两边同乘同一个数；或同除以同一个不为零的数；a = b => ac = bc；a = b, c ≠ 0 => a/c = b/c
- **学生**：听讲解，在学案上填写性质二的条件和结论

- 指着第 2 环节的板书，讲：“刚才我们让天平两边同时加减同一个数，天平仍然平衡。如果两边同时乘或除呢？”引出性质二的字母表示。
- 让学生看屏幕上的公式，在学案上填出 $ac = bc$ 和 $a \div c = b \div c$。
- 用具体数过渡：口述“如果 $3 = 3$，两边同乘 4，得 $12 = 12$；两边同除以 2，得 $1.5 = 1.5$”，确认学生理解后再回到字母。
- 圈出屏幕上 $c \neq 0$ 的条件，在此处停下来问提问 1。学生若答“因为零乘任何数都是零”，追问反例：$5 \times 0 = 3 \times 0$ 成立，但 $5 \neq 3$，说明除以零推不出原来的等式。
- 口头演示解 $4x = 20$：让学生说出 $4x$ 的含义是 4 乘 $x$，要只剩 $x$ 需做逆运算即除以 4，依据是性质二且 $4 \neq 0$，得到 $x = 5$。

**学案笔记**（学生边听边填）

- 等式的第二条性质：如果 $a = b$，那么 $ac$ = 【$bc$】；如果 $a = b$ 且 $c \neq 0$，那么 $a \div c$ = 【$b \div c$】。
- 使用除法时，除数必须满足的条件是【不为零】。

**提问 1**（基础）性质二中除法为什么要加 c 不等于 0 的条件？
- 预期回答：因为除以零没有意义
- 常见错答：因为零乘任何数都是零
- 追问：如果 c = 0，ac = bc 还能推出 a = b 吗？举一个反例。

**时间不够时**　口头演示省略，直接进入第 5 环节

## 五、例题：用性质二解方程（5 分钟）· 重点

- **屏幕**：例2的完整题干和解题步骤
- **板书**：-3x = 15；两边同除以 -3；x = 15 / (-3)；x = -5；检验：-3 × (-5) = 15
- **学生**：在学案上写出例2的步骤和检验过程

### 例2 解乘法型方程

**题目**　说出等式两边同乘同除的依据及除数不为零的条件，并解方程 $-3x = 15$，解完代回检验。

**解答**

1. 依据：等式的性质二，即如果 $a = b$ 且 $c \neq 0$，那么 $a \div c = b \div c$　——这是等式两边同除以同一个不为零的数结果仍是等式的依据
2. 方程两边同时除以 $-3$（$-3 \neq 0$），得 $\frac{-3x}{-3} = \frac{15}{-3}$　——利用性质二使左边只剩下 $x$，此处需确认除数 $-3$ 不为零
3. 化简，得 $x = -5$　——左边 $-3$ 与除以 $-3$ 抵消，只剩 $x$；右边 $15 \div (-3) = -5$

**答案**　依据是等式的性质二，除数 $-3 \neq 0$；$x = -5$

**检验**　将 $x = -5$ 代入原方程左边，$-3 \times (-5) = 15$，等于右边，所以 $x = -5$ 是原方程的解。

**易错**　忘记负号，两边除以 3 得 $x = 5$。代入检验：$-3 \times 5 = -15 \neq 15$。


让学生先在学案上独立写例2的步骤，教师看第 1 步是否写明“两边同除以 $-3$”以及是否标注 $-3 \neq 0$。

学生最容易在第 2 步丢负号，写成两边除以 3 得 $x = 5$。看到这种错法时不直接纠正，指着原方程问：“左边是 $-3$ 乘 $x$，要消掉 $-3$，应该除以 3 还是除以 $-3$？”让学生自己改过来。

第 3 步化简由学生口述结果，教师在板书区同步写下 $x = -5$。

检验环节教师示范格式：把 $x = -5$ 代入原方程左边，写出 $-3 \times (-5) = 15$，与右边比较，确认相等。让学生照此格式在学案上补全检验过程。

做完追问：“这里除以 $-3$ 时，$-3$ 是不是零？为什么必须说明它不为零？”等学生答出“除数不能为零”后，再追问一句：“如果方程是 $0 \cdot x = 15$，能两边除以 0 吗？”让学生体会条件不可省略。

**时间不够时**　不能省

## 六、当堂练习（12 分钟）

- **屏幕**：练1、练2、练3的题干依次显示
- **板书**：练1: x - 8 = 3；练2: x / 4 = -2；练3: 5x = 0
- **学生**：在学案上独立完成 3 道练习，每道写出步骤、依据和检验

### 练1（基础） 解减法型方程

**题目**　说出等式两边同加同减的依据，并解方程 $x - 8 = 3$，解完代回检验。

**解答**

1. 依据：等式的性质一，即如果 $a = b$，那么 $a + c = b + c$　——这是等式两边同加同一个数结果仍是等式的依据
2. 方程两边同时加上 8，得 $x - 8 + 8 = 3 + 8$　——利用性质一使左边只剩下 $x$
3. 化简，得 $x = 11$　——左边 $-8$ 与 $+8$ 抵消；右边 $3 + 8 = 11$

**答案**　依据是等式的性质一；$x = 11$

**检验**　将 $x = 11$ 代入原方程左边，$11 - 8 = 3$，等于右边。

**易错**　两边同时减去 8，写成 $x = 3 - 8 = -5$。代入检验：$-5 - 8 = -13 \neq 3$。


### 练2（基础） 解除法型方程

**题目**　说出等式两边同乘同除的依据，并解方程 $\frac{x}{4} = -2$，解完代回检验。

**解答**

1. 依据：等式的性质二，即如果 $a = b$，那么 $ac = bc$　——这是等式两边同乘同一个数结果仍是等式的依据
2. 方程两边同时乘 4，得 $\frac{x}{4} \times 4 = -2 \times 4$　——利用性质二使左边只剩下 $x$
3. 化简，得 $x = -8$　——左边除以 4 再乘 4 抵消；右边 $-2 \times 4 = -8$

**答案**　依据是等式的性质二；$x = -8$

**检验**　将 $x = -8$ 代入原方程左边，$\frac{-8}{4} = -2$，等于右边。

**易错**　两边同时除以 4，写成 $x = -2 \div 4 = -0.5$。代入检验：$\frac{-0.5}{4} = -0.125 \neq -2$。


### 练3（提高） 解结果为零的方程

**题目**　说出等式两边同乘同除的依据及除数不为零的条件，并解方程 $5x = 0$，解完代回检验。

**解答**

1. 依据：等式的性质二，即如果 $a = b$ 且 $c \neq 0$，那么 $a \div c = b \div c$　——这是等式两边同除以同一个不为零的数结果仍是等式的依据
2. 方程两边同时除以 5（$5 \neq 0$），得 $\frac{5x}{5} = \frac{0}{5}$　——利用性质二使左边只剩下 $x$，此处需确认除数 5 不为零
3. 化简，得 $x = 0$　——左边 5 与除以 5 抵消；右边 $0 \div 5 = 0$

**答案**　依据是等式的性质二，除数 $5 \neq 0$；$x = 0$

**检验**　将 $x = 0$ 代入原方程左边，$5 \times 0 = 0$，等于右边。

**易错**　认为 0 不能作为结果，或者两边除以 0，写成无意义。


- 让学生依次做练1、练2、练3，每道做完立刻讲评
- 练1讲评时要求学生说出两边同加 8 的依据
- 练2讲评时确认学生写了两边同乘 4，并问 4 是否为零
- 练3讲评时关注学生是否正确处理结果为 0 的情况，检验时代入验证

**提问 1**（提高）练2中两边同乘 4，依据是哪条性质？4 能不能换成 0？
- 预期回答：依据性质二，4 不为零所以可以乘；如果换成 0 就不能反过来除了
- 常见错答：依据性质一
- 追问：如果方程是 x / 0 = 3，这个方程有意义吗？

**时间不够时**　练3留作课后作业，课上只做练1和练2（至少 6 分钟）

## 七、小结（2 分钟）

- **屏幕**：两条性质的对比表格
- **板书**：性质一：同加同减，无条件；性质二：同乘，无条件；同除，除数≠0；解方程三步：变形→求值→检验
- **学生**：对照板书回顾两条性质，补全学案上的小结填空

- 让学生自己说出两条性质的区别，特别是除法的限制条件
- 总结解一步方程的流程：选性质、写依据、算结果、代回检验

**小结要点**

- 等式像天平，两边同时做相同的加减运算，天平仍然平衡，这就是性质一。
- 两边同时乘同一个数或除以同一个不为零的数，等式仍然成立，这就是性质二；除法一定要检查除数不为零。
- 解方程就是利用这两条性质，让未知数单独留在等式一边，算完后要把结果代回原方程检验。

**时间不够时**　教师直接念要点，不提问

## 课后作业

### 作业1（基础） 课后巩固加法型

**题目**　说出等式两边同加同减的依据，并解方程 $x + 9 = 2$，解完代回检验。

**解答**

1. 依据：等式的性质一，即如果 $a = b$，那么 $a - c = b - c$　——这是等式两边同减同一个数结果仍是等式的依据
2. 方程两边同时减去 9，得 $x = 2 - 9$　——利用性质一使左边只剩下 $x$
3. 计算，得 $x = -7$　——$2 - 9 = -7$

**答案**　依据是等式的性质一；$x = -7$

**检验**　将 $x = -7$ 代入原方程左边，$-7 + 9 = 2$，等于右边。

**易错**　只在左边减 9，右边不变，写成 $x = 2$。


### 作业2（基础） 课后巩固乘法型

**题目**　说出等式两边同乘同除的依据及除数不为零的条件，并解方程 $-6x = 18$，解完代回检验。

**解答**

1. 依据：等式的性质二，即如果 $a = b$ 且 $c \neq 0$，那么 $a \div c = b \div c$　——这是等式两边同除以同一个不为零的数结果仍是等式的依据
2. 方程两边同时除以 $-6$（$-6 \neq 0$），得 $x = \frac{18}{-6}$　——利用性质二使左边只剩下 $x$，此处需确认除数 $-6$ 不为零
3. 计算，得 $x = -3$　——$18 \div (-6) = -3$

**答案**　依据是等式的性质二，除数 $-6 \neq 0$；$x = -3$

**检验**　将 $x = -3$ 代入原方程左边，$-6 \times (-3) = 18$，等于右边。

**易错**　符号出错，两边除以 6 得 $x = 3$。代入检验：$-6 \times 3 = -18 \neq 18$。


### 作业3（提高） 课后挑战分数系数

**题目**　说出等式两边同乘同除的依据，并解方程 $\frac{2}{3}x = 4$，解完代回检验。

**解答**

1. 依据：等式的性质二，即如果 $a = b$，那么 $ac = bc$　——这是等式两边同乘同一个数结果仍是等式的依据
2. 方程两边同时乘 $\frac{3}{2}$，得 $x = 4 \times \frac{3}{2}$　——利用性质二，乘系数的倒数可使左边只剩 $x$
3. 计算，得 $x = 6$　——$4 \times \frac{3}{2} = \frac{12}{2} = 6$

**答案**　依据是等式的性质二；$x = 6$

**检验**　将 $x = 6$ 代入原方程左边，$\frac{2}{3} \times 6 = 4$，等于右边。

**易错**　两边除以 $\frac{2}{3}$ 时误算为 $4 \div \frac{2}{3} = 4 \times \frac{2}{3} = \frac{8}{3}$，颠倒了除以一个数等于乘它的倒数。
