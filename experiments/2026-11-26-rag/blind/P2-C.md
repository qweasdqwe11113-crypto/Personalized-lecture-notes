# 划分、全概率公式与贝叶斯公式

## 本课要点

**重点**　全概率公式的推导与计算；贝叶斯公式的推导与计算

**难点**　确认事件组构成样本空间的划分；区分先验概率与后验概率并正确代入公式

**本课不展开**　连续型随机变量的全概率公式与贝叶斯公式留作课后阅读

**学习目标**

1. 能判断一组事件是否构成样本空间的划分（由练1、作业1检验）
2. 能推导全概率公式并在给定划分下计算事件的概率（由练2、练5、作业2检验）
3. 能推导贝叶斯公式并计算后验概率（由练3、练4、练6、作业3检验）
4. 能用频数方法复核贝叶斯公式的计算结果并做归一检查（由练4、练6、作业4检验）

**符号**　$\Omega$ 表示样本空间；$A_i$ 表示划分中的第 $i$ 个事件；$B$ 表示所关心的事件；$P(A_i)$ 表示先验概率；$P(B \mid A_i)$ 表示在 $A_i$ 发生条件下 $B$ 发生的条件概率；$P(A_k \mid B)$ 表示在 $B$ 发生条件下 $A_k$ 发生的后验概率

## 一、前测与回顾：条件概率与互斥（4 分钟）

- **屏幕**：显示前测1的题干
- **学生**：独立完成前测1并写下步骤

### 前测1（基础） 乘法公式前测

**题目**　设 $P(A_1) = 0.3$，$P(B \mid A_1) = 0.4$，求 $P(A_1 \cap B)$。

**解答**

1. $P(A_1 \cap B) = P(A_1) \times P(B \mid A_1)$　——乘法公式，需 $P(A_1) > 0$
2. $= 0.3 \times 0.4 = 0.12$　——代入计算

**答案**　$P(A_1 \cap B) = 0.12$

**检验**　概率值在 0 到 1 之间，且不超过 $P(A_1) = 0.3$

**易错**　把乘法公式写成加法 $0.3 + 0.4 = 0.7$，导致概率超过 $P(A_1)$

- 让学生独立做前测1，限时 2 分钟
- 巡视看学生是否写出乘法公式
- 请一名学生报答案并说明依据

**提问 1**（基础）$P(A_1 \cap B)$ 等于什么？
- 预期回答：$P(A_1) \times P(B \mid A_1) = 0.3 \times 0.4 = 0.12$
- 常见错答：写成 $P(A_1) + P(B \mid A_1)$ 或漏乘
- 追问：乘法公式成立需要什么条件？

**时间不够时**　直接口答不写过程

## 二、新授：样本空间的划分（8 分钟）

- **屏幕**：显示划分的定义及例1的数据表格
- **板书**：定义：$A_1, A_2, \ldots, A_n$ 是 $\Omega$ 的划分；条件 1：两两互斥 $A_i \cap A_j = \emptyset$；条件 2：$\bigcup_{i=1}^n A_i = \Omega$；性质：$\sum_{i=1}^n P(A_i) = 1$
- **学生**：对照定义检查例1中三个事件是否构成划分

- 读划分的定义，板书两个条件。讲：“划分就是把样本空间切成若干块，每个样本点恰好落在其中一块里。”
- 用例1的数据逐条验证。先问学生：一件产品能不能同时来自两条产线？确认两两互斥。再问：有没有可能这批产品来自第 4 条产线？确认并集等于 $\Omega$。最后让学生口算 $0.2 + 0.2 + 0.6 = 1$，说明概率之和为 1 是检查完备性的第一步。
- 指出实际建模时划分常对应“来源”或“原因”，如例1中的三条产线。提醒学生：遇到新题先找类别，再看类别是否真的互不重叠且覆盖全部情形。
- 在提问 1 处停顿。若学生答“只要互斥就可以”，追问：缺的那部分概率意味着什么？引导学生说出“有遗漏的样本点不属于任何一个事件，不构成划分”。
- 对已掌握的 7 名学生，口头追加一个变式：若把例1中 $A_3$ 拆成 $A_{3a}$（产线 3 上午）和 $A_{3b}$（产线 3 下午），且 $P(A_{3a})=0.4$、$P(A_{3b})=0.2$，这四个事件是否仍构成划分？让学生快速判断并说明理由。

### 例1 验证样本空间的划分

**题目**　一批产品来自 3 条产线，记 $A_1, A_2, A_3$ 分别为产品来自第 1、2、3 条产线的事件。已知 $P(A_1) = 0.2$，$P(A_2) = 0.2$，$P(A_3) = 0.6$。判断 $A_1, A_2, A_3$ 是否构成样本空间 $\Omega$ 的一个划分。

**解答**

1. 一件产品只能来自一条产线，故 $A_1, A_2, A_3$ 两两互斥　——满足划分的第一个条件
2. 产品必来自三条产线之一，故 $A_1 \cup A_2 \cup A_3 = \Omega$　——满足划分的第二个条件
3. $P(A_1) + P(A_2) + P(A_3) = 0.2 + 0.2 + 0.6 = 1$　——先验概率之和为 1，验证完备性

**答案**　$A_1, A_2, A_3$ 构成样本空间 $\Omega$ 的一个划分

**检验**　概率之和为 1，且实际意义中三条产线覆盖全部来源

**易错**　只验证概率之和为 1 而不说明互斥性，若类别有重叠则不构成划分


**学案笔记**（学生边听边填）

- 设 $A_1, A_2, \ldots, A_n$ 是一组事件，若它们【两两互斥】且【它们的并等于整个样本空间】，则称为样本空间的一个划分。

**提问 1**（基础）如果 $P(A_1)+P(A_2)+P(A_3)=0.9$，这组事件能作为划分吗？
- 预期回答：不能，概率之和不等于 1，说明有遗漏
- 常见错答：认为只要互斥就可以
- 追问：缺的那部分概率意味着什么？

**时间不够时**　只讲定义和例1的验证，省略追问

## 三、新授：全概率公式的推导（8 分钟）· 重点

- **屏幕**：显示全概率公式的推导过程
- **板书**：$B = \bigcup_{i=1}^n (B \cap A_i)$；$P(B) = \sum_{i=1}^n P(B \cap A_i)$；$P(B) = \sum_{i=1}^n P(A_i) P(B \mid A_i)$；条件：$P(A_i) > 0$
- **学生**：在学案上补全推导的两个等号

- 在黑板或屏幕上画一个矩形表示样本空间 $\Omega$，用两条竖线把它切成三块，分别标为 $A_1, A_2, A_3$。再画一个横跨几块的椭圆表示事件 $B$。指图说明：$B$ 被切成了 $B \cap A_1$、$B \cap A_2$、$B \cap A_3$ 三小块。
- 讲：“划分把样本空间切成若干块，每个样本点恰好落在其中一块里，所以 $B$ 也能按这些块拆开。”让学生对照图形，在学案上写出等式 $B = (B \cap A_1) \cup (B \cap A_2) \cup (B \cap A_3)$。
- 提问：这三小块之间是什么关系？引导学生从图上看出它们两两互斥，因此可以直接用概率的可加性，得到第 1 个等号：$P(B) = P(B \cap A_1) + P(B \cap A_2) + P(B \cap A_3)$，即板书中的求和形式。
- 追问：每一项 $P(B \cap A_i)$ 怎么算？回顾前测1用到的乘法公式，指出需要条件 $P(A_i) > 0$ 才能写 $P(B \mid A_i)$。让学生把每一项替换成 $P(A_i) \times P(B \mid A_i)$，补全推导的第 2 个等号。
- 将两步合在一起，指着板书的最终公式强调适用条件：$A_1, A_2, \ldots, A_n$ 必须构成划分（两两互斥且并为 $\Omega$），且每个先验概率 $P(A_i) > 0$。类别有重叠或有遗漏时公式不成立。
- 结合例2的数据做合理性检查：$P(B \mid A_1) = 0.08$，$P(B \mid A_2) = 0.02$，加权平均的结果 $P(B)$ 一定介于 0.02 与 0.08 之间。告诉学生算完后用这个范围快速判断答案是否离谱。

**学案笔记**（学生边听边填）

- 全概率公式：$P(B)$ = 【$\sum_{i=1}^n P(A_i) P(B \mid A_i)$】，使用条件是 $A_1, \ldots, A_n$ 为划分且 【每个 $P(A_i) > 0$】。

**时间不够时**　推导保留，口头带过图形解释

## 四、例题：全概率公式的基础应用（10 分钟）

- **屏幕**：显示例2的题干和表格
- **板书**：$P(B) = 0.4 \times 0.08 + 0.6 \times 0.02$；$P(B) = 0.044$
- **学生**：在学案上跟着写出代入步骤并计算

### 例2 两条产线的次品率

**题目**　一批产品来自 2 条产线，$A_1, A_2$ 构成样本空间的划分。已知 $P(A_1) = 0.4$，$P(B \mid A_1) = 0.08$，$P(A_2) = 0.6$，$P(B \mid A_2) = 0.02$，其中 $B$ 表示取到次品。求 $P(B)$。

**解答**

1. 确认 $A_1, A_2$ 构成划分且 $P(A_1) > 0$，$P(A_2) > 0$　——全概率公式的使用条件
2. $P(B) = P(A_1) P(B \mid A_1) + P(A_2) P(B \mid A_2)$　——全概率公式
3. $= 0.4 \times 0.08 + 0.6 \times 0.02 = 0.032 + 0.012 = 0.044$　——代入数据计算

**答案**　$P(B) = 0.044$

**检验**　$0.044$ 介于 $0.02$ 与 $0.08$ 之间，符合加权平均的含义

**易错**　漏掉某一项只算 $0.4 \times 0.08 = 0.032$，忘记加上第二条产线的贡献

读完题后，先让学生判断 $A_1, A_2$ 是否构成划分。确认两条产线互斥且覆盖全部来源，且 $P(A_1)=0.4>0$、$P(A_2)=0.6>0$，满足全概率公式的使用条件。这一步让全班齐答，基础薄弱的学生跟着说出“互斥”和“完备”两个词即可。

板书代入过程时，教师写公式框架 $P(B) = P(A_1)P(B\mid A_1) + P(A_2)P(B\mid A_2)$，让学生口报数值，教师在黑板上填入：$0.4 \times 0.08 + 0.6 \times 0.02$。乘法部分让学生独立算出 $0.032$ 和 $0.012$，再求和得 $0.044$。

巡视时重点看两类错误：一是漏掉第二项只算 $0.4 \times 0.08 = 0.032$；二是把先验概率与条件概率对错位，写成 $0.4 \times 0.02 + 0.6 \times 0.08$。发现错位时，指着题目问：“$0.08$ 是谁的次品率？对应哪条产线的比例？”让学生自己把数字放回正确位置。

算出 $P(B)=0.044$ 后立刻做合理性检查。提问 1 在此处抛出。若学生答不出怎么判断，提示：“第一条产线次品率是 $0.08$，第二条是 $0.02$，总次品率能比 $0.08$ 还大吗？能比 $0.02$ 还小吗？”讲：“全概率公式本质是加权平均，结果一定被夹在最小和最大条件概率之间。”

追问环节，若学生回答“如果算出来是 $0.09$”，引导定位错因：$0.09$ 大于最大的条件概率 $0.08$，说明某一项乘大了或多加了一项，回头核对代入的数值。

学有余力的学生做完后追问一句：“如果把两条产线的产量比例互换，即 $P(A_1)=0.6, P(A_2)=0.4$，其他不变，$P(B)$ 会变大还是变小？”答案是变小，因为次品率低的产线权重增加了，计算得 $0.6 \times 0.08 + 0.4 \times 0.02 = 0.056$，仍介于 $0.02$ 与 $0.08$ 之间。

**提问 1**（基础）算出的 $P(B)=0.044$ 合理吗？怎么快速判断？
- 预期回答：合理，因为 0.044 介于最小次品率 0.02 和最大次品率 0.08 之间
- 常见错答：不做判断或认为必须等于某个条件概率
- 追问：如果算出来是 0.09，问题可能出在哪里？

**时间不够时**　不能省

## 五、例题：贝叶斯公式的推导与应用（12 分钟）· 重点

- **屏幕**：显示贝叶斯公式推导及例3的题干
- **板书**：$P(A_k \mid B) = \frac{P(A_k \cap B)}{P(B)}$；$= \frac{P(A_k) P(B \mid A_k)}{\sum P(A_i) P(B \mid A_i)}$；$P(B) = 0.033$；$P(A_1 \mid B) = \frac{0.003}{0.033} = \frac{1}{11}$
- **学生**：在学案上补全例3的三个后验概率计算

### 例3 三条产线的贝叶斯推断

**题目**　一批产品来自 3 条产线，$A_1, A_2, A_3$ 构成样本空间的划分。已知 $P(A_1) = 0.3$，$P(B \mid A_1) = 0.01$，$P(A_2) = 0.3$，$P(B \mid A_2) = 0.06$，$P(A_3) = 0.4$，$P(B \mid A_3) = 0.03$，其中 $B$ 表示取到次品。现取到一件次品，求它来自第 1 条产线的概率 $P(A_1 \mid B)$。

**解答**

1. $P(B) = 0.3 \times 0.01 + 0.3 \times 0.06 + 0.4 \times 0.03 = 0.003 + 0.018 + 0.012 = 0.033$　——先用全概率公式求分母
2. $P(A_1 \cap B) = P(A_1) P(B \mid A_1) = 0.3 \times 0.01 = 0.003$　——乘法公式求分子
3. $P(A_1 \mid B) = \frac{0.003}{0.033} = \frac{1}{11} \approx 0.0909$　——贝叶斯公式

**答案**　$P(A_1 \mid B) = \frac{1}{11} \approx 0.0909$

**检验**　同理 $P(A_2 \mid B) = \frac{0.018}{0.033} = \frac{6}{11}$，$P(A_3 \mid B) = \frac{0.012}{0.033} = \frac{4}{11}$，三者之和 $\frac{1}{11} + \frac{6}{11} + \frac{4}{11} = 1$，归一检查通过

**易错**　直接用 $P(B \mid A_1) = 0.01$ 当作 $P(A_1 \mid B)$，混淆了条件概率的方向


**推导贝叶斯公式（4 分钟）**

- 从条件概率定义出发，板书 $P(A_k \mid B) = \frac{P(A_k \cap B)}{P(B)}$。指出要求分母 $P(B)>0$。
- 分子用乘法公式改写：$P(A_k \cap B) = P(A_k) \times P(B \mid A_k)$，这里需要 $P(A_k)>0$。让学生口答例3中 $A_1$ 对应的分子数值，确认得到 0.003。
- 分母用全概率公式展开：$P(B) = \sum_{i=1}^n P(A_i) P(B \mid A_i)$。强调分母就是第 3 环节推导的结论，不是新东西。
- 把分子分母合在一起，写出完整的贝叶斯公式。

讲：“贝叶斯公式解决的是‘由结果推原因’的问题：已经观察到次品，反过来推断它来自哪条产线。”

- 提醒适用条件：事件组必须是样本空间的划分，各先验为正，且 $P(B)>0$。

**带做例3（8 分钟）**

读完题后，先让学生判断：题目给了哪些量，要求哪个量。确认已知三个先验和三个条件概率，求后验 $P(A_1 \mid B)$。

- 例3 第 1 步教师示范：在黑板左侧列出全概率公式的三项乘积，逐项算出 0.003、0.018、0.012，相加得 0.033。边写边说明这是分母。
- 例3 第 2 步让学生说：分子是哪一项？请一名学生报出 $P(A_1) \times P(B \mid A_1) = 0.003$。若有人直接用 $P(B \mid A_1)=0.01$ 当分子，立即纠正：条件概率方向反了，$P(B \mid A_1)$ 是“来自第 1 条产线的条件下是次品”的概率，不是交集的概率。
- 例3 第 3 步让学生独立算：把 0.003 除以 0.033，化简为 $\frac{1}{11}$。巡视时看基础薄弱的学生是否保留了分数形式再约分，避免过早取近似值导致误差。

算完后追问：“如果还要算 $P(A_2 \mid B)$ 和 $P(A_3 \mid B)$，分母需要重新算吗？”确定答案：不需要，分母都是同一个 $P(B)=0.033$，只需换分子。

让学有余力的学生在学案上继续算出另外两个后验并求和，验证 $\frac{1}{11}+\frac{6}{11}+\frac{4}{11}=1$。基础薄弱的学生只完成 $P(A_1 \mid B)$ 即可。

最后提问 1。若学生答不出归一检查，提示：所有来源的后验概率加起来应该等于多少？若有人答“只要大于 0 就行”，追问：如果和不等于 1，最可能哪里算错了？引导回到分母漏项或乘法算错。

**学案笔记**（学生边听边填）

- 贝叶斯公式：$P(A_k \mid B)$ = 【$\frac{P(A_k) P(B \mid A_k)}{P(B)}$】，其中分母 $P(B)$ 由 【全概率公式】 给出。

**提问 1**（基础）算完所有 $P(A_k \mid B)$ 后必须做什么检查？
- 预期回答：检查它们的和是否等于 1
- 常见错答：不检查或只检查是否为正数
- 追问：如果和不等于 1，最可能哪里算错了？

**时间不够时**　推导保留，例3只算一个后验其余课后完成

## 六、例题：贝叶斯公式的频数复核（6 分钟）

- **屏幕**：显示例4的题干
- **板书**：假设 10000 件；$A_1$: 4000 件, 次品 240 件；$A_2$: 6000 件, 次品 420 件；总次品 660 件
- **学生**：独立计算例4并用频数法验证

### 例4 贝叶斯公式的频数复核

**题目**　一批产品来自 2 条产线，$A_1, A_2$ 构成样本空间的划分。已知 $P(A_1) = 0.4$，$P(B \mid A_1) = 0.06$，$P(A_2) = 0.6$，$P(B \mid A_2) = 0.07$，其中 $B$ 表示取到次品。现取到一件次品，求它来自第 1 条产线的概率 $P(A_1 \mid B)$，并用假设 10000 件产品的频数进行复核。

**解答**

1. $P(B) = 0.4 \times 0.06 + 0.6 \times 0.07 = 0.024 + 0.042 = 0.066$　——全概率公式求分母
2. $P(A_1 \mid B) = \frac{0.024}{0.066} = \frac{4}{11} \approx 0.3636$　——贝叶斯公式
3. 假设 10000 件：$A_1$ 产 4000 件，其中次品 $4000 \times 0.06 = 240$ 件；$A_2$ 产 6000 件，其中次品 $6000 \times 0.07 = 420$ 件　——用频数还原各来源的次品数
4. 总次品 $240 + 420 = 660$ 件，来自 $A_1$ 的比例 $\frac{240}{660} = \frac{4}{11}$　——频数比与后验概率一致

**答案**　$P(A_1 \mid B) = \frac{4}{11} \approx 0.3636$，频数复核一致

**检验**　$P(A_2 \mid B) = \frac{0.042}{0.066} = \frac{7}{11} \approx 0.6364$，$\frac{4}{11} + \frac{7}{11} = 1$，归一检查通过

**易错**　频数复核时用总数 10000 做分母算比例，而不是用次品总数 660 做分母

让学生独立列式计算例4，限时 3 分钟。巡视时看学生是否先写出全概率公式求分母 $P(B)$，再代入贝叶斯公式求分子；重点看有没有人直接用 $P(B \mid A_1) = 0.06$ 当作后验概率。

发现学生算出 $P(A_1 \mid B)$ 后停笔，提示：“用假设 10000 件的方法验证一下你的答案。”

频数复核环节，基础薄弱的学生容易把分母写成总数 10000。看到这种错法，先问：“我们现在关心的是哪一批产品？”引导学生明确：已经观察到次品，所以只能在次品里找来源，分母必须是次品总数 660，而不是全部产品 10000。

学有余力的学生算完频数后追问：“如果假设总数是 20000 件，最后算出的比例会变吗？”让学生自己算一遍确认比例不变，理解频数复核的本质是用大数还原条件概率的比值关系。

讲评时挑两类答案对比：一类只写了公式计算结果，另一类补了频数表格。让写频数的学生报出各产线的次品件数（$A_1$ 产线 240 件、$A_2$ 产线 420 件），全班核对总次品 660 件，再看 $\frac{240}{660} = \frac{4}{11}$ 与公式结果一致。

**时间不够时**　改为口头讲解频数复核思路，不独立计算

## 七、当堂练习（40 分钟）· 重点

- **屏幕**：依次显示练1至练6的题干
- **学生**：独立完成 6 道练习，先做 basic 再做 advanced

### 练1（基础） 判断事件组是否为划分

**题目**　掷一枚骰子，样本空间 $\Omega = \{1,2,3,4,5,6\}$。设 $A_1 = \{1,2\}$，$A_2 = \{3,4\}$，$A_3 = \{5,6\}$。判断 $A_1, A_2, A_3$ 是否构成 $\Omega$ 的一个划分。

**解答**

1. $A_1 \cap A_2 = \emptyset$，$A_1 \cap A_3 = \emptyset$，$A_2 \cap A_3 = \emptyset$，两两互斥　——验证划分的第一个条件
2. $A_1 \cup A_2 \cup A_3 = \{1,2,3,4,5,6\} = \Omega$　——验证划分的第二个条件

**答案**　$A_1, A_2, A_3$ 构成 $\Omega$ 的一个划分

**检验**　每个样本点恰好属于一个 $A_i$，无遗漏无重复

**易错**　只看到并集等于 $\Omega$ 就下结论，未验证互斥性

### 练2（基础） 邮件分类的全概率

**题目**　某邮箱收到的邮件中，$A_1$ 表示正常邮件，$A_2$ 表示垃圾邮件，$A_1, A_2$ 构成划分。已知 $P(A_1) = 0.7$，$P(A_2) = 0.3$。事件 $B$ 表示邮件含关键词。已知 $P(B \mid A_1) = 0.1$，$P(B \mid A_2) = 0.8$。求 $P(B)$。

**解答**

1. $P(B) = P(A_1) P(B \mid A_1) + P(A_2) P(B \mid A_2)$　——全概率公式，$A_1, A_2$ 构成划分且先验为正
2. $= 0.7 \times 0.1 + 0.3 \times 0.8 = 0.07 + 0.24 = 0.31$　——代入计算

**答案**　$P(B) = 0.31$

**检验**　$0.31$ 介于 $0.1$ 与 $0.8$ 之间，合理

**易错**　把先验概率和条件概率的位置写反，算成 $0.1 \times 0.7 + 0.8 \times 0.3$ 虽然数值碰巧相同，但若项数多时容易对错位

### 练3（基础） 邮件分类的贝叶斯推断

**题目**　接练2的条件，现收到一封含关键词的邮件，求它是垃圾邮件的概率 $P(A_2 \mid B)$。

**解答**

1. $P(A_2 \cap B) = P(A_2) P(B \mid A_2) = 0.3 \times 0.8 = 0.24$　——乘法公式求分子
2. $P(A_2 \mid B) = \frac{0.24}{0.31} = \frac{24}{31} \approx 0.7742$　——贝叶斯公式，分母取自练2的 $P(B) = 0.31$

**答案**　$P(A_2 \mid B) = \frac{24}{31} \approx 0.7742$

**检验**　$P(A_1 \mid B) = \frac{0.07}{0.31} = \frac{7}{31}$，$\frac{24}{31} + \frac{7}{31} = 1$，归一检查通过

**易错**　用 $P(B \mid A_2) = 0.8$ 直接当作后验概率，忽略了先验概率的影响

### 练4（基础） 疾病检测的贝叶斯推断

**题目**　某疾病的患病率为 $P(A_1) = 0.01$，未患病为 $P(A_2) = 0.99$，$A_1, A_2$ 构成划分。检测呈阳性的概率：患者中 $P(B \mid A_1) = 0.95$，未患者中 $P(B \mid A_2) = 0.05$。若某人检测呈阳性，求其确实患病的概率 $P(A_1 \mid B)$。

**解答**

1. $P(B) = 0.01 \times 0.95 + 0.99 \times 0.05 = 0.0095 + 0.0495 = 0.059$　——全概率公式求分母
2. $P(A_1 \mid B) = \frac{0.0095}{0.059} = \frac{19}{118} \approx 0.1610$　——贝叶斯公式

**答案**　$P(A_1 \mid B) = \frac{19}{118} \approx 0.1610$

**检验**　$P(A_2 \mid B) = \frac{0.0495}{0.059} = \frac{99}{118}$，$\frac{19}{118} + \frac{99}{118} = 1$，归一检查通过

**易错**　认为检测准确率 0.95 就意味着阳性后患病概率也是 0.95，忽略了低先验概率的影响

### 练5（提高） 增加产线后的全概率

**题目**　工厂新增第 3 条产线后，$A_1, A_2, A_3$ 构成划分。已知 $P(A_1) = 0.3$，$P(B \mid A_1) = 0.05$，$P(A_2) = 0.5$，$P(B \mid A_2) = 0.04$，$P(A_3) = 0.2$，$P(B \mid A_3) = 0.10$。求 $P(B)$。

**解答**

1. $P(B) = 0.3 \times 0.05 + 0.5 \times 0.04 + 0.2 \times 0.10$　——全概率公式，三项求和
2. $= 0.015 + 0.020 + 0.020 = 0.055$　——代入计算

**答案**　$P(B) = 0.055$

**检验**　$0.055$ 介于最小条件概率 $0.04$ 与最大条件概率 $0.10$ 之间，合理

**易错**　漏掉第三项或先验概率之和不等于 1 时仍直接代入

### 练6（提高） 比较不同来源的后验

**题目**　接练5的条件，现取到一件次品，分别求它来自三条产线的后验概率 $P(A_1 \mid B)$，$P(A_2 \mid B)$，$P(A_3 \mid B)$，并指出哪条产线的嫌疑最大。

**解答**

1. $P(A_1 \mid B) = \frac{0.015}{0.055} = \frac{3}{11} \approx 0.2727$　——贝叶斯公式，分子为第一项
2. $P(A_2 \mid B) = \frac{0.020}{0.055} = \frac{4}{11} \approx 0.3636$　——贝叶斯公式，分子为第二项
3. $P(A_3 \mid B) = \frac{0.020}{0.055} = \frac{4}{11} \approx 0.3636$　——贝叶斯公式，分子为第三项

**答案**　(1) $P(A_1 \mid B) = \frac{3}{11} \approx 0.2727$；(2) $P(A_2 \mid B) = \frac{4}{11} \approx 0.3636$；(3) $P(A_3 \mid B) = \frac{4}{11} \approx 0.3636$，第 2 条和第 3 条产线的后验概率并列最大

**检验**　$\frac{3}{11} + \frac{4}{11} + \frac{4}{11} = 1$，归一检查通过

**易错**　只看条件概率 $P(B \mid A_3) = 0.10$ 最大就认为 $A_3$ 嫌疑最大，忽略了先验概率 $P(A_3) = 0.2$ 较小

**巡视与分层指导（前 20 分钟：练1至练4）**

发练习后要求全班先做练1至练4。这 4 道题覆盖划分判断、全概率计算和贝叶斯推断的基本操作，是本次课的核心落实环节。巡视时按题号重点看以下内容。

**练1的巡视与纠错**
看学生有没有写出 $A_1 \cap A_2 = \emptyset$、$A_1 \cap A_3 = \emptyset$、$A_2 \cap A_3 = \emptyset$ 这三行。只写“并集等于 $\Omega$”就下结论的，在卷面上画圈标记。基础薄弱的学生往往只验证了完备性而漏掉互斥性。看到这种解答时，当场问一句：“如果 $A_1=\{1,2,3\}$，$A_2=\{3,4,5\}$，$A_3=\{5,6\}$，它们的并也是 $\Omega$，能叫划分吗？”让学生自己发现元素 3 被重复计算了，从而补上互斥的验证步骤。学有余力的学生做完后，让他们思考：如果把 $A_3$ 改成 $\{5\}$，这组事件还满足划分的哪个条件、不满足哪个条件。

**练2的巡视与推导回顾**
看代入顺序。基础薄弱的学生容易把先验概率和条件概率的位置写反。虽然本题 $0.7 \times 0.1 + 0.3 \times 0.8$ 与 $0.1 \times 0.7 + 0.8 \times 0.3$ 数值相同，但要检查学生是否按 $P(A_i) P(B \mid A_i)$ 的顺序书写。看到写反的学生，让他停下来回忆第 3 环节的推导：全概率公式的第一步是把 $B$ 拆成两两互斥的部分 $B \cap A_i$，由可加性得 $P(B) = P(B \cap A_1) + P(B \cap A_2)$；第二步对每一项使用乘法公式，因为 $P(B \cap A_i) = P(A_i) \times P(B \mid A_i)$，这里要求 $P(A_i) > 0$。所以必须先写来源的概率 $P(A_i)$，再乘该来源下结果发生的条件概率 $P(B \mid A_i)$。让学生把这两步推导在草稿纸上重新写一遍，确认无误后再代数据。核对计算：$0.7 \times 0.1 = 0.07$，$0.3 \times 0.8 = 0.24$，相加得 $0.31$。算完后要求学生做合理性检查：$0.31$ 必须介于最小的条件概率 $0.1$ 与最大的条件概率 $0.8$ 之间，符合加权平均的含义。

**练3的巡视与提问时机**
看分母是否直接用了练2算出的 $P(B)=0.31$，而不是重新算或漏掉。分子只看有没有写成 $P(A_2 \cap B) = P(A_2) \times P(B \mid A_2) = 0.3 \times 0.8 = 0.24$。在学生写到这一步时停下来提问 1：“算完所有 $P(A_k \mid B)$ 后必须做什么检查？”等学生回答后，要求他们立刻把 $P(A_1 \mid B)$ 也算出来：分子为 $0.7 \times 0.1 = 0.07$，后验为 $\frac{0.07}{0.31} = \frac{7}{31}$。然后做归一检查：$\frac{24}{31} + \frac{7}{31} = 1$。如果和不等于 1，通常是分母算错了，或者漏掉了某个来源。看到没有做归一检查的学生，提醒他这是贝叶斯公式计算后的必要步骤。

**练4的巡视与纠错**
这是最容易出错的一题。巡视时重点看两点：一是分母 $P(B)$ 有没有把两项都加起来，即 $P(B) = 0.01 \times 0.95 + 0.99 \times 0.05 = 0.0095 + 0.0495 = 0.059$；二是算出 $P(A_1 \mid B) = \frac{0.0095}{0.059} = \frac{19}{118} \approx 0.1610$ 后有没有做归一检查。看到直接用 $0.95$ 当答案的，当场问：“患病率只有 0.01，检测阳性后患病概率真的能到 0.95 吗？”让学生自己发现忽略了低先验的影响。讲清贝叶斯公式解决的是“由结果推原因”的问题：已知各来源的比例和各来源下结果发生的概率，在观察到结果之后，重新评估它来自各个来源的可能性。要求做错的学生用频数法复核：假设 10000 人，患者 100 人中阳性 95 人，未患者 9900 人中阳性 495 人，总阳性 590 人，其中真正患病的只有 $\frac{95}{590} = \frac{19}{118}$。

**分层指导**
基础薄弱的学生卡在练2或练3时，先让他把题目里的“来源”和“结果”分别圈出来：哪几个是 $A_i$，哪个是 $B$，再对应到公式里的位置。实际问题中划分常常对应“来源”或“原因”，建模时先确认这些类别是否真的互不重叠并且覆盖了所有情形。学有余力的学生在第 15 分钟左右做完练4的，直接让他们做练5和练6，不用等全班。给他们的额外追问：“如果患病率从 0.01 提高到 0.5，其他条件不变，后验概率会怎么变？为什么？”

**巡视要点（后 20 分钟：练5、练6）**

**练5的巡视**
看三项求和有没有漏项。核对计算：$0.3 \times 0.05 = 0.015$，$0.5 \times 0.04 = 0.020$，$0.2 \times 0.10 = 0.020$，相加得 $0.055$。算完后同样要求做合理性检查：$0.055$ 必须介于最小条件概率 $0.04$ 与最大条件概率 $0.10$ 之间。看到漏掉第三项算成 $0.035$ 的学生，指出 $0.035$ 小于最小的条件概率 $0.04$，这就说明算错了。

**练6的巡视与比较**
看学生怎么判断“嫌疑最大”。如果只比较 $P(B \mid A_i)$ 就说第 3 条产线嫌疑最大，提醒他回头看练5里算出的三个分子：$A_2$ 和 $A_3$ 的分子都是 $0.020$，所以后验并列最大，均为 $\frac{4}{11} \approx 0.3636$。追问：“为什么 $P(B \mid A_3) = 0.10$ 最大，但后验不是最大？”确定的答案是：因为 $P(A_3) = 0.2$ 比 $P(A_2) = 0.5$ 小得多，乘积被拉平了。在拿两道题作比较之前，先核对各自的步骤：练5中三个乘积分别是 $0.015$、$0.020$、$0.020$，后验概率的分母相同，所以只需比较分子。做完后要求做归一检查：$\frac{3}{11} + \frac{4}{11} + \frac{4}{11} = 1$。

**集中讲评（最后 5 分钟）**

挑两类典型错误投影讲评，不逐题对答案。

第一类，划分验证不完整。投影一份只写了“并集等于 $\Omega$”没写互斥的练1解答。让全班口答缺了什么，板书补上 $A_i \cap A_j = \emptyset$。强调两两互斥保证不重复计算，完备保证没有遗漏。

第二类，混淆条件概率方向。投影一份练4中把 $P(B \mid A_1) = 0.95$ 直接当作 $P(A_1 \mid B)$ 的解答。带全班用频数复核：假设 10000 人，患者 100 人中阳性 95 人，未患者 9900 人中阳性 495 人，总阳性 590 人，其中真正患病的只有 $\frac{95}{590} = \frac{19}{118} \approx 0.1610$。强调 $P(A \mid B)$ 与 $P(B \mid A)$ 一般不相等，贝叶斯公式的分母是全概率公式算出的总概率，每次算完后验概率都要做归一检查，确保各项之和等于 1。

## 板书设计

**主板书**（整节课保留）

1. 划分的定义：两两互斥且并为 $\Omega$
2. 全概率公式：$P(B) = \sum_{i=1}^n P(A_i) P(B \mid A_i)$
3. 贝叶斯公式：$P(A_k \mid B) = \frac{P(A_k) P(B \mid A_k)}{P(B)}$
4. 归一检查：$\sum_{k=1}^n P(A_k \mid B) = 1$

## 课后作业

### 作业1（基础） 判断划分

**题目**　袋中有红球 3 个、白球 2 个、黑球 5 个。设 $A_1$ 为取到红球，$A_2$ 为取到白球，$A_3$ 为取到黑球。验证 $A_1, A_2, A_3$ 构成样本空间的划分，并写出各自的先验概率。

**解答**

1. 一次只能取到一个颜色的球，故 $A_1, A_2, A_3$ 两两互斥　——验证划分的第一个条件
2. $P(A_1) = \frac{3}{10} = 0.3$，$P(A_2) = \frac{2}{10} = 0.2$，$P(A_3) = \frac{5}{10} = 0.5$，和为 1　——验证划分的第二个条件

**答案**　$A_1, A_2, A_3$ 构成划分，$P(A_1) = 0.3$，$P(A_2) = 0.2$，$P(A_3) = 0.5$

**检验**　概率之和 $0.3 + 0.2 + 0.5 = 1$

**易错**　只验证概率之和为 1 而不说明互斥性

### 作业2（基础） 全概率计算

**题目**　接作业1的袋子，设 $B$ 为取到的球标有记号。已知 $P(B \mid A_1) = 0.2$，$P(B \mid A_2) = 0.5$，$P(B \mid A_3) = 0.1$。求 $P(B)$。

**解答**

1. $P(B) = P(A_1) P(B \mid A_1) + P(A_2) P(B \mid A_2) + P(A_3) P(B \mid A_3)$　——全概率公式，$A_1, A_2, A_3$ 构成划分且先验为正
2. $= 0.3 \times 0.2 + 0.2 \times 0.5 + 0.5 \times 0.1 = 0.06 + 0.10 + 0.05 = 0.21$　——代入数据计算

**答案**　$P(B) = 0.21$

**检验**　$0.21$ 介于最小条件概率 $0.1$ 与最大条件概率 $0.5$ 之间，合理

**易错**　漏掉某一项，例如只算前两项得 $0.16$

### 作业3（提高） 贝叶斯计算

**题目**　接作业2的条件，若取到的球标有记号，求它是白球的概率 $P(A_2 \mid B)$。

**解答**

1. $P(A_2 \mid B) = \frac{0.2 \times 0.5}{0.21} = \frac{0.10}{0.21} = \frac{10}{21} \approx 0.4762$　——贝叶斯公式

**答案**　$P(A_2 \mid B) = \frac{10}{21} \approx 0.4762$

**检验**　$P(A_1 \mid B) = \frac{0.06}{0.21} = \frac{2}{7}$，$P(A_3 \mid B) = \frac{0.05}{0.21} = \frac{5}{21}$，$\frac{6}{21} + \frac{10}{21} + \frac{5}{21} = 1$

### 作业4（提高） 频数复核贝叶斯

**题目**　接作业2的条件，假设袋中球扩大到 1000 个（保持比例不变），用频数方法复核作业3中 $P(A_2 \mid B)$ 的结果。

**解答**

1. 红球 300 个，有记号 $300 \times 0.2 = 60$ 个；白球 200 个，有记号 $200 \times 0.5 = 100$ 个；黑球 500 个，有记号 $500 \times 0.1 = 50$ 个　——按先验比例和条件概率算各类有记号的频数
2. 有记号的共 $60 + 100 + 50 = 210$ 个，其中白球占 $\frac{100}{210} = \frac{10}{21}$　——频数比等于后验概率

**答案**　频数复核得 $P(A_2 \mid B) = \frac{10}{21}$，与作业3一致

**检验**　与作业3的公式计算结果完全吻合
