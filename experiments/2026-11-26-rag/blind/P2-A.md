# 划分、全概率公式与贝叶斯公式

## 本课要点

**重点**　推导并应用全概率公式计算事件概率；推导并应用贝叶斯公式由结果反推原因

**难点**　确认一组事件是否构成样本空间的划分；区分全概率公式与贝叶斯公式的适用方向

**本课不展开**　连续型随机变量的全概率与贝叶斯公式留作课后阅读

**学习目标**

1. 能判断一组事件是否构成样本空间的划分（由前测1、作业1检验）

4. 能用归一检验和范围检验核查计算结果的合理性（由例2、例3、练3、练4、练6、作业3检验）

**符号**　$\Omega$ 表示样本空间；$A_i$ 表示划分中的第 $i$ 个事件；$B$ 表示所关心的目标事件；$P(A_i)$ 表示先验概率；$P(B \mid A_i)$ 表示在 $A_i$ 发生条件下 $B$ 发生的条件概率；$P(A_k \mid B)$ 表示观察到 $B$ 后 $A_k$ 的后验概率

## 一、前测与回顾：判断划分（4 分钟）

- **屏幕**：前测1题目及三个选项
- **学生**：独立完成前测1并举手示意选项

### 前测1（基础） 判断划分

**题目**　掷一枚骰子，样本空间 $\Omega = \{1, 2, 3, 4, 5, 6\}$。下列哪组事件构成 $\Omega$ 的划分？
(1) $A_1 = \{1, 2\}$，$A_2 = \{3, 4\}$；
(2) $A_1 = \{1, 2, 3\}$，$A_2 = \{4, 5, 6\}$；
(3) $A_1 = \{1, 2\}$，$A_2 = \{2, 3\}$，$A_3 = \{4, 5, 6\}$。

**解答**

1. 逐一检查两两互斥和完备性　——划分的两个必要条件

**答案**　(2)

**检验**　(2) 中 $A_1 \cap A_2 = \emptyset$ 且 $A_1 \cup A_2 = \Omega$

**易错**　选 (1)，只检查了互斥，没有发现 $A_1 \cup A_2 = \{1,2,3,4\} \neq \Omega$，不完备


- 让学生独立做前测1，限时 2 分钟
- 请 3 位选不同答案的学生说理由
- 指出只有同时满足互斥和完备才是划分

**提问 1**（基础）选项 (1) 为什么不是划分？
- 预期回答：缺少 $A_3$，三个事件的并不等于 $\Omega$，不完备
- 常见错答：只检查了互斥就认为是划分
- 追问：如果加上 $A_3 = \{3\}$ 呢？

**时间不够时**　直接给出答案，口头说明两个条件

## 二、新授：样本空间的划分（8 分钟）

- **屏幕**：划分的定义与示意图
- **板书**：定义：$A_1, A_2, \dots, A_n$ 是 $\Omega$ 的划分；条件 1：两两互斥 $A_i \cap A_j = \emptyset$；条件 2：完备 $\bigcup_{i=1}^n A_i = \Omega$；性质：$\sum_{i=1}^n P(A_i) = 1$
- **学生**：对照板书补全学案笔记

结合前测1的选项，用前测1中 (1) 和 (3) 的错误对比引出定义。

- **要点 1：从错例归纳两个条件。** 指着前测1的选项 (1) 说明：$A_1 \cup A_2 = \{1,2,3,4\} \neq \Omega$，漏掉了 5 和 6，不完备；指着选项 (3) 说明：$A_1 \cap A_2 = \{2\} \neq \emptyset$，不互斥。只有选项 (2) 同时满足两两互斥且并为 $\Omega$。讲：“划分就像把一块蛋糕切成几块，既不能有重叠，也不能有剩余。”
- **要点 2：板书定义并强调缺一不可。** 在黑板写下 $A_i \cap A_j = \emptyset$（$i \neq j$）和 $\bigcup_{i=1}^n A_i = \Omega$。指出这两个条件是判断划分的唯一标准，少一个都不行。
- **要点 3：提问 1。** 在此处抛出提问 1。若学生答“互斥是为了让概率相加等于 1”，追问：如果不互斥，事件 $B$ 拆开后各部分还能直接用加法公式求概率吗？引导学生认识到互斥保证每个样本点只被计算一次，完备保证没有遗漏。
- **要点 4：推导性质与拆分。** 由完备性得 $\sum_{i=1}^n P(A_i) = 1$，提醒这是检查先验概率是否写对的第一步。再写出任意事件 $B$ 的拆分：$B = \bigcup_{i=1}^n (B \cap A_i)$。因为 $A_i$ 两两互斥，所以 $B \cap A_i$ 也两两互斥，从而 $P(B) = \sum_{i=1}^n P(B \cap A_i)$。这一步是后续全概率公式的基础。
- **要点 5：联系实际问题。** 说明建模时划分常对应“来源”或“原因”，如产品来自哪条产线、病人是否患病。拿到题目先确认这些类别是否真的互不重叠并且覆盖了所有情形。
- **要点 6：核对学案填空。** 让学生对照板书补全学案上的两处填空。巡视时看基础薄弱的 7 名学生是否准确填出“两两互斥”和“它们的并等于整个样本空间”，以及第二处填空是否写出 $B \cap A_i$。对已掌握的 7 名学生口头追加一问：如果去掉完备性只保留互斥性，$\sum_{i=1}^n P(A_i)$ 还一定等于 1 吗？

**学案笔记**（学生边听边填）

- 设 $A_1, A_2, \dots, A_n$ 是一组事件，若它们【两两互斥】且【它们的并等于整个样本空间】，则称为样本空间的一个划分。
- 任何事件 $B$ 都可以按划分拆成两两互斥的部分：$B = \bigcup_{i=1}^n (B \cap A_i)$，因此 $P(B) = \sum_{i=1}^n P(\text{【}B \cap A_i\text{】})$。

**提问 1**（基础）为什么要两两互斥？
- 预期回答：保证每个样本点只被计算一次，不重复
- 常见错答：互斥是为了让概率相加等于 1
- 追问：如果不互斥，$B$ 拆开后各部分还能直接用加法吗？

**时间不够时**　跳过提问，直接给出定义和性质

## 三、例题：全概率公式的推导与应用（18 分钟）· 重点

- **屏幕**：例1完整题干与求解过程
- **板书**：全概率公式：$P(B) = \sum_{i=1}^n P(A_i)P(B \mid A_i)$；例1计算过程；$P(B) = 0.2 \times 0.05 + 0.2 \times 0.07 + 0.6 \times 0.08 = 0.072$
- **学生**：跟随板演记录步骤，回答每步依据

### 例1 三产线次品率

**题目**　某工厂有 3 条产线生产同一种产品，产量分别占总产量的 $20\%$、$20\%$、$60\%$。设 $A_i$ 表示产品来自第 $i$ 条产线（$i=1,2,3$），$B$ 表示取到的产品是次品。已知各产线的次品率分别为 $P(B \mid A_1) = 0.05$，$P(B \mid A_2) = 0.07$，$P(B \mid A_3) = 0.08$。求从全部产品中任取一件是次品的概率 $P(B)$。

**解答**

1. 确认 $A_1, A_2, A_3$ 构成 $\Omega$ 的划分，且 $P(A_1)=0.2$，$P(A_2)=0.2$，$P(A_3)=0.6$　——使用全概率公式的前提条件
2. $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2) + P(A_3)P(B \mid A_3)$　——全概率公式
3. $P(B) = 0.2 \times 0.05 + 0.2 \times 0.07 + 0.6 \times 0.08 = 0.01 + 0.014 + 0.048 = 0.072$　——代入数据计算

**答案**　$P(B) = 0.072$

**检验**　$0.072$ 介于最小次品率 $0.05$ 与最大次品率 $0.08$ 之间，符合加权平均含义

**易错**　漏掉某一项，例如只算两条产线得 $0.2 \times 0.05 + 0.2 \times 0.07 = 0.024$，未覆盖全部来源

**要点 1：从第 2 环节的拆分过渡到公式推导。**
指着板书上 $B = \bigcup_{i=1}^n (B \cap A_i)$ 的等式，说明因为 $A_1, A_2, \dots, A_n$ 构成划分，所以 $B \cap A_1, B \cap A_2, \dots, B \cap A_n$ 两两互斥。由概率的可加性，直接写出第一步：
$$P(B) = \sum_{i=1}^n P(B \cap A_i)$$

**要点 2：用乘法公式展开每一项。**
对求和号里的每一项 $P(B \cap A_i)$，使用乘法公式 $P(B \cap A_i) = P(A_i) \times P(B \mid A_i)$。在板书写出这一步时，在旁边标注“需要 $P(A_i) > 0$”。代入后得到全概率公式：
$$P(B) = \sum_{i=1}^n P(A_i)P(B \mid A_i)$$
讲：“全概率公式的含义就是加权平均，把目标事件按来源拆开，每种来源下发生的概率乘以该来源的比例，再全部加起来。”

**要点 3：结合例1第 1 步确认前提条件。**
读题后先不急于代数字，让学生判断 $A_1, A_2, A_3$ 是否满足使用公式的条件。巡视时看学生是否在草稿纸上验证了 $P(A_1)+P(A_2)+P(A_3)=0.2+0.2+0.6=1$。若有人直接跳过这步，提醒：类别有重叠或遗漏时公式不成立。

**要点 4：带做例1第 2 步和第 3 步。**
教师示范写出求和展开式 $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2) + P(A_3)P(B \mid A_3)$，让学生口述代入的数字。
学生在例1第 3 步最容易走错的地方是漏项或小数点错位。若看到只算两条产线得 $0.2 \times 0.05 + 0.2 \times 0.07 = 0.024$ 的错解，立刻叫停，问：“第三条产线的产品去哪了？”指出不完备的拆分不能直接用加法。带着全班核对计算：$0.2 \times 0.05 = 0.01$，$0.2 \times 0.07 = 0.014$，$0.6 \times 0.08 = 0.048$，三项之和为 $0.072$。

**要点 5：教给学生两种检验方法。**
算完后不要马上进入下一题，要求全体做范围检验：找出题目中最小的次品率 $0.05$ 和最大的次品率 $0.08$，确认 $0.072$ 介于两者之间。告诉学生如果算出的结果超出这个范围，一定是某一步乘错了或漏加了。

**要点 6：提问与分层处理。**
写完推导过程后提出提问 1。若学生回答“直接用了加法公式”，追问：“拆开后各项为什么可以直接相加？”引导其回到划分的互斥性质。
基础薄弱的学生若在代入数据时卡住，让其对照板书上的公式模板，先把 $P(A_i)$ 和 $P(B \mid A_i)$ 分别圈出来再相乘。学有余力的学生做完范围检验后，多问一句：“如果第三条产线的产量占比提高到 $0.8$，其余不变，总次品率会靠近哪个数？不用算，说出理由。”（预期回答：靠近 $0.08$，因为权重变大了。）

**学案笔记**（学生边听边填）

- 全概率公式：若 $A_1, \dots, A_n$ 是 $\Omega$ 的划分且 $P(A_i)>0$，则 $P(B) = \sum_{i=1}^n \text{【}P(A_i)\text{】} \times \text{【}P(B \mid A_i)\text{】}$。
- 使用条件：事件组必须【两两互斥】并且【完备】，各先验必须为正。

**提问 1**（基础）第一步把 $B$ 拆成 $B \cap A_i$ 的并，依据是什么？
- 预期回答：$A_1, A_2, A_3$ 构成划分，所以 $B$ 可以按划分拆开
- 常见错答：直接用了加法公式
- 追问：拆开后各项为什么可以直接相加？

**时间不够时**　推导过程口述，只板书公式和例1计算

### 练1（基础） 两产线次品率

**题目**　某工厂有 2 条产线，产量分别占 $40\%$ 和 $60\%$。设 $A_1$、$A_2$ 分别表示产品来自第 1、2 条产线，$B$ 表示取到次品。已知 $P(B \mid A_1) = 0.03$，$P(B \mid A_2) = 0.08$。求任取一件是次品的概率 $P(B)$。

**解答**

1. $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2)$　——全概率公式
2. $P(B) = 0.4 \times 0.03 + 0.6 \times 0.08 = 0.012 + 0.048 = 0.06$　——代入数据计算

**答案**　$P(B) = 0.06$

**检验**　$0.06$ 介于 $0.03$ 与 $0.08$ 之间

**易错**　把产量占比与次品率相乘时小数点错位，如 $0.4 \times 0.03 = 0.12$


### 练2（基础） 两箱取白球

**题目**　甲箱中有 3 个白球和 7 个黑球，乙箱中有 6 个白球和 4 个黑球。设 $A_1$ 表示选中甲箱，$A_2$ 表示选中乙箱，$B$ 表示取出白球。选中甲箱的概率 $P(A_1) = 0.5$，选中乙箱的概率 $P(A_2) = 0.5$。求取出白球的概率 $P(B)$。

**解答**

1. $P(B \mid A_1) = \frac{3}{10} = 0.3$，$P(B \mid A_2) = \frac{6}{10} = 0.6$　——由箱中白球比例得条件概率
2. $P(B) = 0.5 \times 0.3 + 0.5 \times 0.6 = 0.15 + 0.30 = 0.45$　——全概率公式

**答案**　$P(B) = 0.45$

**检验**　$0.45$ 介于 $0.3$ 与 $0.6$ 之间

**易错**　条件概率算错，如把甲箱白球概率写成 $\frac{3}{7}$

- **学生**：记录推导过程，参与归一检验的计算

### 例2 两箱取球溯源

**题目**　有两个箱子。甲箱中有 2 个红球和 4 个白球，乙箱中有 3 个红球和 3 个白球。设 $A_1$ 表示选中甲箱，$A_2$ 表示选中乙箱，$B$ 表示取出的球是红球。已知选中甲箱的概率 $P(A_1) = \frac{1}{3}$，选中乙箱的概率 $P(A_2) = \frac{2}{3}$。现从中任取一球，结果是红球，求该红球来自甲箱的概率 $P(A_1 \mid B)$。

**解答**

1. $P(B \mid A_1) = \frac{2}{6} = \frac{1}{3}$，$P(B \mid A_2) = \frac{3}{6} = \frac{1}{2}$　——由各箱中红球数与总球数之比得到条件概率
2. $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2) = \frac{1}{3} \times \frac{1}{3} + \frac{2}{3} \times \frac{1}{2} = \frac{1}{9} + \frac{1}{3} = \frac{4}{9}$　——全概率公式，作为贝叶斯公式的分母
3. $P(A_1 \mid B) = \frac{P(A_1)P(B \mid A_1)}{P(B)} = \frac{\frac{1}{9}}{\frac{4}{9}} = \frac{1}{4}$　——贝叶斯公式
4. $P(A_2 \mid B) = \frac{P(A_2)P(B \mid A_2)}{P(B)} = \frac{\frac{1}{3}}{\frac{4}{9}} = \frac{3}{4}$　——计算另一项后验用于归一检验

**答案**　$P(A_1 \mid B) = \frac{1}{4}$

**检验**　$P(A_1 \mid B) + P(A_2 \mid B) = \frac{1}{4} + \frac{3}{4} = 1$，归一检验通过

**易错**　把 $P(A_1 \mid B)$ 与 $P(B \mid A_1)$ 混淆，直接答 $\frac{1}{3}$


待核对：板书里写 $P(B)=0.054$、$P(A_1 \mid B)=\frac{1}{3}$、$P(A_2 \mid B)=\frac{2}{3}$，但例2的题干与步骤算出 $P(B)=\frac{4}{9}$、$P(A_1 \mid B)=\frac{1}{4}$、$P(A_2 \mid B)=\frac{3}{4}$，两处数值不一致。

**推导贝叶斯公式（约 4 分钟）**

承接第 2 环节划分的概念和第 3 环节全概率公式的结论，直接提问：“现在反过来，已经取到红球，想知道它来自甲箱的概率，该用什么？”让学生意识到方向变了：已知结果 $B$ 发生，要反推原因 $A_k$。

- 写出条件概率定义：$P(A_1 \mid B) = \frac{P(A_1 \cap B)}{P(B)}$。强调这一步要求 $P(B)>0$，本题中红球确实可能被取出，条件满足。
- 处理分子：用乘法公式把交集拆开，$P(A_1 \cap B) = P(A_1) \times P(B \mid A_1)$。提醒学生这里需要 $P(A_1)>0$，选中甲箱的概率为 $\frac{1}{3}>0$，成立。
- 处理分母：$P(B)$ 就是刚才用全概率公式算出的总概率。讲：“分母不是凭空来的，它就是所有来源贡献的总和。”
- 合并得到贝叶斯公式：

$$
P(A_k \mid B) = \frac{P(A_k) \times P(B \mid A_k)}{\sum_{i=1}^n P(A_i) \times P(B \mid A_i)}
$$

在此处提出提问 1。若学生答“分母是 $P(A_k)$”，立刻在黑板上试算：若分母误用 $P(A_1)=\frac{1}{3}$，则 $P(A_1 \mid B)=\frac{1/9}{1/3}=\frac{1}{3}$，再算 $P(A_2 \mid B)=\frac{1/3}{2/3}=\frac{1}{2}$，两项之和 $\frac{1}{3}+\frac{1}{2}=\frac{5}{6} \neq 1$，说明分母用错会导致后验之和不等于 1。

**板演例2（约 10 分钟）**

读完题先让学生判断方向：题目问“结果是红球，求来自甲箱的概率”，这是由果推因，用贝叶斯公式。

- 例2 第 1 步让学生口答。巡视时看是否有人把甲箱红球概率写成 $\frac{2}{4}$（只看了红白之差而没除以总数 6）。看到这种错误，指着题干“2 个红球和 4 个白球”问：“总共有几个球？条件概率的分母是什么？”
- 例2 第 2 步教师示范书写格式：先写全概率公式的结构，再代入分数，通分相加得 $P(B)=\frac{4}{9}$。强调这步的结果要保留分数形式，不要化成小数，否则后面做归一检验会凑不齐。
- 例2 第 3 步让学生接着算。分子已在第 2 步算过是 $\frac{1}{9}$，只需做除法 $\frac{1/9}{4/9}=\frac{1}{4}$。最容易走错的地方是忘记分子里的 $P(A_1)$，直接用 $P(B \mid A_1)=\frac{1}{3}$ 当分子。若发现学生这样写，让他回看推导第一步：分子必须是 $P(A_1 \cap B)$，而不是 $P(B \mid A_1)$。
- 例2 第 4 步让全班一起算 $P(A_2 \mid B)$，得 $\frac{3}{4}$。

做完追问：“这两个后验加起来等于多少？如果算出来不等于 1，问题出在哪里？”确定答案为 1；若不等于 1，通常是分母 $P(B)$ 算错或漏掉了某个来源。

**分层提示**

### 例3 三产线次品溯源

**题目**　沿用例1的情境和数据：3 条产线的产量占比为 $P(A_1)=0.2$，$P(A_2)=0.2$，$P(A_3)=0.6$，次品率为 $P(B \mid A_1)=0.05$，$P(B \mid A_2)=0.07$，$P(B \mid A_3)=0.08$，已算得 $P(B)=0.072$。现取到一件次品，求它分别来自 3 条产线的概率 $P(A_1 \mid B)$、$P(A_2 \mid B)$、$P(A_3 \mid B)$。

**解答**

1. $P(A_1 \mid B) = \frac{P(A_1)P(B \mid A_1)}{P(B)} = \frac{0.2 \times 0.05}{0.072} = \frac{0.01}{0.072} = \frac{5}{36}$　——贝叶斯公式，分子是第 1 条产线贡献的次品概率
2. $P(A_2 \mid B) = \frac{P(A_2)P(B \mid A_2)}{P(B)} = \frac{0.2 \times 0.07}{0.072} = \frac{0.014}{0.072} = \frac{7}{36}$　——同上
3. $P(A_3 \mid B) = \frac{P(A_3)P(B \mid A_3)}{P(B)} = \frac{0.6 \times 0.08}{0.072} = \frac{0.048}{0.072} = \frac{24}{36} = \frac{2}{3}$　——同上

**答案**　$P(A_1 \mid B) = \frac{5}{36}$，$P(A_2 \mid B) = \frac{7}{36}$，$P(A_3 \mid B) = \frac{2}{3}$

**检验**　$\frac{5}{36} + \frac{7}{36} + \frac{24}{36} = \frac{36}{36} = 1$，归一检验通过

**易错**　分母误用某个先验概率如 $P(A_1)=0.2$，得 $P(A_1 \mid B) = \frac{0.01}{0.2} = 0.05$，三项之和远大于 1


让学生独立列式 3 分钟。巡视时看三点：分母是否直接沿用例1的 $0.072$ 而非重算；分子是否写成 $P(A_k) \times P(B \mid A_k)$ 两项相乘，有无漏乘先验概率；三项后验是否全部列出。

请 1 名学生报出分母结果，确认是 $0.044$。若有人报成 $0.072$，提醒本题事件 $B$ 的定义与数据已更换，需重新用全概率公式计算。

板书三个后验的分数形式。基础薄弱的学生若卡在通分，提示先把小数比 $\frac{0.018}{0.044}$ 的分子分母同乘 1000 化为整数比再约分。带领全班通分验证后验之和为 1：$\frac{18}{44} + \frac{21}{44} + \frac{5}{44} = 1$。强调每次算完所有后验必须做归一检验，和不为 1 说明分母算错或漏掉某个来源。

学有余力的学生做完后追问：“对比先验概率 $P(A_1)=0.2$、$P(A_2)=0.3$、$P(A_3)=0.5$，观察后验概率的变化，哪个来源的后验相对先验上升了？为什么？”确定答案：$A_1$ 从 $0.2$ 升至约 $0.4091$，$A_2$ 从 $0.3$ 升至约 $0.4773$，因为它们的条件概率 $0.09$、$0.07$ 高于加权平均得到的总概率 $0.044$；$A_3$ 的条件概率 $0.01$ 最低，后验降至约 $0.1136$。

**时间不够时**　只算 $P(A_1 \mid B)$，其余口述

### 例4（提高） 零件合格率综合

**题目**　某车间有 2 台机床加工同一种零件。设 $A_1$ 表示零件由第 1 台机床加工，$A_2$ 表示零件由第 2 台机床加工，$D$ 表示取到的零件是合格品。第 1 台机床加工的零件占 $60\%$，合格率为 $P(D \mid A_1) = 0.95$；第 2 台机床加工的零件占 $40\%$，合格率为 $P(D \mid A_2) = 0.90$。
(1) 求任取一个零件是合格品的概率 $P(D)$；
(2) 若取到的零件是合格品，求它由第 1 台机床加工的概率 $P(A_1 \mid D)$。

**解答**

1. 确认 $A_1, A_2$ 构成划分，$P(A_1)=0.6$，$P(A_2)=0.4$，$P(A_1)+P(A_2)=1$　——使用全概率公式的前提条件
2. (1) $P(D) = P(A_1)P(D \mid A_1) + P(A_2)P(D \mid A_2) = 0.6 \times 0.95 + 0.4 \times 0.90 = 0.57 + 0.36 = 0.93$　——全概率公式
3. (2) $P(A_1 \mid D) = \frac{P(A_1)P(D \mid A_1)}{P(D)} = \frac{0.57}{0.93} = \frac{19}{31}$　——贝叶斯公式，分母已在第 (1) 问求出

**答案**　(1) $P(D) = 0.93$；(2) $P(A_1 \mid D) = \frac{19}{31}$

**检验**　$P(A_2 \mid D) = \frac{0.36}{0.93} = \frac{12}{31}$，$\frac{19}{31} + \frac{12}{31} = 1$，归一检验通过

**易错**　第 (2) 问重新算分母时四舍五入导致后验之和不等于 1，应保留精确值或分数运算


让学生默读例4题干，限时 30 秒。读完先判断两问的方向：第 (1) 问已知机床占比和合格率求总合格率，是由因求果；第 (2) 问已知取到合格品反推来自哪台机床，是由果推因。

此时抛出提问 1。若学生答错，直接指出两问方向不同，要求重新看题目中“已知”和“求”分别是什么，再作判断。

讲：“第 (1) 问是全概率公式，第 (2) 问是贝叶斯公式，而且第 (2) 问的分母就是第 (1) 问的答案，顺序不能颠倒。”

确认方向后让学生独立计算 4 分钟。巡视重点看两处：一是例4 第 1 步是否先验证 $A_1, A_2$ 构成划分且 $P(A_1)+P(A_2)=1$；二是例4 第 3 步算后验时是否直接引用第 (1) 问的精确值 $0.93$，而非四舍五入后的近似值。若看到学生把 $0.93$ 写成 $0.9$ 再去除，当场指出：用 $0.9$ 作分母算出的两个后验之和不等于 1，归一检验会失败。

请 1 名学生报出两问答案。核对例4 第 2 步 $P(D)=0.6 \times 0.95 + 0.4 \times 0.90 = 0.93$ 和例4 第 3 步 $P(A_1 \mid D) = \frac{0.57}{0.93} = \frac{19}{31}$。

追问一句如何对第 (2) 问做归一检验，要求学生说出具体操作并算出结果。

对基础薄弱的学生，提示先把两台机床的先验、条件概率列成两行再代入公式。对学有余力的学生多问一句：如果第 (1) 问算错成 $0.92$，第 (2) 问的后验之和还是 1 吗？让其体会分母错误会导致归一检验失效。

**提问 1**（基础）第 (1) 问和第 (2) 问分别是由因求果还是由果推因？
- 预期回答：第 (1) 问由因求果用全概率，第 (2) 问由果推因用贝叶斯
- 常见错答：两问都用贝叶斯
- 追问：如果只求第 (2) 问，能跳过第 (1) 问吗？

**时间不够时**　第 (1) 问口述结果，重点讲第 (2) 问

**题目**　袋中有编号 1 至 5 的 5 个球。判断下列各组事件是否构成样本空间 $\Omega = \{1,2,3,4,5\}$ 的划分，并说明理由。
(1) $A_1 = \{1,2\}$，$A_2 = \{3,4,5\}$；
(2) $A_1 = \{1,2\}$，$A_2 = \{3,4\}$；
(3) $A_1 = \{1,3\}$，$A_2 = \{2,3\}$，$A_3 = \{4,5\}$。

**解答**

1. (1) 检查互斥性和完备性　——划分的定义
2. (2) 检查互斥性和完备性　——划分的定义
3. (3) 检查互斥性和完备性　——划分的定义

**答案**　(1) 是划分，两两互斥且并为 $\Omega$；(2) 不是划分，$A_1 \cup A_2 = \{1,2,3,4\} \neq \Omega$，不完备；(3) 不是划分，$A_1 \cap A_2 = \{3\} \neq \emptyset$，不互斥

**检验**　只有 (1) 同时满足两个条件

**易错**　(2) 只看互斥不看完备就判断为划分


### 作业2（基础） 两厂次品率

**题目**　某产品由甲、乙两厂供应，甲厂供货占 $70\%$，乙厂供货占 $30\%$。设 $A_1$ 表示来自甲厂，$A_2$ 表示来自乙厂，$B$ 表示取到次品。甲厂次品率 $P(B \mid A_1) = 0.05$，乙厂次品率 $P(B \mid A_2) = 0.09$。求任取一件是次品的概率 $P(B)$。

**解答**

1. $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2)$　——全概率公式
2. $P(B) = 0.7 \times 0.05 + 0.3 \times 0.09 = 0.035 + 0.027 = 0.062$　——代入计算

**答案**　$P(B) = 0.062$

**检验**　$0.062$ 介于 $0.05$ 与 $0.09$ 之间

**易错**　把供货比例与次品率搞反，写成 $0.05 \times 0.7 + 0.09 \times 0.3$ 虽然数值相同但概念混淆，若数据不对称则会出错


### 作业3（提高） 疾病检测

**题目**　某疾病的患病率为 $P(A_1) = 0.01$，未患病的概率为 $P(A_2) = 0.99$，其中 $A_1$ 表示患病，$A_2$ 表示未患病。设 $B$ 表示检测结果为阳性。已知患者检测呈阳性的概率 $P(B \mid A_1) = 0.95$，未患病者检测呈阳性的概率 $P(B \mid A_2) = 0.05$。若某人检测结果为阳性，求他确实患病的概率 $P(A_1 \mid B)$。

**解答**

1. $P(B) = P(A_1)P(B \mid A_1) + P(A_2)P(B \mid A_2) = 0.01 \times 0.95 + 0.99 \times 0.05 = 0.0095 + 0.0495 = 0.059$　——全概率公式求分母
2. $P(A_1 \mid B) = \frac{P(A_1)P(B \mid A_1)}{P(B)} = \frac{0.0095}{0.059} = \frac{19}{118}$　——贝叶斯公式

**答案**　$P(A_1 \mid B) = \frac{19}{118} \approx 0.1610$

**检验**　$P(A_2 \mid B) = \frac{0.0495}{0.059} = \frac{99}{118}$，$\frac{19}{118} + \frac{99}{118} = 1$；患病率很低时即使检测阳性，真正患病的后验概率仍不高，符合直觉

**易错**　把 $P(A_1 \mid B)$ 等同于 $P(B \mid A_1) = 0.95$，忽略先验概率的影响
