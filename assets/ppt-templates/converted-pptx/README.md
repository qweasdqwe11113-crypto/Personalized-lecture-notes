## 转换方式

本机未安装 LibreOffice，使用已安装的 Microsoft PowerPoint 2024 转换。先在临时目录将 OTP 复制为 ODP 工作副本，仅将 ODF 的 `mimetype` 与 manifest 根媒体类型由 presentation-template 改为 presentation，其他条目保留原内容；再用 PowerPoint 打开并另存为标准 PPTX。此过程通过 PowerPoint 实际转换文件内容，不是把扩展名直接改成 PPTX。

输出保留原页面数量与尺寸，并保留可编辑的母版、版式、占位符。没有统一为 16:9，也没有将页面转成图片。

## 预览与检查

已检查 8 份 PPTX 的 ZIP、XML、页数、可读取的版式和占位符，核对原 OTP 的 SHA-256 未变化。每套的首张预览由 PowerPoint 临时填入中文示例后导出；示例文字未保存进 PPTX。仅检查这些预览，不代表所有版式、长文本及公式都经过验证。

`cinema` 的预览标题在深色胶片边框上对比度不足，接入前需调整标题颜色或位置。其他模板也需要按实际教学内容检查字体替换、长题干和公式。

**这些是转换完成的模板资产，尚未完成课堂类型到母版占位符的映射，也没有修改当前生成器、模板选择 UI 或运行中的服务。** 转换与生成器接入是两个独立步骤。
