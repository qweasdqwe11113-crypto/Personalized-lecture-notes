# 蓝白教学 · 内容自适应

项目默认的 16:9 课堂设计，ID `teaching-blue`。根据用户提供的「个性化讲义-创新实践汇报」参考字号层次、蓝白配色与信息组织，重新编写教学布局；未复制其业务正文、数据、图片或整页背景。

- `theme.json`：配色、尺寸、字体与版本，提交任务时冻结 SHA-256。
- `preview.png`：由项目新布局生成并经 PowerPoint 渲染的示例封面。
- 布局实现：`tools/ppt-kit/pptkit/classroom.py`，包括学习目标、概念、推导、对比、原生表格、流程、数据、练习、回顾等 10 种结构。

这是一组按内容填充的可编辑布局，不需要额外准备或转换 PPTX。字体依赖运行环境中的 Microsoft YaHei，项目不附带字体。社区 8 套模板的 CC0 声明只适用于对应模板，不涵盖用户提供的参考文件和 ppt-kit。

输入、检查、版本兼容与限制见 [接入说明](../../../docs/ppt-template-integration.md)。
