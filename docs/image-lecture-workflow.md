# 图片解析接入讲义生成

语言模型只接收文字。独立 VLM 读取图片并生成待核对的解析，选择后的解析随讲义输入冻结保存。

## 当前配置

```dotenv
VLM_BASE_URL=http://127.0.0.1:11434/v1
VLM_MODEL=qwen3.5:9b
VLM_API_KEY=local-ollama
```

文字生成沿用 `QWEN_*` 配置，embedding 沿用 `QWEN_EMBEDDING_*` 配置；VLM 不使用这两个通道的地址或密钥。系统设置页面可编辑三类模型，保存后需要重启。

## 操作

1. 在「上传资料」上传图片、PDF 或 DOCX。每份资料最多 10 MB、8 张图片。
2. 点击「图片识读」，预览图片并点击「使用本地 VLM 解析图片」。核对公式、数值、单位和无法确认项。
3. 回到讲义工作台，刷新「图片解析依据」，选择最多 4 条与教学目标相关的解析。
4. 选择 SQL 或向量检索并生成。原图只发给 VLM，语言模型接收课程材料和解析文字。
5. 讲义下方可查看本次使用的图片、解析、VLM 模型名和图片 SHA-256。正文用 `[V1]` 等引用图片解析，课程材料仍用 `[M编号]`。

解析存入本地 `.runtime/uploads.sqlite3`，包括规范化图片原始字节、VLM 完整请求与 SHA-256、请求及返回模型、解析文本、提示版本和时间。重做解析会新增记录，不覆盖旧解析。生成请求保存解析文字、来源、图片指纹和解析请求指纹，不包含图片 base64，也不包含 VLM 密钥。语言模型的输入结构版本为 `lecture-context-vision-v1`。

## 边界

- 此阶段为「视觉模型解析 → 语言模型编写讲义」，语言模型没有直接看图。
- PDF 只抽取内嵌图片；不渲染整页，不保证覆盖 PDF 矢量图、复杂图层或整页排版。DOCX 抽取 `word/media` 中可解码的图片。
- 旧上传记录需重新上传才能提取图片。文本资料的课程收录流程保持原样；选择图片解析不自动把它写入向量库。
- 图片解析和引用支持关系都需要教师核对，程序不会自动标记审核通过。解析可能遗漏、误读或与当前目标无关。
- 导出的讲义正文保留 `[V编号]`；图片与解析可在网页原稿和生成输入中追溯。本阶段没有向 DOCX/PDF 导出嵌入原图。
