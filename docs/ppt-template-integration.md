# PPT 技巧与模板的教学适配

本项目已经接入 8 套转换后的真实 PPTX 母版和 ppt-kit 版式引擎。生成窗口可选择模板，默认简洁浅色。原始 OTP 保留，转换清单为 `assets/ppt-templates/converted-pptx/conversion.json`。

## 实际生成链路

`lecture-ppt-v2` 生成课堂 JSON → `presentations.parse_deck` 校验 → `pptkit_export` 加载已选 PPTX → 使用原始母版的空白版式 → ppt-kit 分栏封面/左右分栏正文 → 缩放到母版安全区域 → 写入讲稿与来源 → 几何检查 → 可编辑 PPTX。

母版映射在 `demo/ppt_templates.py`，版本 `classroom-masters-v1`。保留原始尺寸、主题、背景和装饰，移除模板示例页，禁用工具封面的大背景色块。转换后的占位符有重复 idx 或缺失几何，故清理新页面的空占位符并用原生可编辑文本框填充。深色模板统一使用已验证的深底母版，技术办公避开铅笔和尺子，明亮蓝避开底部色带。

提交时冻结模板 ID、文件 SHA-256 和映射版本。下载时核对指纹，文件变化会明确报错。旧记录没有 `export_version` 时保留原 XML 导出器；没有模板 ID 的早期 ppt-kit 记录保留其默认版式。

验证使用固定测试内容：16 项 PPT 测试通过，8 套模板均用 20 页长标题/最大正文内容生成并检查，PowerPoint 实际打开并检查封面和内页。未据此验证真实模型的教学质量或 WPS 兼容性。

## 已采用的技巧

1. 先按学习目标规划整套页序，每页一个知识点或教学动作，再写要点，避免逐段切割讲义。
2. 模型只输出语义内容。坐标、字体、配色、母版和版式选择由程序控制，保持结构化契约。
3. 概念定义、完整例题条件和关键步骤放投屏，细致解释、例题答案、提问预期回答放教师讲稿。练习页保留必要题目条件并隐藏答案。
4. 标题直接点明知识对象或任务。有来源支持的结论才用结论式标题，不强迫概念页写商务口号。
5. 内容拥挤时先提炼和调整页内分工，在用户指定总页数内规划，不缩字号硬塞、不省略关键条件。

这些内容要求已写入 `demo/prompts/lecture-ppt-v2.md`；旧 v1 文件保留。课堂输出字段保持兼容，新生成任务使用已接入的渲染器，历史记录按冻结的版本导出。

## 不直接套用的原规则

| ppt-kit 原规则 | 本项目处理 |
| --- | --- |
| 每页正文 120–420 字，常规页推荐 180–340 字 | 保留课堂每页 1–4 条、总计不超过 180 字的上限，取消最低密度要求，详细内容进入讲稿 |
| 所有标题必须为论断句 | 定义、概念、练习可用准确主题标题，不编造结论 |
| 封面、目录、章节页的固定骨架 | 6–20 页课堂课件优先学习内容，不强制占页插入目录或章节扉页 |
| Hero 配额、非对称比例、相邻版式禁止相同 | 作为版式研发参考，不影响连续例题等合理教学安排，不设机械配额 |
| 通用固定字号和行距 | 后续遵循所选模板母版；中文长文本必须结合实际文本框高度检查 |
| JSON 中的 anti_pattern / role / rhythm | 开发参考，不加入现有课堂 JSON，避免破坏校验和历史记录 |

## 后续扩展版式的建议

当前所有模板都已接入分栏封面与左右分栏正文。下表中的表格、流程、图表等属于后续语义字段扩展建议，尚未接入模型输出。

| 模板 ID | 优先用途 | 可参考的 ppt-kit 版式 | 适配注意 |
| --- | --- | --- | --- |
| simple-clear | 默认讲课、概念与例题 | split_title_body、table_insight | 建议第一套适配，保持浅底可读性 |
| peter-river | 课程导入、分步骤讲解 | cover_split、flow_axis | 保留原模板主色和层次 |
| vivid-blue | 知识点、复习总结 | split_title_body、asym_two_col | 强调色用于关键条件，控制占比 |
| simple-dark | 深色投影、技术分享 | split_title_body、big_number_insight | 原工具默认白底，不能直接视为支持此模板；需检查反白和对比度 |
| notebook | 练习、学习笔记 | split_title_body | 避开侧边装饰，验证横线与公式是否干扰 |
| pencil | 学校课堂、活动课程 | cover_split、asym_two_col | 装饰不遮挡题干和选项 |
| technical-office | 理工课程、过程与对比 | flow_axis、table_insight、chart_insight | 只使用有资料支持的数据，图表保留单位 |
| cinema | 影视与媒体课程 | cover_split、split_title_body | 文字与图片避开胶片边框 |

## 新增模板或改版的检查步骤

1. 将选中的 OTP 在 LibreOffice 中另存为 PPTX，保留原文件，核对 4:3/16:9 和字体。转换不等于已适配。
2. 枚举转换后的母版、版式和占位符，分别给 cover/concept/example/question/summary 建立经过验证的映射。内容类型 `kind` 与视觉 `layout` 分开。
3. 渲染器从母版新建页面并填充可编辑文字，继续写入教师讲稿、来源与版本指纹。不让模型指定路径、坐标或执行内容。
4. 先跑契约和几何检查，再在 PowerPoint/WPS 渲染真实中文课程，检查公式、长标题、题干完整性、练习答案隐藏和字体替换。
5. 检查通过后加入模板白名单、生成窗口和回归验证。当前 8 套已有选择 UI；服务器不执行 OTP 转换。

模板授权见 `assets/ppt-templates/licenses/`。`ppt-kit` 的授权状态单独记录在 `tools/ppt-kit/README.md`，两者不能混同。
