## 讲义工作台

### 生成一份讲义

1. **选择备课与讲义对象**：备课列表只显示顶部所选课程的备课；讲义对象可选「全班」（按班级画像，见下文）或当前班级中的某名学生。预置课程为初中数学（一步 / 两步方程）和大学概率论（条件概率与贝叶斯，基础 / 进阶），各有一个演示班级：初中小林、小周、小陈，大学小许、小唐、小顾，均为虚拟数据。
2. **本次怎么讲**：授课时长 5—180 分钟，新授 / 巩固 / 纠错 / 复习，讲解详略，完整例题 0—6 道、课堂练习 0—10 道。按时长与详略给出篇幅建议，也可填写 400—6600 个目标汉字，允许约 20% 浮动，上限 8000。例如常规 45 分钟约 3600—5400 汉字。这只是写作要求，不保证实际课堂用时或篇幅达标。
3. **本次讲解安排**：按知识点列出诊断依据和建议讲法，可逐项修改，每项最多 400 字。观察时间缺失、证据超过 90 天或存在「保留原判断」的证据会提醒；未知状态不当作薄弱，修改不写回长期诊断。
4. **高级设置**：选择「使用学生画像」或「无画像对照」，以及材料取用方式（精确 SQL / 向量检索）。无画像模式不发送个体诊断、讲解安排和学生观察。
5. **图片解析依据**（选填，最多 4 条）与**备注**（选填，本次补充说明，随输入保存，不改写画像）。
6. 提交后进入后台队列，完成后显示讲义编号、用时与用量。

讲义面向教师授课，包含建议时间安排、板书步骤、课堂提问、预期回答、错误引导和练习参考答案，固定五个二级章节：学习目标、本次学习安排、核心讲解、例题与检验、易错点与小结。正文用 `[M编号]` 引用课程材料、`[V编号]` 引用图片解析、`[K编号]` 定位本次讲解安排。标记存在不代表调整已经落实。

### 阅读与追溯

- **阅读版本**：在原稿与 R1、R2 等修订之间切换。下载支持 Markdown、纯文本、HTML、Word，导出当前版本、审核状态和原始来源；「打印 / PDF」打印当前预览。
- **查看生成输入**：核对实际发送的消息、提示词版本、参数和用量，可下载输入 JSON。早期 #1—#5 没有完整输入，系统不补造。
- **画像对照**：比较生成时与当前的学生说明、知识状态、依据和讲解策略，可只看变化。
- **讲义比较**：选择同课程同目标的另一份讲义及版本，按章节对照差异。材料、模型、提示或参数不同会标注，不把差异自动归因于画像。
- 点击正文中的 `[M编号]` / `[V编号]` 打开保存时的来源快照，可转入「支持 / 不支持 / 不确定」的问题记录。

历史讲义按唯一课程编号恢复设置。「按原输入重试」复用旧请求字节，「重新生成」读取当前资料与画像。网页只显示最近 8 份讲义、10 条运行记录和 12 个后台任务，全部记录保存在数据库中。

### 按章节调整

打开讲义或修订后点击「按章节调整」，选择二级章节与展开 / 简化 / 更换例题 / 自定义要求，生成候选后对照前后内容，点击「采用并另存草稿」只替换该章节。候选有独立请求和 SHA-256，走同一后台队列，失败可按原输入重试。审核记录变化后会拒绝采用旧候选。

## 写作方式、公式与图

「高级设置」里有两项新选择，随输入一起冻结；不带这两项的旧请求和历史记录保持原样。

### 写作方式

- **先列大纲，再分章节写**（默认，`sectioned-v1`）：冻结的请求只要一份大纲（标题、统一的符号约定、五个章节各自的要点）。随后每个章节单独调用一次模型，各有自己的篇幅下限和上限（学习目标 5%、本次学习安排 10%、核心讲解 45%、例题与检验 30%、易错点与小结 10%），最后由程序拼成整篇。这是针对「一次写完整篇时篇幅只有要求的三分之一」做的改动。
- **自动重写一次**：某个章节如果结构不对（多写了别的章节、没有正文）、引用了不存在的来源编号，或篇幅不到本章节下限的 70%，程序会把上一次输出和具体问题发回去，要求重写一次。重写后仍有结构或引用问题，整份讲义记为失败并保留已写出的正文；只是篇幅仍偏短时保留较长的一稿，由篇幅检查如实提示。大纲两次都不合格时不报错，各章节按固定的章节说明写。
- **可追溯**：章节请求由冻结请求、冻结上下文（含当时的章节提示词和篇幅配额）与大纲推导，每次调用的请求 SHA-256、字数、用时和未通过原因保存在运行记录里，「查看生成输入」可以看到。「按原输入重试」沿用同一份冻结请求和章节提示词。
- **一次写完整篇**（`single`）：与原来相同的单次调用，只是改为流式返回。
- **代价**：分章节约 6 次模型调用，每次都带完整的材料与画像，输入 token 约为单次的 6 倍；模型并发为 1 时总用时也接近 6 倍。

### 公式、表格与图

- **LaTeX 公式与结构化图**（默认，`rich-v1`）：行内公式写在 `$…$` 中，独立公式写在 `$$…$$` 中，网页用随项目提供的 KaTeX 排版（不依赖外网）。可以使用 Markdown 表格。
- **图由程序画，不由模型画**：模型只在 ` ```figure ` 代码块里写出数据（JSON），程序校验后绘制。五种类型：概率树、数轴、等式变形、函数图像、柱状对比。程序会核对图自身的一致性——同一节点下的概率之和是否为 1、把解代回等式变形的每一步是否成立——并在图下和「讲义检查」里提示。图与正文是否对应仍需教师核对。
- **纯文本公式**（`plain`）：原来的 Unicode 纯文本格式。
- 「$5 和 $8」这类金额不会被当成公式：紧挨空格的 `$` 不作为公式定界符。

### 实时预览

生成时右侧显示模型正在写的内容，分章节时每个章节有「等待 / 写作中 / 重写中 / 完成」的状态。预览只用于显示，不保存；完成后以通过程序检查并保存的版本为准。服务重启后预览丢失，不影响已保存的记录。

### 新增的程序检查

新流程生成的讲义多三项检查，结果同样只是提示：

- **算式复算**：重算正文里能识别的纯数字等式（如 `0.6 × 0.02 + 0.4 × 0.05 = 0.032`），并把写出的解（如 `x = 5`）代回它前面的方程。四舍五入按写出的小数位数容差。识别不了的式子直接跳过，不猜测；可能误报。
- **结构化图**：每幅图能否绘制，数据是否自相一致。
- **公式标记**：`$` 是否成对出现。

### 导出

| 格式 | 公式 | 图 | 表格 |
| --- | --- | --- | --- |
| Word | 转成 Word 原生公式（可编辑）；不认识的命令保留原文 | 嵌入图片；本机没有中文字体时改为一行文字说明 | Word 表格 |
| 网页（HTML） | 保留 LaTeX 源码（导出文件不含脚本） | 内嵌矢量图 | HTML 表格 |
| 纯文本 | LaTeX 源码 | 一行文字说明 | 竖线分隔 |
| Markdown | 原文 | 原文（` ```figure ` 块） | 原文 |

需要排好版的公式时，用页面上的「打印 / PDF」或下载 Word。授课包里的教师手册同样支持公式和图。授课 PPT 仍使用纯文本公式，不含图。

## 批量生成与模型并发

- **批量生成**：工作台「为多名学生批量生成…」沿用左侧当前的备课副本、目标、授课设置和高级设置，为所选学生各提交一份。每名学生有自己的冻结输入、运行记录和讲义，使用各自画像的默认讲解安排（手动改过的安排只对单个学生有效，批量时不使用）。一次最多 60 人。窗口显示每份的状态，可直接打开已保存的讲义；关闭窗口不会中断任务。
- **模型并发**：`MODEL_CONCURRENCY`（1—8，默认 3）决定同一时间最多几个语言模型调用，讲义、出题、阅卷、PPT 共用。后台同时处理的任务数与它相同。分章节写作在有空闲额度时并行写多个章节，没有空闲时退回逐章顺序写。设为 1 即恢复「严格逐个调用」。
- **队列上限**：单份提交仍是小队列（并发数 + 3 个未完成任务）；批量提交可排到 80 个。
- **出题与课件的自动重试**：新提交的题组或课件如果没有通过程序校验（JSON 无效、题数不符、引用了不存在的编号等），会带着具体问题自动重试一次；第二次仍不合格则如实记为失败。

## 教师编辑与审核

正文修改始终另存为 R1、R2 等新版本，原稿、输入和材料快照保留。保存时填写记录者、理由、自报审核 / 修改用时（0 秒表示未记录）和状态。

1. 对已保存版本选中准确且唯一的原文，记录问题类型和依据；引用支持问题须选择原材料及支持 / 不支持 / 不确定的判断。
2. 编辑正文，核对五项教师检查表，逐条说明问题处理。标记「教师已审核」须确认全部检查项、说明全部问题并修正无效编号。
3. 修改正文或开始新一轮编辑会重置审核确认。遇到 409 冲突时先保留输入，重新读取最新记录再确认，防止覆盖他人判断。
4. 版本历史显示变动行号、内容、理由、状态和用时。后续新增的问题不改写旧版本保存时的审核判断。

现存 #2、#4 及大学 14 份样例的 16 份修订都是助手草稿，教师检查未代勾、用时未记录，不能据此声称教师批准或节省时间。

## 输入冻结、预算与质量检查

- **输入冻结**：请求字符串只序列化一次，先保存请求正文和 SHA-256，再发送相同的 UTF-8 字节。成功讲义与运行状态在同一事务提交。SHA-256 用于一致性校验，不是防篡改签名。密钥、认证头、服务地址和原始异常不进入记录。
- **提示词版本**：基础模板为 lecture-math-v3 / lecture-probability-v2 / lecture-general-v1，新流程追加 plan-v1，授课设置为 teaching-v2，输入结构为 lecture-context-teacher-v2。旧模板和每次实际系统消息不修改。详见 [demo/prompts/README.md](../demo/prompts/README.md)。
- **字符预算**：材料超过 16000 字符时按知识点轮流保留，并按目标选取原文片段，记录节选位置、原文 SHA-256 和未纳入的材料编号。教案上限 8000 字符，整体上下文上限 56000 字符，超出时拒绝发送并提示精简。字符预算不等于 token 数。
- **范围检查**：列出知识点与来源的关联，提醒自定义目标、缺材料、可能超范围等情况。词语匹配不理解否定，不证明完整覆盖。
- **程序检查**：标题、五个章节、汉字篇幅、引用标记与编号、资料关联；大学课程增加概率条件和已知错误表述提醒。无效 `[M]` / `[V]` 编号的讲义不会保存为成功。历史报告保留当时的检查版本和阈值。
- 工作台在正文上方显示检查摘要，可跳到完整的「讲义检查」面板。

## 课程、班级与学生

- **层级**：课程 → 班级 → 学生。每门课程有自己的备课、课程资料和班级；班级属于一门课程，有自己的班级特点、学生名单和班级资料。
- **顶部切换**：除生成记录与系统设置外，每页顶部都有「课程 › 班级」下拉框，讲义工作台、出题、阅卷、课程与班级页面都跟随切换。也可在「全部课程」（`#courses`）点课程卡片进入。选择记在本浏览器，打开其他课程的历史讲义时会自动切过去。
- **学生归属**：学生档案在各课程间共享（同一名学生可以同时上初中数学和大学概率论）；同一门课程中每名学生只属于一个班。把已在本课程其他班的学生加入本班时需勾选「转入本班」。移出班级只结束班级关系，档案、诊断和已生成讲义都保留。
- **新建**：在「课程」页新建课程；在课程的「班级」标签新建班级；在班级的「学生」标签新建学生、批量导入或添加已有学生（新学生自动加入本班）。
- **备课**：新建或复制的备课属于当前课程，对本课程所有班级的学生可用。知识点从课程的「知识点库」勾选（见下节）。旧数据库首次启动时，已有自建备课按原课程名与学段自动归入对应课程，没有课程名的归入「未命名课程」；这些旧备课仍对全部学生可用。

## 学生画像

- **档案**：管理姓名、年级、学习特点、长期薄弱点和诊断证据，保留修改历史。档案页显示所在的各课程班级，知识点诊断只列当前课程的知识点。「为该学生备课」切到当前课程中包含该学生的备课并读取上下文。
- **编辑学生画像**：在学生档案页点「编辑学生画像」，或在班级学生名单的卡片上点「编辑」，直接修改姓名、学生说明和学习特点，填写录入者与修改理由后保存。原内容进入档案页的「修改历史」；保存时若他人已改过，本次不写入，需重新打开编辑。不必删除后重新添加，已生成的讲义仍按生成时的画像记录。
- **记录诊断证据**：在档案页「知识点掌握情况」点「记录诊断证据」，录入某知识点的作业、测验、课堂观察或教师复核证据（任务、表现、观察时间、记录者），由教师确认新状态或保留原判断并填写理由。证据与判断在同一事务保存；模型生成永远不更新状态。版本冲突时本次不写入，需重新读取后确认。
- **批量导入**（班级 → 学生 → 批量导入）：导入到当前班级，下载 CSV 模板后填写。
  - 学生名单按姓名新建档案并加入本班；本班已有同名学生跳过，不覆盖；其他班有同名学生时仍新建，并在预览中提示。
  - 学习证据只匹配本班学生，需选择本课程的备课；每行写明来源、观察日期、「更新状态 / 保留原判断」和理由，与逐条录入走同一确认路径，同一知识点的多行按文件顺序生效。
  - 先预览、逐行核对再确认。任一行有误，或预览后名单、画像被他人修改，整批不导入。支持 UTF-8 与 Excel 默认的 GBK 编码，每次最多 300 行。
- 证据窗口显示最近 50 条证据，档案页显示最近 20 次画像修改；模型输入每个知识点最近 3 条证据。录入者为手填，没有登录认证。

## 班级画像与班级讲义

- **班级画像**（班级与画像 → 班级画像）：按知识点汇总班内每名学生经教师确认的掌握状态，显示分布条、各状态的学生名单和「需要重点关注」的学生。可按本课程某份备课筛选。班级状态是规则判断，不是诊断：已诊断学生中「需要补充」占 30% 及以上记为需要补充，「已掌握」占 70% 及以上记为已掌握，其余为部分掌握，无人诊断为未知。
- **班级特点**：教师填写的整体学情与课堂特点，修改需填写录入者和理由，保留历史；用于班级讲义。
- **班级讲义**：讲义对象选「全班」或在班级页点「为全班生成讲义」。模型收到班级特点、各知识点的人数分布和少量匿名证据样例，不含学生姓名和个人画像；讲法按全班情况分层，提示词另加 `prompts/lecture-class-v1.md`。保存的讲义不属于某名学生（记录中显示为「班级名（全班）」），不能做学生画像对照；配套出题沿用班级画像。超过一半学生未诊断、或班内同时有需要补充和已掌握的学生时，讲解安排会提醒。
- **班级出题**：出题页「参考对象」可选「全班」，按班级画像分层出题，同样不发送学生姓名。
- **批量生成**：「为班内学生逐个生成」默认列出当前班级的学生，每人一份独立讲义。

## 知识点库与知识点识别

- **知识点库**（课程 → 知识点库，`#materials/knowledge`）：一门课程的知识点由本课程所有备课共用，按章节分组显示，每个知识点列出资料片段、使用它的备课数和已诊断的学生数。学生诊断按知识点记录，所以在一份备课中记录的诊断，其他勾选同一知识点的备课也会读到。可新增、改名（使用它的备课同步显示新名称）、改章节或归档；归档的知识点不出现在勾选列表中，已有备课、诊断和历史讲义不变。章节按「第 N 章」的编号排序，没有编号的章节排在前面，未分章节的排在最后。
- **自动识别**：在课程或班级资料中上传有正文的文件后，系统自动识别知识点（资料行显示进度，也可点「识别知识点」或「重新识别」）。识别分两步：
  1. 程序把 PDF 按页、其他文件按标题和约 1600 字切成片段，去掉重复的页眉页脚，跳过目录页，并按「2.1.3」「第二章」「# 标题」这类编号标题找出章节结构；
  2. 模型（`prompts/knowledge-recognition-v1.md`，JSON 模式）依据片段正文给出细粒度的中文知识点，每个知识点对应一段页码范围。

  模型不可用或返回无法解析时，草稿只按编号标题给出，并在窗口里注明。
- **审核与确认**：识别结果只是草稿。在资料行或知识点库点「审核并确认」，逐条改名、调整页码范围、「并入上一条」、删除或新增，再确认。与知识点库同名的条目合并到已有知识点，不会重复建立。确认后每个知识点的那段资料（最多 12000 字，带「【第 N 页】」标记）写入 `materials`，来源记为 `upload:<编号>#p起-止`；班级资料识别出的片段只用于该班。已确认的资料可以查看并再次确认，同一片段只更新不重复。
- **勾选进备课**：备课的「知识点」改为按章节分组的勾选列表（可筛选，最多 20 个），勾选后该知识点的资料片段自动成为本备课的参考资料；下方「新增知识点」逐行填写的名称在保存时加入知识点库，与库中同名的直接沿用。复制或示例备课自带、不在库中的知识点列在「本备课已有」中。「收录到备课」仍可把整份资料补充给某个备课。
- **来源链接**：讲义的参考材料和知识点库中的来源可直接打开原 PDF 并跳到片段的起始页。
- **诊断窗口**：档案页的「记录诊断证据」按章节分组列出本课程知识点库中的知识点。
- 旧数据首次启动时，各备课已有的知识点按所在课程自动归入知识点库；复制备课产生的知识点仍是该备课专用，不进入知识点库。

## 课程资料与班级资料

- **备课副本**（课程 → 备课）：保存章节、教学目标、教案正文和知识点，课程与学段取自所属课程。副本不绑定学生，可复制后独立修改；复制会保留目标、教案和参考材料，并分配独立的知识点与材料编号。仅有目标和教案也能生成讲义，但会提示来源不足。
- **诊断身份**：复制的知识点通过 `knowledge_aliases` 沿用来源知识点的诊断，教师更新原诊断时副本读取同一证据。数学 / 概率副本保留专用提示与检查规则。同一课程中同名的知识点共用知识点库中的那一个；没有课程的旧备课保持原规则（同名不合并，改名建立新身份）。
- **上传位置**：在「课程 → 课程资料」上传的资料本课程所有班级共用；在「班级与画像 → 班级资料」上传的资料只属于该班。课程资料页同时列出各班专用资料并标注班级。课程划分之前上传的资料列在「未归类的旧资料」，点「归入本课程」后归档。
- **上传格式**：支持本地 TXT / MD / PDF / DOCX（每份最多 10 MB、20 万字符，PDF 最多 200 页）和公开网页、文档直链。原文件与正文保存在 `.runtime/uploads.sqlite3`。PDF 正文中的控制字符会被清除，方正排版教材（如人教版）里被读成「狓」「犃」的斜体字母会还原为 x、A；课件 PDF 中的康熙部首字形、数学斜体字母和 Wingdings 项目符号会还原为常用字符；扫描版 PDF 需先 OCR；网址导入不发送登录凭据，也不读取内网地址。
- **收录到备课**：上传本身不等于进入讲义：确认识别出的知识点后，资料片段随知识点进入备课；也可在资料行点「收录到备课」，或在备课详情的「添加参考资料」中选择本课程的备课、知识点和资料后才会写入 PostgreSQL 的 `materials`，此后可用于 SQL 取材。班级资料收录后只在为该班或班内学生生成时使用，其他班看不到；选择向量检索时自动建立索引。只有图片的资料通过「图片识读」使用。

## 材料取用方式与检索

1. **精确 SQL**（默认）：按所选知识点取全部关联材料，与历史讲义和 2026-10-12 对照实验一致。
2. **向量检索**：先召回所选知识点的全部片段（500 字符一块、重叠 80），再用本次目标（有画像时附加薄弱知识点）与片段的余弦相似度排序取前 6 段。片段沿用所属材料的 `[M编号]`，同一材料的多段合并。

选择向量检索时自动检查索引：材料、来源、分块或嵌入模型变化时重建，未变化的片段复用。排序在 Python 侧对 `float8[]` 计算，按分值、材料号、块号稳定排序，因此同一查询结果可复现。装上 pgvector 后可切换到 `<=>` 排序，调用方不变；本机当前未安装。

嵌入通道默认沿用语言模型的地址与密钥，可用 `QWEN_EMBEDDING_*` 单独配置。每次生成把检索方式、后端、嵌入模型、问句和命中片段写入 `generation_runs.retrieval`。相似度不等于内容支持，片段是否被恰当使用仍需教师判断。

## 图片识读

图片先由独立的视觉模型（VLM）识读为文字，教师核对后选择最多 4 条用于讲义；语言模型只接收解析文字，不接收原图。导出附上解析文字、识读模型和图片指纹。PDF 只抽取内嵌图片，不整页渲染。详细操作见 [image-lecture-workflow.md](image-lecture-workflow.md)。

## 出题与配套出题

- **按备课副本出题**（出题页）：选择备课副本、参考学生（选填）、学生水平、题数（1—30）和基础 / 中等 / 拔高 / 混合难度，题型可选单选、填空、简答、计算、综合应用，可指定知识点与额外要求。混合难度按约 5∶3∶2 分配，题型轮流安排。按画像出题使用当前长期证据；其他水平不发送个人画像。
- **配套出题**（讲义工具栏）：以当前阅读的讲义版本出题，冻结讲义正文及其生成时的材料与画像快照，追加 `quiz-lecture-v1` 规则，要求题目与讲义的概念、方法和符号一致，但不照抄例题。选择通用水平时去掉个体诊断。
- 题数、逐题题型、难度、知识点、选项格式和引用编号由程序校验。题组保存在 `quiz_jobs` 表，学生版不含答案，教师版含答案、解析和易错点，均可下载 Word / Markdown / 纯文本 / 网页。出题使用独立队列（最多 4 个未完成任务），与讲义共用模型锁。
- 新提交的题组请求使用服务端 JSON 模式（`response_format: json_object`，版本标记 `+json-v1`），避免模型在 JSON 字符串中写入未转义的双引号；旧记录和按原输入重试保持原字节。JSON 模式只保证格式有效：实际生成中曾出现答案错误、解析夹带自我更正的题目，程序检查未能发现，需逐题核对。

## 授课 PPT

### 生成课件

在讲义工具栏点击「生成授课 PPT」，依据当前阅读版本设置总页数（6—20 页，含封面和总结，默认 12 页）和课件要求。模型把讲义改编为投屏要点、概念与例题页、课堂提问和总结，详细讲解与练习答案放进逐页教师讲稿（PowerPoint 备注，附来源、原讲义版本和正文 SHA-256）。

默认风格「蓝白教学 · 内容自适应」为 16:9，按内容选用学习目标、重点讲解、概念与条件、分步推导、对比、表格、流程、数据、练习和回顾 10 类可编辑版式；另有 8 套社区 CC0 母版同样适配这些版式。文字、公式、表格和流程节点都可编辑，不自动配图或加动画。导出前检查文字容量和越界，必要时修正一次布局，仍放不下则明确失败，不截断内容。模板与版本兼容见 [ppt-template-integration.md](ppt-template-integration.md)。

新任务冻结风格 ID、模板 SHA-256、映射版本和完整请求，新请求同样使用 JSON 模式；历史课件按原渲染版本导出。页数、文字长度和来源编号由程序校验，答案是否泄露和内容正确性需教师复核。

### 视觉审查（仅 Windows）

在装有 Microsoft PowerPoint 和本机 Ollama 视觉模型（默认 `PPT_AESTHETIC_MODEL=qwen3.5:9b`）的 Windows 机器上，生成任务会渲染全部页面并审查可读性、层次、留白、对齐、对比和裁切，根据明确问题自动修改最多两轮，只保留评价改善的版本。其他环境自动跳过审查，直接交付有效课件。审查结果保存在 `.runtime/ppt-aesthetics/`。

### 单页微调

课件窗口右侧「只修改这一页」，或每页上方的「修改这一页」：选择页码并填写要求，模型只返回目标页 JSON，程序合并后校验其他页不变。完成后对照修改前后，选择「采用并保存新版本」或「放弃修改」。采用后保存为独立课件版本，原版保留，可在新版本上继续微调；未采用的候选不能下载。

## 授课包

在讲义工具栏点击「导出授课包」，系统按当前阅读版本预选对应的配套练习与课件，可改选或不选。授课包只读取已保存记录，不调用模型。ZIP 包含：

- **教师授课手册**（Word 与 Markdown）：授课概览、生成时学生档案与本次讲解安排、讲义正文、练习答案与解析、材料与图片来源、程序检查与待处理问题、授课前核对清单；
- **学生练习**：不含答案和学生信息，可直接打印；
- **练习教师版**、**讲义正文 Markdown**、**授课课件 PPTX**；
- **授课包清单**：每个文件的大小与 SHA-256。

也可只下载教师授课手册。题组与讲义的关系（配套本讲义 / 同课程未关联）会在手册中标明。

## 阅卷与记入画像

- **上传**：学生作答支持图片、PDF、DOCX、TXT、Markdown，单次合计 10 MB，每份最多 30 题、8 张图片或 8 页 PDF（按整页渲染识读，包括扫描与手写作答）。
- **参考答案来源**（三选一）：使用系统题组的教师版答案（有已生成题组时默认，评分后可按知识点记入画像）、上传答案文件，或由模型推导（标记为推导答案，需重点核对）。
- **结果**：逐题显示题干、学生作答、参考答案、建议得分和错因。识读不清或答案冲突的题目标为待核对，不计分；原卷未标分时默认每题 10 分。记录保存在 `.runtime/grading.sqlite3`，可下载 TXT。
- **记入画像**：阅卷完成后选择学生，系统按题组知识点把 AI 建议得分整理为证据草稿；教师可修改表现描述，选择保留原判断或更新状态并填写理由，逐条点击「确认记录」才写入。未对应题组的题目需手动选择知识点。
- 每次只处理一个阅卷任务；服务重启会把未完成任务标为失败，需重新上传。

## 后台任务、配置与失败重试

- **系统设置**：分别配置语言模型、VLM 和 embedding 的地址、模型名和密钥（OpenAI 兼容接口），密钥不回显。连接测试会实际调用模型：语言模型请求一段文本，VLM 识读一张测试图，embedding 返回向量维度。保存会原子更新本地 `.env`，重启服务后生效。
- **检测配置**只检查数据库连接、密钥是否存在和地址格式，不调用模型，不能证明服务可用。
- **队列**：讲义、章节调整、PPT 和固定对照共用一个有限队列（FIFO）；出题有独立队列；所有语言模型调用共用一个并发闸门，同时进行的调用数不超过 `MODEL_CONCURRENCY`（默认 3，见[批量生成与模型并发](#批量生成与模型并发)）。可取消尚未开始的排队任务，已发送的调用不伪装成已取消。单次模型等待上限由 `QWEN_TIMEOUT_SECONDS` 设置（30—600 秒，默认 600）。
- **失败与重试**：失败保留分类、耗时和可读的部分正文，不伪造成功讲义。「按原输入重试」新建运行并复用完整旧输入；要使用最新画像或模板，从表单重新提交。
- **重启恢复**：服务启动时把遗留的排队 / 运行中任务标为中断，不自动重发模型请求。队列只适用于本机单进程。

## 固定输入对照实验

- **历史实验**（2026-10-12）：3 类虚拟画像 × 有 / 无画像 × 2 次重复，共 12 次真实输出，原输入、助手评分与草稿见 [experiments/2026-10-12-bayes](../experiments/2026-10-12-bayes/summary.md)。12 份原稿均低于当时的篇幅要求，另有两处明确数学错误。`demo/experiment.py` 保留文件清单式的兼容运行方式，已有结果不覆盖。
- **当前版本对照**（生成记录 → 固定对照）：冻结大学概率进阶任务的同样 12 份输入，冻结时不调用模型；开始后顺序执行真实调用，并暂时阻止其他生成任务。输入、参数和结果存入 PostgreSQL，已有结果不会被挑选替换。
- 逐份通过「编辑与审核」记录正确性、目标、画像对应、引用支持和实际修改用时；页面只汇总实际保存的记录，没有记录的用时不估算。
- 模型参数一致不保证输出确定；助手量表不能代替教师评审和真实教学效果。

## 界面与操作

- **动效**：页面切换、弹窗、讲义出现和后台任务状态有简短的过渡；系统开启「减少动态效果」时全部关闭。
- **可安装**：在 Chrome / Edge 地址栏可把页面安装为独立窗口的应用（PWA）。它仍然连接本机服务；离线时只能打开页面外壳，数据接口不做缓存。
- 左侧导航按页面切换，使用 URL 片段，支持刷新和前进后退；切换页面保留表单输入和后台任务。窄屏时导航变为顶部单行横向滚动。
- 工作台顶部的步骤条显示「选择 → 生成 → 审核修订 → 配套出题、课件与授课包」四步；空白时直接列出最近 3 份讲义。
- 讲义工具栏在打开讲义后出现，分为「授课准备」（配套出题、生成授课 PPT、导出授课包，并显示已有练习与课件数量）、「审核与追溯」和「导出」三组。
- 宽屏可拖动两栏间的把手调整设置栏宽度（方向键微调，双击恢复默认）；窄屏时设置与预览上下排列，打开讲义后自动滚到预览。
- 编辑、追溯和对照窗口的标题与关闭按钮始终可见，正文独立滚动。历史验证见 [demo/VERIFICATION.md](../demo/VERIFICATION.md)。

## 规模数据与评测基线

预置数据只有 6 名学生和 6 段各一两百字的材料，测不出真实规模下的表现。`demo/scale/` 提供可选的扩展数据和三个脚本，详见 [scale-data.md](scale-data.md)：

- **扩展语料**：两门整章课程（一元一次方程、条件概率与贝叶斯），各 12 个知识点，每个知识点一段自编讲解和一组由程序计算的例题，合计约 1.4 万和 2.4 万字符。后者超过 16000 字符的材料预算，会走按知识点轮流保留、按目标节选的路径。
- **合成班级**：每门课默认 40 名合成学生，按能力层次和知识点难度抽样出掌握状态与学习证据。
- **检索评测**：48 条带标注的教学问题，比较向量、BM25 和两者融合的命中率。
- **生成基准**：在一次性的隔离库里通过真实的队列和存储代码批量生成，比较不同并发下的用时；加 `--real` 时调用真实模型，并统计篇幅达标率和各项程序检查。
