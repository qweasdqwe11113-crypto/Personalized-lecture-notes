# Demo 验证记录

日期：2026-09-18。验证对象为本地 `lecture_demo_prototype` 数据库及用户指定的 Qwen 服务。

## 已完成

- 新建独立 PostgreSQL 数据库，使用本地用户连接；没有修改其他数据库。
- 初始数据为 3 名虚拟学生、3 个知识点、9 条掌握记录、3 条课程材料。
- 通过网页完成 3 次真实 Qwen 讲义生成并保存：小林约 21.4 秒，小陈早期版本约 34.2 秒、修订提示后约 24.9 秒。
- 小林结果补充了等式平衡和逐步操作，并正确保留未知状态；小陈结果缩短基础回顾，增加含括号或两边含未知数的例子。
- 刷新网页后，可以从历史记录读取讲义与生成时的上下文。
- Markdown 附件接口返回讲义正文和来源链接，旧版本的审核提醒一并导出。
- 按一步方程主题查询，仅返回知识点 1、2 对应的两条材料。
- 无效学生参数类型、无效主题、超长目标返回 400；跨来源生成请求返回 403。
- 重复执行初始化，没有重复插入种子数据或删除已有讲义。
- 检查源码及前端文件不包含模型密钥；本机 `.env` 权限为 600。
- Python 编译检查与 JavaScript 语法检查通过。

这里验证的是端到端可用性与少量样例差异，不构成模型教学正确率或实际学习效果的统计评价。所有生成讲义仍需人工审核。
