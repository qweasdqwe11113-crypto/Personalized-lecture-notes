# 大学概率小专题

核查日期：2026-10-12。主题为条件概率、全概率与贝叶斯公式；资料为少量公开课程文字摘要，产线数值是本项目自编假设模型。大学课程的基础 / 进阶任务由共同教学目标区分，学生掌握状态单独维护。

## 资料与范围

| 材料 | 课程出处 | 本地内容与边界 |
| --- | --- | --- |
| M11 | [Penn State STAT 414，4.2 / 4.3](https://online.stat.psu.edu/stat414/Lesson04) | 条件概率定义、正分母、交集与乘法规则；两个方向一般不同 |
| M12 | [Penn State STAT 414，6.2](https://online.stat.psu.edu/stat414/Lesson06) | 有限互斥完备划分、同一观测事件的交集分解、全概率 |
| M13 | [Penn State STAT 414，6.2](https://online.stat.psu.edu/stat414/Lesson06) | 由条件概率和全概率得到贝叶斯公式；归一与先验变化为公式的直接推论 |

本地材料是中文概括，不是整章复制。来源章节使用不同事件字母，本地统一以 Ai 表示来源、B 或 D 表示观测事件。没有把本地例子的参数说成教材实测数据。适用条件要逐个说明：P(A|B) 要求 P(B)>0，反向要 P(A)>0，使用各 P(B|Ai) 要各 P(Ai)>0；划分必须互斥且覆盖整个样本空间。互斥划分不能推出独立。

来源提供定义和公式，数值例题、精确归一核查与“交集为零时两个方向仍可相等”的反例由项目依据这些公式计算，见 [参考计算](../../experiments/2026-10-12-bayes/math_reference.json)。连续密度、多次观测的独立假设、因果推断均不在本专题范围。

## 共同目标与假设例题

基础任务要求解释方向和条件、计算全概率与后验并核对归一；进阶任务要求从定义及划分推导公式，再比较先验变化。两种任务均可选择三种画像，不把需要补充的学生限制为较低课程级别。

| 情形 | 来源先验 | 次品似然 | P(D) | 两项后验 | 假设 10000 件次品 |
| --- | --- | --- | --- | --- | --- |
| 基准 | 0.6 / 0.4 | 0.02 / 0.05 | 0.032 | 0.375 / 0.625 | 120 / 200 |
| 仅改先验 | 0.2 / 0.8 | 0.02 / 0.05 | 0.044 | 1/11 / 10/11 | 40 / 400 |

精确后验之和为 1。舍入到三位小数可辅助展示，仍需核对方向和分子；归一不是正确性的充分条件。
