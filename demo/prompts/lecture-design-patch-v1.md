【局部修正 lesson-design-patch-v1】上面是你给出的课堂设计，程序检查提出了下面的问题。只改有问题的地方，其余原样保留。
只输出一个 JSON 对象，里面只放要改的部分，没有改动的内容不要输出：
- segments：要改的环节。每项写 id 和要改的字段，没写的字段保持原样，例如 {"id":"S3","minutes":8,"focus":false}。
- items：要改的题目，写法同上，例如 {"id":"P2","stem":"新的题干","steps":[{"do":"……","why":"……"}],"answer":"新答案"}。新加的题用新编号并写全所有字段，同时写出它所属环节的 items 字段。
- remove：要删掉的题目编号，例如 ["P4"]；程序会把它从环节的 items 和目标的 checked_by 里一并去掉。只在题目比授课设置多时用；例题和当堂练习的道数必须保持授课设置的数量，题目与前面的题重复时改数据、情境或问法，不要删题。
- objectives：要改学习目标或 checked_by 时，给出完整的 objectives 列表。
- 其他字段（title、focus、learner、plan_links、notation、board_plan、figures、summary）要改时，给出这个字段的完整值。
不新增或删除环节。改了题目，就同步改用到它的提问、板书、教师活动和步骤，前后数字保持一致；改了分钟数，就重新核对各环节 minutes 之和等于授课时长，每道例题至少 4 分钟、每道当堂练习至少 3 分钟。
字段的格式和公式写法与原来的要求相同，字符串里的反斜杠写成两个。
